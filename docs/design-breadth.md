# 騰落（設計）

市場全体の上げ下げを数で見るペイン（`breadth`）。タブで「市場」と「業種別」を切り替える。要求は [requirements.md](requirements.md) §6.17
（FR-BR1〜BR5）。マーケットのタブの右下に、マーケットの小さなチャート（market-overview）と並べて置く。

## 1. 方針

- **見た目と操作はウォッチリスト・マーケット一覧に揃える**。タブ（`.tabs`）・件数と列の選択の段（`.filter`）・表（`table.grid`）、
  ↑↓・PageUp/PageDown・Home/End・Ctrl+PageDown/PageUp・G/Shift+G・← → と S・Ctrl+Shift+C・Enter。
- **データは指標の表（`metrics`）だけ**から作る。通信先・データ源は増やさない。スクリーナーと同じ口（`screener.run`）で、
  プライム（株式）と J-REIT の指標を受け取り、renderer で数える。
- **集計は純粋な関数**（`src/shared/breadth.ts`）。ペインは数えない。
- **業種の騰落率はヒートマップと同じ時価総額の加重**（ヒートマップと数字が合うように）。

## 2. 指標の表に足す列

今の `metrics` には「その日の売買代金」と「52 週の高値・安値を更新したか」が無い（`turnover20` は 20 日の平均、`hi52` は今日を含む高値）。
`METRIC_COLUMNS` と `computeMetrics` に次の 3 列を足す（DB の移行 v6 で表を作り直し、起動時に日足から計算し直す）。

| 列         | 意味                                                                                                     |
| ---------- | -------------------------------------------------------------------------------------------------------- |
| `turnover` | 最新の足の売買代金（終値 × 出来高。円）。出来高の無い足は欠損                                            |
| `newHi52`  | 最新の足の高値が、その前の 52 週（244 本）の高値を上回ったら 1、そうでなければ 0。日足が足りなければ欠損 |
| `newLo52`  | 同じく、安値が前の 52 週の安値を下回ったら 1                                                             |

スクリーナーの項目（登録表の `FIELDS`）には足さない（このペインの集計にだけ使う）。

## 3. 集計（`src/shared/breadth.ts`）

```ts
interface BreadthIn {
  id: InstrumentId
  group: string
  m: MetricsRow
}
interface BreadthRow {
  key: string // 市場: 'P' | 'R'、業種: 33 業種の名前（日本語。表示は言語に合わせる）
  n: number // 銘柄数（基準日の値がある銘柄）
  up: number
  down: number
  flat: number // 前日比 > 0 / < 0 / = 0
  newHi: number
  newLo: number
  turnover: number | null // 売買代金の合計
  ret: Record<'d1' | 'm1' | 'm3' | 'ytd' | 'y1', number | null> // 時価総額で加重した騰落率
  asOf: JstDate | null // いちばん新しい基準日
}
export function breadth(rows: BreadthIn[]): BreadthRow[]
```

- **古い値は数えない**: 基準日がその集まりのいちばん新しい基準日より前の銘柄（売買の無い日・取得の取りこぼし）は、値上がり・値下がり・
  新高値・新安値・売買代金に入れない。騰落率の加重には入れる（ヒートマップと同じ）。
- 前日比が欠損の銘柄は、値上がり・値下がり・変わらずのどれにも入れない。
- 加重の騰落率は、値と時価総額の両方がある銘柄だけで出す（全部欠損なら欠損）。J-REIT も時価総額（`marketCap`）で加重する。

## 4. ペイン（`breadth`）

```
[騰落 · 市場                                              ]
 市場 │ 業種別 33                                              ← ウォッチリストと同じタブ
 基準日 2026/11/13                              2 行  [列]    ← 段
 市場     銘柄数  値上がり 値下がり 変わらず 新高値 新安値 売買代金 前日比
 プライム  1,553    …
 J-REIT      58    …
```

- **市場のタブ**: 行はプライム（株式）と J-REIT。列は 前日比（加重）・値上がり・値下がり・変わらず・新高値・新安値・売買代金・銘柄数（狭いペインでは右から隠すので、前日比を左に置く）。
- **業種別のタブ**: 行は 33 業種（プライムの株式）。列は 1日・1か月・3か月・年初来・1年・値上がり・値下がり・売買代金・銘柄数。既定の並びは 1日の降順。
- **中へ入る**（ヒートマップと同じ）: 行で Enter を押すと、その市場・業種の銘柄の一覧になる（タブの見出しは「業種別 › 銀行業」）。
  銘柄の一覧はウォッチリストと同じ列の定義（`lib/columns.ts`。既定は コード・名前・終値・前日比・1か月・年初来・売買代金(20日平均)）と
  `RowCells`。↑↓ で同じリンク色のチャートが追従する。Esc・Backspace で戻る（戻ると入る前の行を選ぶ）。
- **列**: 市場・業種別の表は、このペインの列の定義（`lib/breadthColumns.ts`。見出し・値・並べ替えの値）。Ctrl+Shift+C で、その表の列から選ぶ
  （ウォッチリストと同じダイアログ）。銘柄の一覧ではウォッチリストと同じ列の選択。列の選択と並べ替えは表ごと（市場・業種別・銘柄）に持つ。
- **色**: 前日比・騰落率は `--up` / `--down`（`cls`）。値上がり・値下がりの数も同じ色。
- 選択は中身（市場の記号・業種名・銘柄）で持つ（`SelectionFollow`）。取得で値が変わって並びが入れ替わっても動かない。
- 一覧の中身（`columns()`）は、銘柄の一覧のときだけ返す（CSV の書き出し・一覧の取り直し）。
- フリーの窓には置かない（一覧のペインと同じ）。

### キー（`registerPane` の `key()`）

| キー                                     | 動き                                                           |
| ---------------------------------------- | -------------------------------------------------------------- |
| ↑ / ↓ / PageUp / PageDown / Home / End   | 行を選ぶ（銘柄の一覧では同じリンク色のチャートが追従）         |
| Enter                                    | 市場・業種の中へ入る / 銘柄をリンクグループに送る              |
| Esc / Backspace                          | 中から戻る                                                     |
| Ctrl+PageDown / Ctrl+PageUp、G / Shift+G | タブ（市場・業種別）を切り替える（中に入っていれば戻ってから） |
| ← / → と S                               | 列を選んで並べ替える（もう一度で逆順）                         |
| Ctrl+Shift+C                             | 列を選ぶ                                                       |

## 5. マーケットのタブの並び

右の下の段を左右に分け、左に market-overview（55%）、右に騰落（45%）を置く。リンク 1。保存済みのレイアウトは変えない（「プリセットに戻す」で新しい並び）。

## 6. テスト

| 層  | 確かめること                                                                                                                                                                                 |
| --- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| L1  | `breadth`: 上げ下げ・変わらず・欠損、古い基準日を数えない、新高値・新安値、売買代金の合計、時価総額の加重（欠損・0）。`computeMetrics` の `turnover`・`newHi52`・`newLo52`（境目・日足不足） |
| L2  | 列の定義: ID が重ならない、見出しの文言が `ja` と `en` にある                                                                                                                                |
| L3  | DB の移行 v6 で列が増え、指標を計算し直す。`screener.run` の結果に 3 列が入る                                                                                                                |
| L5  | マーケットのタブに騰落があり、G で業種別、Enter で業種の中、↓ でチャートが追従、Esc で戻る、S で並べ替え                                                                                     |
