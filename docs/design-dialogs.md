# ダイアログの見直し（案）: コマンドバー・ショートカット一覧・ペインの種類・設定

対象は、キーで呼び出して「探して選ぶ」3 つの画面と、設定の画面。

| 画面 | キー | 今の実装 | 要求 |
|---|---|---|---|
| コマンドバー | Ctrl+K | `overlays/Palette.svelte` | FR-KB1・FR-KB7・FR-U3 |
| ショートカット一覧 | F1 | `overlays/Help.svelte` | FR-KB7・FR-KB6 |
| ペインの種類を変える | Ctrl+Shift+N | `commands.ts` の `changeWidgetDialog` → `Dialogs.svelte` の `choice` | §6.5「一覧から選ぶ」・FR-L7・FR-L11 |
| 設定 | Ctrl+, | `overlays/Settings.svelte`・`KeysSettings.svelte`・`news/NewsSettings.svelte` | FR-KB2・FR-KB6・FR-V10・FR-D6 ほか |

モック: [mock/palette.html](mock/palette.html)・[mock/shortcuts.html](mock/shortcuts.html)・[mock/panetype.html](mock/panetype.html)・[mock/settings.html](mock/settings.html)（`file://` で開ける。値はすべて架空）。

## 1. 今の実装と課題

### 1.1 コマンドバー（Palette.svelte）

- 1 つの入力欄で、銘柄（`instruments.search` の 10 件）・スクリーニング条件（6 件まで）・アクション（`paletteActions()` とマイレイアウトのページ）を探す。`>` で始めるとアクションだけ。
- 一覧に無いコードは「追加して取得する」（FR-U3）。銘柄の行には ★（Ctrl+D）と、フォーカス中のウォッチリストへの追加（Ctrl+Enter）。
- 照合は、アクションは名前と ID の**部分一致**（`includes`）、条件は名前の部分一致。

課題:

1. **空のときにアクションが登録順に約 90 件並ぶ**。何から選べばよいか分からず、最近使ったものも出ない。
2. アクションに**分類が無く**、「アクション」の 1 段に全部が入る。似た名前（「ドロワー」「ウォッチリスト」を含むもの）が散らばる。
3. 照合が部分一致だけ。「保有 書き出」のように語を分けて打つと 0 件。ひらがな・カタカナの違いでも当たらない。どこが当たったかの強調も無い。
4. 今のペインで使えないアクション（一覧のペインが要るものなど）も同じ見た目で出て、Enter のあとでトーストで断られる。
5. 銘柄の行はコード・名前・市場だけ。終値・前日比・保有の有無が見えないので、同名の銘柄（親子上場・REIT と運用会社）を選び分けにくい。
6. ペインの中のキー（チャートの L・グリッドの P など）はアクションではないので、コマンドバーで探しても出てこない。

### 1.2 ショートカット一覧（Help.svelte）

- 8 つの段（全体・一覧・スクリーナー・チャート・チャートグリッド・マーケット・保有・ドロワー・ニュース）を 2 段組みで並べる静的な表（約 110 行）。
- 割り当てを変えられるキーは `keyOf()` で今の割り当てを出す。フォーカス中のペインの段は見出しが色付きで「●」。

課題:

1. **絞り込めない**。110 行の中から目で探す。キーから操作を引く（「Ctrl+Shift+N は何だっけ」）こともできない。
2. FR-KB7 は「フォーカス中のペインで効くキーを**先に**出す」だが、今は印を付けるだけで並びは固定（チャートの段は 2 段目の中ほど）。
3. 1 行に「A / B / C」と操作を詰め、キーも「X / Y / Z」と並べている（マーケット・配当シミュレータの段は 1 行に 7〜8 個）。操作とキーの対応を目で数えることになる。
4. 「マーケット・保有」の段に、銘柄情報・ヒートマップ・株価ボード・ランキング・騰落・保有・ポートフォリオ・配当シミュレータが同居して長い。
5. 割り当てを変えられるキー（アクション）と、変えられないペインの中のキーの区別が見えない。
6. 行がコンポーネントの中のリテラルなので、テストできない（キーの表記の揺れ・抜けを確かめられない）。

### 1.3 ペインの種類を変える（choice ダイアログ）

- 汎用の `choice` ダイアログに、17 種類（フリー N では 5 種類）の名前を登録順に並べる。↑ ↓ で選び Enter。
- 変えると `changeWidget` が状態を作り直す。リンク色は残り、リンクの無いペインは銘柄だけ引き継ぐ（FR-L11）。

課題:

1. 名前だけで、**何のペインか分からない**（「マーケット」と「マーケット一覧」、「保有」と「ポートフォリオ」の違い）。
2. **今の種類が分からない**。選択はいつも先頭（チャート）から。
3. 打って絞り込めない。17 件を ↓ で送る。別名（株価ボード → ヒートマップ）でも引けない。
4. 変えると時間軸・指標などの**ペインの設定が消える**ことが、選ぶ前に分からない。
5. フリー N では使えない種類が黙って消える（なぜ無いのか分からない）。

### 1.4 設定（Settings.svelte）

- 820×460px。左に 7 つのタブ（一般・表示・チャート・データ・キー・ニュース・このアプリについて。↑ ↓ で切り替え）、右に「名前 | 操作」の行を区切り線で並べる。
- 操作の部品は、オン・オフが 10px の四角（`.toggle .box`）、選択肢が高さ 20px・等幅の字体のセグメント（`.seg`）。表示倍率は 6 個、日足の保存期間は 1〜10 の 10 個のボタン。

課題:

1. **まとまりが見えない**。区切り線だけの平たい行で、「起動と常駐」の 3 項目と「更新と通知」の 3 項目の境が無い。枠・見出しが無いので、どこまでが 1 つの話か分からない。
2. **説明の出し方がばらばら**: スイッチの横に小さく（自動で更新）、下の段落（目標利回りの線）、ツールチップだけ（フォーカスの枠）、無し（言語・テーマ）。
3. **部品が小さく、意味が読みにくい**。10px の四角はチェックボックスに見え、オン・オフの文字も無い。等幅・20px のセグメントは押しにくい。10 個並ぶ「1 2 3 … 10」は単位（年）も容量も出ない。
4. **置き場所が混ざる**: 一般に行の高さ・表示倍率（表示の話）と追加した銘柄（データの話）がある。
5. データのタブで、**消してしまう操作**（全データを削除して取り直す）が JPX の取り込みと同じ並びにある。バックアップ・ログ・書き出しは説明の無いボタンの列。
6. **探せない**。どのタブにあるかを覚えていないと見つからない。
7. **既定から変えた項目が分からず**、1 つずつ既定に戻せない（キーのタブだけ、変えたキーが青い）。
8. 本文はボタンを Tab で 1 つずつ巡るので、下の項目まで遠い。
9. 高さがタブで変わる（min-height だけ）。ニュースのフィードの一覧などは窮屈。

## 2. 共通の方針

4 つを**同じ骨格**にする（スクリーナーの条件を選ぶダイアログ `FieldPicker` の 3 回目の案と同じ考え方）。

```
┌ タイトル ─ 検索欄 ──────────────────────────────┐
│ 範囲・探し方のチップ（検索欄の下の行）  Tab で送る   │
├─────────────────────────────────────────────┤
│ 段（分類）ごとの一覧。当たった文字を強調             │
│ …                                                   │
├ 下の段: 選んだ項目の説明（2 行まで。キーだけで読める）┤
└ フッター: このダイアログのキー（kbd で）             ┘
```

- **照合は共通の関数**（`src/shared/match.ts`。L1 でテスト）: NFKC・小文字・カタカナをひらがなに寄せ、空白で分けた語をすべて含むものを残す（AND）。語の頭で当たったものを上に。別名（`ALIAS_OF` と同じ考え方）でも当てるが、強調はしない。当たった範囲を返し、画面は `<mark>` で強調する（`{@html}` を使わず、区切った文字列を `{#each}` で描く）。
- 選んだ項目の**説明は下の段に固定の高さで**出す（出し入れしない。CLAUDE.md の「場所を取ったまま見えなくする」）。
- キーは `<kbd>` を 1 キーずつ描く（`Ctrl` `Shift` `N`）。表記の分解は `lib/keys.ts` の関数（L1）。
- 文字の入力欄にフォーカスを置いたまま、↑ ↓ PgUp PgDn で一覧を動かす（今と同じ）。IME の変換中は無視（FR-KB5）。
- **範囲・探し方のチップは検索欄の下の行**に置く（検索欄と同じ行だと、幅 560px や英語の Symbols / Actions で入力欄が潰れる）。Tab は「このチップの行を送る」で 3 画面とも同じ意味にする。
- **Enter の意味は下の段に**出し、フッターには書かない（同じことを 2 か所に書かない）。下の段の右の案内は 1 行に横並び（縦に積むと固定の高さからはみ出してフッターに重なる）。
- 行の先頭の列は種類によらず**同じ幅**（76px）にし、名前の始まりをそろえる。

### 2.1 トークン

- 文字は app.css の `--fs-0`〜`--fs-5` だけを使う（モックの 15・17・18px は `--fs-4`（16px）・`--fs-5`（20px）に寄せた）。
- 角丸は 2 つのトークンを足す: `--radius-ctl`（4px。ボタン・検索欄・kbd・セグメント）と `--radius-dlg`（8px。ダイアログ・枠・カード）。今の `--radius`（2px）は表の中の小さな部品に残す。
- 検索欄の高さは 2 つだけ: 主役 34px（コマンドバー・F1・ペインの種類）、補助 28px（設定の左・キーのタブ）。
- **選択行**は左の線を 3px（`--sel-bar`）にする。ライトの `--select-strong`（#e6eefb）は地の `--panel-2`（#f5f7fa）とほぼ同じなので、一段濃く（#d6e4fa）する。
- 意味の色: 危険は `--danger`・`--danger-bg`・`--danger-line`（`--up` は欧米式で緑になるので使わない）、目標利回りの線は `--yield-line`、キーで探して当たったキーは `--focus`（`mark` とそろえる。警告の `--warn` は使わない）。「いま」などの札は `--text-2` の枠（`--ok` の緑は欧米式の上昇と重なる）。
- 薄くするのは不透明度ではなく文字の色（`--text-3`）で（ライトで説明が読めなくなる）。

### 2.2 読み上げ（アクセシビリティ）

- 検索欄は `role="combobox"`・`aria-expanded`・`aria-controls`・`aria-activedescendant`（選んだ候補の ID）。一覧は `role="listbox"`、候補は `role="option"`・`aria-selected`、段は `role="group"` と見出しの `aria-labelledby`。
- 下の段は `aria-live="polite"`（選んだ候補の説明・使えない理由を読む）。件数が変わったら「12 件」と読む。
- 使えない候補は `aria-disabled="true"`。錠・鉛筆などのアイコンには読み上げ用の文字（「今は使えません」「割り当てを変えられます」）を付ける。
- F1 の「キーを押して探す」はキーを奪うので、入ったときに「キーを押して探しています。Tab で文字に戻ります」と読む（`aria-live="assertive"`）。
- 設定のタブは `tablist`・`tab`・`tabpanel`、スイッチは `role="switch"`・`aria-checked`・項目の名前。行の ↑ ↓ のほかに、Tab で行の中の部品を順に巡る道も残す（読み上げソフトの利用者の逃げ道）。
- コントラスト: 本文の文字は 4.5:1、部品の枠・選択の線・スイッチのつまみは 3:1 以上（オンのスイッチのつまみは `--bg` の色にして地の `--focus` との差を取る）。

## 3. コマンドバー（Ctrl+K）

- 幅 640 → 720px。検索欄の下の行に**範囲のチップ**「すべて・銘柄・アクション・条件・ペイン」。Tab / Shift+Tab で切り替え。`>`（アクション）はそのまま、`#`（スクリーニング条件）・`@`（ペインの種類）を足す。
- **空のとき**は先に 3 段: 「最近の銘柄」（チップを横に 1 行。← → で選ぶ。↑ ↓ ではこの行を 1 段として飛ぶ）・「最近使ったアクション」（3 件）・「このペインで」（フォーカス中のペインの種類に関係するアクション。例: チャートなら「アラートを作る」「日足を CSV に書き出す」「フリーのウィンドウへ送る」）。続けて「すべてのアクション」を分類ごとに。
- アクションに**分類**を持たせる（`Action.group`: ペインとレイアウト・ウィンドウ・銘柄とリスト・保有・アラート・データ・表示・アプリ）。分類の名前は、行の先頭に枠なしの `--text-3` の文字で、「最近使った」「このペインで」と検索の結果のときだけ出す（分類の見出しの下では見出しの繰り返しになるので出さない）。右にキー。
- **今使えないアクションは**行の先頭に錠のアイコンを置き、名前とキーを薄くし、下の段に理由（「一覧のペインにフォーカスしてから」）。Enter は今と同じくトーストで断る（実行の可否は `Action.enabled?(): string | null` で、理由の文言を返す）。
- 銘柄の行に **終値・前日比（%）**・保有の印・★。値は `app` が持っている指標から（無ければ出さない。Core に問い合わせを足さない）。
- **ペインの種類**も候補にする（「このペインをヒートマップにする」）。Enter で §5 と同じ `changeWidget`。
- **ペインの中のキー**も候補にする（「チャート: 対数軸 L」）。実行はできないので、Enter で F1 をその語で絞り込んだ状態で開く。
- 下の段: 選んだ項目の説明と、右に Enter（とその候補で使える Ctrl+Enter・Ctrl+D）の意味を 1 行で。キーの割り当てへ飛ぶ Alt+Enter は作らない（使う頻度の割に 2 画面をまたぐ実装になるため。割り当ては設定 > キー で探す）。
- 最近使ったものは設定の平たい項目 `paletteRecent: string[]`（`act:<id>`・`sym:<id>` を 20 件まで）に持つ。利用者が選ぶ設定ではないので、設定の登録表（§6 の `settingsSpec`）には載せない（「既定から変えた数」・既定に戻す・設定を探す、の対象外）。利用者のデータの書き出しにも入れない。

## 4. ショートカット一覧（F1）

- 上に**検索欄**（コマンドバーと同じ部品）。操作の名前・別名・キーの表記で絞り込む（「対数」「Ctrl+Shift」「ドロワー」）。
- **キーを押して探す**: 検索欄の下の「文字で・キーを押して」の 2 つのチップ（コマンドバーの範囲のチップと同じ部品）を、Tab で切り替える。押して探すときは、押した組み合わせ（Ctrl+Shift+N）を欄に出し、そのキーを使う行だけを残す（ペインごとに違う意味があれば全部出る）。範囲の表記（`1–9`・`Alt+1–6`・矢印）にも当てる。**当たった組み合わせの kbd だけ**を `--focus` で示す（同じ行の当たっていないキーは光らせない）。
- 左に**目次**（段と件数）。**フォーカス中のペインの段を先頭**に置き「● いまのペイン」と書く（FR-KB7 の「先に出す」を満たす）。PgUp / PgDn で段を移る。絞り込み中は件数が変わり、0 件の段は薄くする。
- 段を**ペインの種類ごとに分ける**: 全体（アプリ・ペインとレイアウト・マイレイアウト・ウィンドウ・銘柄・アラート）・一覧・スクリーナー・チャート・チャートグリッド・ヒートマップと株価ボード・ランキングとマーケット一覧と騰落・保有とポートフォリオ・銘柄情報・配当シミュレータ・ドロワー・ニュース。
- **1 行に 1 操作**。「日足 / 週足 / 月足」は 3 行に分ける（キーが 1 つずつ並ぶ）。似た操作は小見出しでまとめる。
- 行は「**キー（左の固定列 130px・右寄せ）｜操作の名前｜印**」。名前が左端・キーが右端だと間が 450px ほど空いて目で追えない。段の中は、幅が 700px 以上あれば小見出しのまとまりごとに **2 段組み**（`columns: 2 360px`）。720px 以下では左の目次を畳む。
- 割り当てを変えられる行の印は鉛筆のアイコン（`title` と読み上げ用の文字つき）。「変更可」の文字の列は英語（Rebindable）で溢れるので使わない。
- **探すだけの画面**にする。行から操作を実行しない（実行はコマンドバーの役目。2 つの画面の役目を重ねない）。Enter も行に対しては何もしない。
- 割り当てを変えられる行（アクション）は、下の段に「割り当ては 設定 > キー で変えられます」と、今の割り当てが既定と違えば「既定: …」を出す。ペインの中のキーは「割り当ては変えられません」。
- 行のデータは `lib/shortcuts.ts` の登録表にする（`{ section, group, label: Key, keys: string[] | actionId, alias? }`）。i18n のキー・表記の形・ACTIONS の ID の実在、**1 行の名前に「 / 」で複数の操作を詰めていないこと**を L2 で確かめる。
- キーボードの早見図（単キーの割り当てを色で塗る）は入れない。ペインごとに意味が変わるうえ、利用者の配列（JIS・US）で形が違い、作る手間に対して得るものが小さい。キーを押して探すで足りる。

## 5. ペインの種類を変える（Ctrl+Shift+N）

- 種類を**カードの格子**（56×36 の線画の図・名前・説明）で、5 つの分類に分けて並べる: 銘柄を見る（チャート・マルチ時間軸・銘柄情報）・見比べる・絞り込む（ウォッチリスト・スクリーナー・チャートグリッド・ランキング）・市場（ヒートマップ・マーケット・マーケット一覧・騰落）・保有と配当（保有・ポートフォリオ・配当カレンダー・配当シミュレータ）・その他（ニュース・ジョブ）。4 列の格子で段が 4 枚ずつに収まるよう、ニュースは「その他」に置く。
- **線画の図**はペインの形を表す（チャートはローソク足、ヒートマップは矩形の分割、マルチ時間軸は 3 段など）。`currentColor` の線だけで描き、データは描かない。名前を読まずに形で選べる。説明は切らずに全文を出す。
- **今の種類に「いま」の札**（`--text-2` の枠）を付け、選択はそこから始める。Enter で今と同じ種類を選んだら何もしないで閉じる。同じ種類がこのタブにもうあれば「このタブに 1」の札を付ける（同じ種類を重ねる誤りを防ぐ）。
- 打って絞り込む（名前・説明・別名。「株価ボード」→ヒートマップ、「MTF」→マルチ時間軸、「ログ」→ジョブ）。漢字の名前には読み（はいとう・ほゆう）も別名に持たせる（照合は漢字を読まないので）。矢印で格子を動く（← → は検索欄が空のときだけカードを動かす。打っている間は文字のカーソル）。**打っている間は ↑ ↓ を読む順に 1 枚ずつ**送る（絞り込むと同じ行に 2 枚並ぶことがあり、↓ だけでは 2 枚目に行けないため）。空のときも、↑ ↓ ← → で空間的に相手が無ければ読む順の前後へ送る。
- 下の段は**変えると何が起きるか**だけ（カードの説明は繰り返さない）: 「リンク 1 の銘柄に従う」または「銘柄 7203 を引き継ぐ」（FR-L11）と、「時間軸・指標などこのペインの設定は初期に戻る」。今の種類と同じなら「いまの種類」。
- フリー N で使えない種類は消さずに薄くし（不透明度ではなく文字の色で）、札の行に「1 枚目だけ」（ツールチップと読み上げに「フリーのウィンドウでは使えません」。FR-L7）。選べない。
- 右に分割・下に分割（Ctrl+Shift+E / O）の続きで種類を選ぶときも同じダイアログを使う（タイトルが「新しいペインの種類」になり、「いま」の札は出さない）。
- 説明・別名・分類は `lib/widgetInfo.ts`（`WIDGETS` と一致することを L2 で確かめる）。線画の図（56×36）とコマンドバーの 16px のアイコンは `components/icons/` に。

## 6. 設定（Ctrl+,）

モック: [mock/settings.html](mock/settings.html)。

- 大きさを **980×660px に固定**（タブを替えても揺れない。狭い窓・大きい倍率では今と同じく背景の幅に収める）。ダイアログの幅が **760px 以下**（表示倍率 150% の 1366×768 は実質 910×512 で当たる）では、左の列をアイコンだけ（52px）にし、行は操作を名前の下に置き、データの状態の 4 枚は 2×2 にする（container query）。
- 左: 上に**設定を探す**欄（Ctrl+F・/）、その下にアイコン付きのタブ。既定から変えた項目のあるタブに、その数を `--text-3` の数字だけで（「● 1」は未読の通知に見えるので使わない）。下にバージョンと「変更はすぐ保存されます」。
- 右: タブの名前と一言の説明。本文は**節ごとの枠（カード）**に見出しを付ける。
- 行は「名前（太字）と**説明（いつも名前の下）**｜操作｜↺」の 3 列。既定から変えた行は**名前の前に 6px の青い点**と名前の後に「既定: 100%」（選択行の左の線と同じ辺・同じ色に置くと紛れる）、右の ↺（Backspace）で既定に戻す。依存する行（「起動したら通知領域に入れておく」はサインイン時の起動がオンのときだけ）は薄くして理由を出す。理由の文は**常に場所を取り**（`visibility: hidden` で出し入れ）、説明には同じことを書かない（行の高さを変えない・文を重ねない）。
- 部品: オン・オフは**スイッチ**（36×20・「オン／オフ」の文字つき）、選択肢は高さ 26px・通常の字体のセグメント、値が多いもの（表示倍率・日足の保存期間）は**ステッパー**と見込み（保存期間なら容量の増減）。**← → は仮の値**（点線の枠）で、見本と見込みだけが変わる。**Enter で 1 回だけ決める**（Esc でやめる）。保存期間を縮めるときの確認も、決めるときの 1 回だけ（1 段ごとに確認を出さない。10 年から 3 年で 7 回にならない）。表示倍率も、決めるまではダイアログ自体を動かさない（見本の文字だけ大きさが変わる）。
- **見本**: テーマ（見出し・一覧と選択行・ローソク足 3 本を描いた小さな画面。何が変わるかが分かる）・ローソク足の色（ローソク 3 本。色の名前も）・行の高さ（架空の文字の線を入れた 3 行。地の色の差だけだとダークで見えない）・表示倍率（見本の文字）・目標利回り（`--yield-line` の線の見本）。
- タブの中身を並べ直す:

| タブ | 節 |
|---|---|
| 一般 | 言語 / 起動と常駐（閉じても通知領域・サインイン時の起動・起動したら通知領域）/ 更新と通知（自動で更新・アラートの通知・新しいバージョン） |
| 表示 | テーマ / 文字と密度（表示倍率・行の高さ。一般から移す）/ 色（ローソク足）/ 動きとフォーカス / レイアウト（すべてのタブを初期に戻す） |
| チャート | 目標利回りの線（スイッチ・3 つの欄・見本）/ 画像（保存） |
| データ | 状態（DB の容量・銘柄数・取得失敗・期間の 4 枚）/ 保存（日足の保存期間）/ 銘柄（銘柄一覧の更新・JPX の取り込み・追加した銘柄。一般から移す）/ バックアップと持ち出し（利用者のデータ・DB・ログ）/ **危険な操作**（全データを削除して取り直す。`--danger` 系の枠） |
| キー | 検索・「変えたものだけ」・分類ごとの枠（コマンドバーと同じ分類）。行は F1 と同じ作り（キーを左の列）。変えたキーは `--focus` の kbd と「既定: …」。衝突は確認のダイアログの前に行の中で知らせ、Enter で入れ替える |
| ニュース | 中身は今の `NewsSettings` のまま。枠と部品（スイッチ・ステッパー）だけ合わせる |
| このアプリについて | アプリの札（バージョン・新しいバージョンを確かめる）/ データとライセンス / 免責 |

- **探す**: 打つと全タブから当たる項目を、タブごとの枠に「タブ › 節」の札を付けて並べ、その場で変えられる（名前・説明・別名で当てる。§2 の照合）。
- **キー操作**: ↑ ↓ でタブ（今と同じ）、→ / Tab / Enter で本文へ。本文は**行ごとに** ↑ ↓ で選び（行の中のボタンを Tab で巡らない）、Space / Enter でスイッチ・ボタン、← → でセグメント・ステッパー・行の中のボタン、Backspace で既定に戻す、Esc でタブへ戻る（もう一度で閉じる）。FR-KB2。
- 項目の登録表 `lib/settingsSpec.ts`（`{ id, tab, section, label: Key, desc: Key, kind, alias?, dependsOn? }`）を作り、探す・既定に戻す・変えた数をこれで決める。`Settings` の項目がちょうど 1 回ずつ現れること・i18n のキーを L2 で確かめる。部品は `overlays/settings/`（`Row`・`Switch`・`Seg`・`Stepper`）。サインイン時の起動（Windows の登録が正）・保存期間（縮めるときの確認）・目標利回り（打った値の検証）は今の処理をそのまま呼ぶ。
- ほかのダイアログ（アラート・保有）のトグルも同じスイッチにそろえる（`app.css` の `.toggle` を置き換える）。

## 8. 決めたこと（2026-11-21）

1. 最近使ったものは**再起動をまたいで残す**（設定の `paletteRecent`）。
2. コマンドバーに**ペインの中のキーも出す**（Enter で F1 をその語で開く）。多すぎると感じたら範囲のチップの「すべて」から外す。
3. ショートカット一覧からは**実行しない**。探して見るだけにする（実行はコマンドバーと重なるため）。
4. 設定の項目を**タブの間で動かす**（行の高さ・表示倍率を「表示」へ、追加した銘柄を「データ」へ）。慣れた置き場所が変わるので、探す欄と合わせて入れる。
