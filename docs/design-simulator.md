# 配当シミュレータ（設計案）

スクリーニングで絞った銘柄群を**仮想の銘柄群**として、「N 年前に買っていたら今どうなっていたか」（過去）と「今買ったら配当はどれだけ入りそうか」（これから）を、手元の DB の価格と配当だけで計算して見せるペイン「配当シミュレータ」（`divsim`）の設計。
**インカム重視のこのアプリの差別化の柱**にする。

- モック: [mock/simulator.html](mock/simulator.html)（値はすべて架空。一つのファイルで動き、`file://` で開ける）
- 状態: **P1 を実装**（2026-11-18。要求は requirements.md §6.20 の FR-SIM1〜SIM9。設計・モックと違えたところは 21 章）
- 関連: スクリーナー（§5.2）・ポートフォリオ（[design-portfolio.md](design-portfolio.md)。実際の保有）・銘柄情報の業種の中央値（FR-I7）・配当込みの価格（FR-D2）

## 1. ねらい

スクリーナーは「今の条件に合う銘柄」を出す。その次に知りたいのは、次の問いである。

| 問い                                                         | シミュレータの答え                                                                      |
| ------------------------------------------------------------ | --------------------------------------------------------------------------------------- |
| この銘柄群を 3 年前に 300 万円買っていたら、今いくらか       | 評価額・含み損益（キャピタル）・受け取った配当（インカム）・トータルリターン            |
| それは市場（1306）や同じ業種の平均と比べて良かったのか       | 1306 と同業種の均等の群を同じルールで回した線と差                                       |
| 良かったのは業種のおかげか、銘柄選びのおかげか、運か         | 超過分の分解（滝）と、無作為に選んだ群との比較（何 % 点にいるか）                       |
| どの銘柄が効き、どの銘柄が足を引っ張ったか。業種の中で何番か | 銘柄ごとの寄与と、同業種の中の順位（「3/12」）                                          |
| 今買ったら、年にいくら・どの月に配当が入りそうか             | 年ごとの見込み（横ばい・伸びを見込む・帯）と、月ごとの配当                              |
| 2020 年のような年がまた来たら、どれだけ減るか                | 減配のストレス（DB にある最悪の年の前年比を当てる）と、1 銘柄が無配になったときの感応度 |

### 1.1 差別化の要点

ほかの「高配当シミュレータ」は、利回りと増配率を手で打つ電卓がほとんどである。このペインは次の点で違う。

1. **実データで、銘柄群のまま**: スクリーナーの結果をそのまま入れ、手元の DB の権利落ち日ごとの配当と、分割調整済みの価格で計算する。打つのは金額だけ。
2. **比べる相手が 2 つある**: 市場（1306・配当込み）と**同業種**。「業種の追い風」と「銘柄選び」を分けて見せる。
3. **正直さを画面の一部にする**: 後知恵（今日の条件で過去を測っている）・生存者・月次の精度・データの欠けを、隠れた注記ではなく「前提」のカードに常に並べる。数字には必ず、何を仮定した値かが付く。
4. **一点で言い切らない**: これからの配当は、横ばいの 1 本と減配のストレスの 1 本から始め、P2 で帯（10・50・90%）にする。直線の延長は「直線トレンド試算」と呼び、参考に下げる。
5. **キーボードで完結する業務画面**: ほかのペインと同じトークン・カードの作り・キーの意味（B・G・P・S）で、スクリーナー・チャート・銘柄情報とリンク色で連動する。

### 1.2 しないこと

- 「買い」「最適」などの判定・最適な配分の計算・リバランス・効率的フロンティア（§1.2 の投資助言に当たる）
- 試算した値を、スクリーナーの指標（`fields.ts`）や列に出すこと（予想配当を載せない方針と合わない）
- 実際の保有の評価（ポートフォリオの担当。保有はこれからの試算の入力にだけ使う）
- 当時のスクリーンの結果の再現（P2 の「当時の条件で選び直す」で、価格と配当だけから作り直せる指標に限って行う）

## 2. 用語

| 用語                   | 意味                                                                                                   |
| ---------------------- | ------------------------------------------------------------------------------------------------------ |
| 仮想の銘柄群           | シミュレータに入れた銘柄の集まり。保有ではない。画面では「仮想」と書き、ポートフォリオの用語を使わない |
| 基準日                 | 買ったとみなす日。今日の 1・3・5 年前（P2 で 10 年前と日付の指定）                                     |
| 元本                   | 基準日に入れた金額（積立は P2）                                                                        |
| 受け取った配当         | 基準日から今日までに権利落ちした配当の合計（税の扱いは設定どおり）。再投資したときは再投資の前の額     |
| 同業種の均等の群       | 選んだ銘柄と同じ業種の、ほかの銘柄を均等の金額で買い持ちした仮想の群（4 章）                           |
| 取得利回り（YOC）      | 直近 1 年の 1 株配当 ÷ 基準日の取得単価（再投資を含まない）                                            |
| 元本に対する配当利回り | 直近 1 年に受け取った配当 ÷ 元本（再投資で増えた株の分を含む）                                         |
| 試算                   | これからの配当の計算。過去の実績の機械的な延長で、予想ではない                                         |

## 4. 同業種との比較

目的は「その銘柄群が良かったのは、業種のおかげか、業種の中での銘柄選びのおかげか」を分けること。

### 4.1 同業種の均等の群の作り方

1. 選んだ銘柄ごとに、その銘柄の業種（33 業種。J-REIT はまとめて 1 つ）の**相手**を集める。
   - 相手のきまりは選んだ銘柄と同じ: 今上場している・基準日に価格と配当の記録がある・選んだ銘柄の市場区分と同じ（プライムの銘柄ならプライム）。`delisted` は入れない（選んだ側に入らないので）。
   - **選んだ銘柄自身は相手から外す**（小さな業種で差が縮むため）。
   - 相手が 5 銘柄未満なら **17 業種に自動で切り替える**（「17 業種で比較」と印）。それでも 5 未満なら、その銘柄は比較から外して件数を出す。
   - ETF・ETN・指数・業種の無い銘柄は比較から外す（件数を出す）。
2. 業種ごとに、相手を均等の金額で**買い持ち**した配当込みの推移（基準日 = 1）を作る。月次の騰落率の平均にはしない（毎月リバランスしたことになり、選んだ群と同じルールにならない）。
3. 選んだ銘柄 i に入れた金額 aᵢ で、その銘柄の業種の推移を買ったとみなす。同業種の群 = Σ aᵢ × 業種(i) の推移。**業種の構成比は基準日の金額で決まる**。
4. 配当の受け取り・再投資・税は、選んだ群と同じ設定で回す。
5. **比較できない銘柄（相手が足りない・ETF・業種の無い銘柄）があるときは、比較できた銘柄の構成比で元本の全額を配り直す**: 同業種の群 = 元本 × Σ wᵢ × 業種(i) の推移、wᵢ = aᵢ ÷ Σ（比較できた銘柄の aᵢ）。同業種の線は選んだ群と同じ元本から始まり、円の線も差も比べられる（比較できた分だけを足して元本より小さく始めない）。前提のカードと札に「同業種は 16/18 銘柄の業種の構成で比べています」と書く。偶然との比較・超過分の分解も同じ配り直しで回す。全部の銘柄が比較できないときは、同業種の線・差・順位を出さず「同業種と比べられる銘柄がありません」と書く

業種は今の業種（`sector_ja`）で、当時の業種ではないことを前提のカードに書く。

### 4.2 銘柄ごとの順位

- 銘柄ごとの表に、同業種の相手の中でのトータルリターンの順位を「3/12」の形で出す（パーセンタイルにしない。相手が少ない業種で誤解されるため）。
- P2 で、配当の伸び（5 年の年率）・取得利回りの順位を足す。今の値どうしの比較（実績利回りなど）は既存の `sectorStats`（`src/core/infoExtra.ts`）の作法をそろえる。

### 4.3 超過分の分解（P2）

1306 との差を、足すと一致する段に分ける。インカムとキャピタルに分けて積む（ポートフォリオの増減要因 FR-PF7 と同じ見せ方の滝）。

```
1306（時価総額加重） → 全銘柄の均等（規模の差） → 同業種の均等（業種の配分） → 選んだ群（業種の中の銘柄選び・参考）
```

- 「全銘柄の均等」は 1306 との差を規模（小型株の効果）として取り出すための群。母集団は同業種の相手と同じきまりにそろえる:

  | きまり     | 全銘柄の均等の群                                                                                                                    |
  | ---------- | ----------------------------------------------------------------------------------------------------------------------------------- |
  | 市場区分   | 選んだ銘柄の市場区分の和（プライムだけの群ならプライム。J-REIT を含めば J-REIT も）                                                 |
  | 入れる銘柄 | 今上場している・基準日に価格と配当の記録がある・業種がある銘柄。**選んだ銘柄も入れる**（市場全体の代わりなので）                    |
  | 外す銘柄   | ETF・ETN・指数・優先株と社債型種類株式（5 桁のコード）・業種の無い銘柄・`delisted`                                                  |
  | 重み       | 均等の金額で買い持ち（月ごとのリバランスはしない）                                                                                  |
  | 計算の量   | 業種ごとの推移のキャッシュ（10.1）を足し合わせるだけ。全業種を読むので、初回は同業種だけより重い（P2 なので P1 の目標には入れない） |
- **最後の段は「参考」**: 選んだ群は今日の条件（今の高利回り・連続増配）で選ばれており、結果を知って選んでいる。同業種の群にはその先読みがない。最後の段は「銘柄選びの効果の上限」と書く。

### 4.4 偶然との比較（P2）

- 選んだ銘柄ごとに、同じ業種の相手から 1 銘柄を無作為に選び、同じ銘柄数・同じ業種の構成の群を作る。これを 1,000 回回し、トータルリターンの分布の中で選んだ群が何 % 点にいるかを出す。
- 材料は 4.1 の銘柄ごとの推移（基準日 = 1）をそのまま使い回せるので、追加の読み出しは無い。
- 乱数の種は「基準日 + 銘柄群 + 設定」から決め、同じ入力なら同じ結果にする（テストできるように）。
- 「選び方に意味があったか、運の範囲か」を示すだけで、後知恵は消えない（同じ注記を付ける）。
- **順位であって、統計的な有意（検定）ではない**とカードに書く（「上から 5%」を「有意」と読まれないように）。

## 5. 計算のきまり

### 5.1 過去（バックテスト）

| 項目                       | きまり                                                                                                                                                                                                                                                    |
| -------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 今日                       | カレンダーの今日ではなく、**データの基準の日** = 終値のある最新の取引日（`metrics` の `as_of` と同じ。大引け前の場中なら前の取引日）。仮の足（FR-D8）はスクリーナーと同じく含め、見出しの基準の日に「仮」を付ける。チャート・ポートフォリオと同じ日になる |
| 基準日                     | 今日（上の行）の N 年前の同じ日以前の最後の取引日。日足の範囲より前なら、その月の月末の終値（「月次の精度」）                                                                                                                                             |
| 配分                       | 均等の金額（P1）。端株を認める（金額で買う）。**表の株数は小数で出す**（小数第 1 位）。利回り加重は P2、当時の単元（分割前の株数・2018 年 10 月より前の 1,000 株単元）は P3                                                                               |
| 買い値                     | 基準日の終値（分割調整済みのまま。株数も今の基準で数える）                                                                                                                                                                                                |
| 配当                       | 権利落ち日に、そのときの株数 × 1 株配当を受け取る。支払日は持たないので、再投資は少し早く使う分だけ有利に出る（前提のカードに書く）                                                                                                                       |
| 再投資                     | 税を引いた額で、権利落ち日の終値で同じ銘柄を買い増す（日足の範囲より前は、その月の月末の終値）。端株を認める                                                                                                                                              |
| 税                         | 税引前 ／ 20.315% ／ 非課税（P1。非課税は計算は税引前と同じで、名前と前提の文だけ違う。NISA の枠は見ない）。源泉徴収の概算で、配当控除・確定申告での還付・損益通算は見ない。含み益に譲渡益の税はかけない（「売ったときの手取り」は P2）                   |
| 基準日より後に上場した銘柄 | 外して、残りに配り直す（件数を出す）                                                                                                                                                                                                                      |
| データの欠け               | 配当の記録が基準日より後から始まる銘柄・基準日に価格が無い銘柄は、合計から外して印と件数を出す（FR-D9 と同じく、途中の値で埋めない）                                                                                                                      |
| 推移                       | 月次（月末の終値）にそろえる。選んだ群・1306・同業種の群・全銘柄の均等は同じ月の点で比べる。最後の点は今日（上）の終値                                                                                                                                    |
| 今日の終値が無い           | 取得に失敗して今日の終値が無い銘柄（基準の日より古い）は、最後の終値で評価し、表に「更新できていない」の印と日付を出す（FR-S13 と同じ）。外さない                                                                                                         |
| 減配の回数                 | 1 株配当の年の合計（直近 N 回の数え方）が前年を下回った回数。**記念配当・特別配当の剥落も含む**（区別するデータが無い）。列の説明（ツールチップ）と F1 に書く                                                                                             |
| 最大下落率                 | 日足の範囲の中だけで、配当込み。範囲より前を含むときは「日足の範囲で」と書く（月足で測ると小さく出るため）                                                                                                                                                |
| 年率                       | (評価額 + 受け取った配当（再投資しないとき）) ÷ 元本 の年率。基準日を「N 年前」で選んだときは、取引日の都合で 1 年にわずかに足りなくても出す（年数は N で数える）。1 年未満になるのは日付の指定（P2）だけで、そのときは出さない                           |
| 再投資の日に値が無い       | 権利落ち日に終値が無い銘柄（売買停止など）は、その前の最後の終値で再投資する                                                                                                                                                                              |
| 有効な銘柄が 0             | 基準日のきまりで全部の銘柄を外したときは、0 円と計算せず、過去のタブに「基準日（2021-11）に条件を満たす銘柄がありません。基準日を近くしてください」と外した理由の一覧を出す。これからのタブは計算する（下の 5.2）                                         |

配当込みの価格の計算は、チャートの「配当込み」と銘柄情報（FR-I7）の関数を使う（別に作らない）。

### 5.2 これから（試算）

1 年の配当 D は「直近 N 回の権利落ちの合計」（N は直近 2 年の回数から決める。FR-PF7 と同じ数え方）。最初の年と、今の終わっていない年は使わない。

| 方式                     | 優先度        | 式                                                                                                                                                                                                                                                                                                                                          |
| ------------------------ | ------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 横ばい（既定）           | P1            | Dₜ = D₀。J-REIT の D₀ は**権利落ちの回ごと**の金額の直近 4 回の中央値 × 年の回数（暦年の合計の中央値ではない。売却益による一時的な増配をならす。FR-I5）                                                                                                                                                                                     |
| 減配のストレス           | P1            | **市場全体で固定した最悪の年** y（下の 5.2.1）の、各銘柄の前年比 r を D₀ に当てる: 1 年目 = D₀ × min(1, r)、以降は横ばい。r が無ければ 17 業種の中央値、それも無ければ y 年の全銘柄の中央値                                                                                                                                                 |
| 伸びを見込む             | P1（M。21.9） | gᵢ = ln Dₜ の年次の系列の Theil–Sen の傾き。w = n/(n+5) で 17 業種の中央値に寄せ、±10% で打ち切る。伸びは毎年 0.8 倍ずつ弱める: Dₜ = D₀·exp(g·Σ_{s=1..t} 0.8ˢ)                                                                                                                                                                              |
| 直線トレンド試算（参考） | P2            | Excel の FORECAST.LINEAR と同じ最小二乗の直線。予測区間 ŷ ± t(n−2)·s·√(1 + 1/n + (x₀−x̄)²/Sxx) を付け、0 で下限を切る                                                                                                                                                                                                                        |
| 帯（10・50・90%）        | P2            | 暦年を 1 つ引き、その年の各銘柄の前年比（無ければ 17 業種の中央値）を全銘柄に同時に当てる（年ごとに引く。2020 年のような一斉の減配を残す）。対数の前年比から全期間・全銘柄の平均（1 つの定数）を引いて伸びを除き（年ごとの中央値は引かない。一斉の減配が消えるため）、帯の 50% 点が選んだ方式の線に重なるように合わせる。1,000 回・種は固定 |

- **これからの段の銘柄は、過去の基準日のきまりと切り離す**: 今上場していて今日の終値がある出どころの銘柄をすべて入れ、元本を均等に配る（基準日より後に上場した銘柄も入る）。過去の段で外した銘柄も、これからの段には出る。
- 記録が 4 年に満たない銘柄・無配の銘柄は横ばいだけにし、「期間不足」と出す（伸びは見込まない）。
- **配当の合計が 0 のときの割合**: 出どころの全銘柄が無配などで 1 年目の配当の合計が 0 円のときは、割合（月ごとの偏り・感応度の %・元本に対する利回り）を 0 で割らずに「—」とし、月ごとの配当には「配当のある月: 0/12」と出す。ストレスの年との差（÷ 横ばいの 1 年目）・帯の中央へのそろえ（÷ 50% 点）も同じく、分母が 0 なら「—」・帯は 0 にする。純関数の側で 0 を確かめる（画面で NaN を出さない）
- **前の年か今年の 1 株配当が 0 の年は、伸び・前年比の系列から除く**（対数・比が発散するため。無配から復配した年を含む）。除いた結果、点が 4 未満なら期間不足で横ばい。直近 1 年が 0 の銘柄（無配）は D₀ = 0 で、これからの配当は 0 として表に出す（外さない）。ストレスの年の前年比も、前の年が 0 の銘柄は使わない（17 業種の値で代える）
- 直近 10 年は日本株の増配が強かった時期なので、伸びと帯は上に偏りうると前提のカードに書く。
- **元本回収の目安**（P2）: 受け取る配当の累計（選んだ方式の中央の線）が元本の 50%・100% に届く年。試算の期間（既定 20 年、最長 30 年。21.17）に届かなければ「30 年以内には届かない」と書く。
- **月ごとの配当**: D₀ を、直近 1 年の権利落ちの**回ごとの実績の比**で月に配る（中間 30%・期末 70% のような偏りをそのまま出す。均等割りしない）。月は権利確定月、受取月の目安（+3 か月）に切り替えられる。J-REIT は D₀ をならしているので、回ごとの比は直近 4 回の比の中央値。

#### 5.2.1 ストレスの年の決め方と、欠けた年の扱い

- **ストレスの年は市場全体で 1 つに固定する**（選んだ銘柄群によって変えない。出どころを替えてもストレスの年が同じなので、群どうしを同じシナリオで比べられる）。
- 年 y の市場の前年比 = Σ(y 年の 1 株配当の年合計) ÷ Σ(y−1 年の同じもの)。足すのは「y−1 年と y 年の両方に、まる 1 年分の記録がある銘柄」だけ（記録の始まりの年・上場した年・今年は使わない）。母集団は全銘柄の均等の群（4.3）と同じきまり（ETF などを除く）。
- その年に両方の記録がある銘柄が、その時点の母集団の 50% に満たない年は候補にしない（古い年で記録が薄いときに、偏った年を選ばないため）。
- 候補の年のうち、前年比がいちばん低い年を y とする（同じなら新しい年）。データの取り直しで変わりうるので、前提のカードに年を書く（例「2020 年の前年比（市場全体 −8.1%）を当てています」）。
- 銘柄ごとの r は、その銘柄が y−1 年と y 年の両方に記録があるときだけ実績を使う。無ければ 17 業種の中央値（同じく両方の年に記録がある銘柄から）、それも無ければ市場全体の中央値。上場が y より後の銘柄は、こうして当てた値であることを表の印（「業種の値」）で示す。
- **直近の実績にさらに当てる**: すでに減配した直後の銘柄にも、D₀（減配後）に最悪の年の前年比を当てる（二重に減る）。保守の側に倒した仮定として前提のカードに書く。
- 伸びを見込む方式・帯の前年比の系列も同じきまりで欠けを扱う（両方の年に記録がある年だけを点にする。点が 4 未満なら期間不足で横ばい）。

## 7. ペインの構成

### 7.1 見出し

- ペイン名「配当シミュレータ」・リンク色・出どころの札（例「今のスクリーナー: 高配当銘柄 · 24 銘柄」）・前提の札（6 章）・段のタブ（過去 ／ これから）・基準の日。
- **見出しは 2 段にする**（アプリの `PaneHeader` は右端に操作のボタン（⋯・分割・ペインの種類・ドロワーへ・最大化・閉じる）を持ち、中身の `.body` は `overflow: hidden` で切られるため）:
  - 1 段目（`PaneHeader` の中身）: リンク色・ペイン名・「仮想」・出どころの札・前提の札・基準の日。ここには操作の要になるものを置かない（ボタンに押されて切れても困らないものだけ）。
  - 2 段目（ペインの中の帯）: 左に**段のタブ（過去 ／ これから）**、右に文で読める設定の帯。タブは縮めない。帯が入らない幅では、帯だけが次の行へ折り返す。
- **狭い幅で大事なものを切らさない**: 1 段目のうち、前提の札・リンク色・ペイン名は縮めない（`flex: none`）。出どころの札だけを縮めて「…」で省く。ペインの幅が 700px 未満では基準の日と「仮想」の札を隠す（基準の日は前提のカードにも出す）。
- **過去とこれからはタブで切り替える**（どちらか一方だけを出す。PgUp・PgDn か押して切り替える）。縦に並べてスクロールで切り替えると、表を見ている途中で設定の帯が入れ替わって並びがずれるため。計算は両方を一度に済ませているので、切り替えでは計算し直さない（読み込み中も出さない）。
- その下に**設定の帯**（1 行）を**文で読める形**にする。変えられる語に点線の下線とキーを添え、押すかキーで次の値へ進める（ボタンの列にしない。何を仮定した計算かを、そのまま読めるように）:
  - 過去: 「[3 年前]に [300 万円]を [18 銘柄]へ均等に入れて、配当は[受け取る]・[税引後 20.315%]」＋右に「比べる [1306 と同業種] 業種 [33 業種]」
  - これから: 「今 [300 万円]を [18 銘柄]へ均等に入れたら、[10 年]を[横ばい]で試算・[税引後 20.315%]」
  - 「18 銘柄」は出どころのダイアログ（L）、「300 万円」は入力欄（A）を開く。帯は前提のカードと同じ値を出す。
- 設定の帯の Tab の順（実装）: 出どころ → 基準日 ／ 期間 → 元本 → 配分 → 配当 → 税 → 比べる相手 ／ 試算の方式 → 業種。ペインの中のカードを巡る Tab とは別で、帯にフォーカスがあるときだけ。

### 7.4 幅（L・M・S）

ポートフォリオと同じく、コンテナの幅で並びを変える。L（1,180px 以上）は 12 列の bento、M（760〜1,179px）は 6 列、S は 1 列で、表の列を減らす。グリッドの領域で決め、穴を作らない。

- 行の高さは最小だけを決める（L の 1 行目は `minmax(318px, auto)`）。文字が折り返してカードの中身が増えても切らない。
- カードの見出しは、右側の切り替え（セグメント・凡例）が入らない幅では 2 行に折り返す（`flex-wrap`）。切り替えを見えなくしない。
- 図の中の文字（線の右端の値・1 年目の値・「元本を回収」）は、重なるときはずらし、図の外へはみ出すときは内へ押し戻す。縦線に添える文字には地の色の下敷きを敷く。
- ツールチップは、十字線が図の右半分にあるときは十字線の左に出す（右端の値と重ねない）。
- ライトのテーマでは、金の棒（インカム）の薄い塗り（再投資で増えた分など）に細い輪郭を付ける。
- 読み込み中の箱は、ペインより広くならない（`max-width`）。

### 7.5 見た目

- 色・文字・余白は `app.css` のトークン。インカムは金（`--gold`）、キャピタルの増減は `--up` / `--down`、1306 は `--ind1`、同業種は `--ind2`、元本は `--text-3` の線。
- 大きな数字はヒーローの 2 つだけ。ほかは図を先に、数字は脇役（ポートフォリオと同じ方針）。
- カードの見出しに、何を見せているかの短い説明（「月末ごと · 右端に今の値」「税引後 · 右の軸は累計」）を薄く添える。分かりにくい指標（取得利回り・元本に対する配当利回り・減配の回数）には ⓘ を付け、定義をツールチップで出す。
- 段のタブ（過去 ／ これから）は見出しの中でいちばん目立つ操作にする（文字を一段大きく、選んだタブに下線）。
- 「仮想」の印: 見出しに小さな「仮想」の札を付け、ヒーローの数字の色は保有の色（口座の色）を使わない。保有と見間違えないため。
- アクセシビリティ（実装）: 段のタブは `role="tablist"`・`aria-selected`、カードは `role="group"` と名前（`aria-label`）、選んだカードは `aria-current`。表は一覧のペインと同じく `aria-selected` の行。ライトのテーマで金（インカム）と白地の差を確かめる（棒は輪郭を付けられるようにする）。

| 出し方           | `sim.run` が過去とこれからの両方の結果を 1 回で返し、そろってから全部のカードを一度に出す（260ms のフェード。動きを減らす設定では無し）                                                                                                                                                                                                                |
| 続けて変えたとき | 新しい要求を送り、古い要求の結果は捨てる（要求ごとに番号）。読み込み中のまま続ける                                                                                                                                                                                                                                                                     |
| 失敗したとき     | 読み込み中をやめ、本体に理由（「同業種のデータを読めませんでした」など）と「もう一度（F5）」を出す。前の結果は出さない                                                                                                                                                                                                                                 |
| 読み上げ         | 箱は `role="status"`。出し終えたら「計算しました」と知らせる                                                                                                                                                                                                                                                                                           |

- キャッシュ（10.1）が効いて速い 2 回目以降も、同じく読み込み中を出す（入力が変わったことを示すため）。
- 取得のジョブの間（日々の更新）は、データが変わるたびに計算し直すと何度も読み込み中になるので、取得の完了で 1 回だけ計算し直す。
- 取得の完了での計算し直しは読み込み中を出さない。前の結果を出したまま計算し、そろったら差し替える（ほかのペインも取得が終わると黙って書き換わるのに合わせた。21.14）。入力（銘柄・設定）が前の結果と同じかで見分ける（`showsLoading`）。

### 10.1 性能

- 月次の終値は、日足の範囲は日足の月末から、それより前は月次系列から作る（チャートの月足と同じ組み立て）。
- 同業種の群に要るのは、選んだ銘柄の業種の全銘柄の月次の終値と配当。最大でも約 2,000 銘柄 × 120 か月 = 24 万点で、1 回の SQL で読む。日足は読まない（最大下落率の選んだ銘柄だけ）。
- 業種ごとの推移（基準日 = 1 の銘柄ごとの配当込みの推移）は、キー（基準日・再投資・税・市場区分の組）でキャッシュし、取得の完了（`dataChanged`）で捨てる。
- 偶然との比較は、キャッシュした銘柄ごとの推移の終わりの値を足すだけ（1,000 回 × 銘柄数の足し算）。
- 目標: 24 銘柄・基準日 3 年・同業種あり で 400ms 以内（初回。はじめは 300ms、2026-11-18 に利用者の判断で緩めた）、キャッシュが効く設定の切り替え（R・X）は 100ms 以内。どちらも読み込み中（7.6）を出す前提で、この時間は「待たされた」と感じさせないための目安。Core は 1 スレッドなので、取得のジョブと重なったときの時間を実測する（13 章）。
- スクリーナーの結果の変化での計算し直しは 300ms 間引く。

## 13. 決めていないこと・実装の前に確かめること

2026-11-18 に見直した（P2 の実装の後）。

決めたこと:

- 200 銘柄で切るときの順: 出どころの `screener.run` が返す `ids` の順（条件の並べ替えの順）で切る（`SimData.run`）。結果表の画面での並べ替え（スクリーナーのペインの `pane.state`）は使わない。ペインの状態を Core に渡す経路を足すほどの差がないため。

- 「当時の条件で選び直す」で作り直せる指標: 実績利回り・連続増配・連続非減配（`RESCREEN_KEYS`）と、銘柄の属性・★・ウォッチリスト（今の値のまま）。PER・PBR・ROE などは当時の値を持たないので外して前提に名前を出す。廃止した銘柄が候補に入らない偏りは前提で知らせ、避けるのは利用者に任せる（利用者の判断）。

まだ決めていないこと:

- 取得のジョブと重なったときの初回の計算時間（Core は 1 スレッド）。実測していない。400ms を大きく超えるなら、計算を取得のジョブの合間に回すかを決める。
- 再投資の時期を「権利落ち日 + 約 3 か月の目安の月の月末」にする選択肢を足すか（今は権利落ち日。前提に書いている）。

## 22. 1 銘柄のシミュレーション（決定。2026-11-18。FR-SIM10）

### 22.1 対象（1 銘柄 ⇔ 群）

スクリーナー・ウォッチリストの結果表はいつも 1 行を選んでいる（リンク色の銘柄も必ず決まっている）ので、「選んでいるか」から自動では決められない。

| 対象           | 計算する銘柄                                                                           | 変わるきっかけ                                                                           |
| -------------- | -------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------- |
| 1 銘柄（既定） | 同じリンク色の銘柄（スクリーナーの結果の行・銘柄ジャンプ・ウォッチリストで選んだ銘柄） | リンク色の銘柄が変わったとき（↑↓ で続けて動かしたときに毎回計算しないよう 300ms 間引く） |
