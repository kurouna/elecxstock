ペインの種類を変える（Ctrl+Shift+N）見直し案

対象: 窓: 試す: 「マーケット」「株価ボード」「mtf」「はいとう」「ログ」 · コマンドバー · ショートカット一覧 · 設定

今との違い

  • 名前だけの縦の一覧（17 件）→ 線画の図・名前・説明のカードを、5 つの分類に（名前を読まずに形で選べる）
  • 今の種類に「いま」の札。選択はそこから始まる。同じ種類がこのタブにあれば「このタブに 1」
  • 打って絞り込む（名前・説明・別名・読み。「株価ボード」でヒートマップ、「MTF」でマルチ時間軸）
  • 下の段は「変えると何が起きるか」だけ（銘柄・リンクの引き継ぎと、ペインの設定が初期に戻ること）
  • フリー N で使えない種類は消さずに薄く。理由は下の段に
  • 分割（Ctrl+Shift+E / O）の続きで選ぶときも同じダイアログ

キー

← → ↑ ↓カードを選ぶ。打っている間は ← → が文字のカーソルなので、↑ ↓ で読む順に前後へ送る
Home End最初・最後のカード（検索欄が空のとき）
Enterその種類にする（今と同じなら何もしないで閉じる）
Esc打った語を消す → もう一度で閉じる
