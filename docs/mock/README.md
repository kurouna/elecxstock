# 画面モック

要求仕様（[../requirements.md](../requirements.md)）の画面デザインを決めるためのモック。`index.html` をブラウザか Electron で開く。

- データはすべて架空（`mock-data.js`）。銘柄名は実在だが、価格・配当・指標は乱数。
- フォントはモックだけ Google Fonts から読む（アプリでは同梱する）。
- `lightweight-charts.standalone.production.js` は TradingView Lightweight Charts 5.3.0（Apache-2.0。ライセンス全文は `lightweight-charts.LICENSE`）。

## アラートのモック（P3）

`alerts.html` はアラート（[../requirements.md](../requirements.md) §6.14・[../design-alerts.md](../design-alerts.md)）の画面のモック。チャートのライブラリを読むので、`py -m http.server` などで手元のサーバーから開く（`file://` では動かない）。

| 操作 | キー |
|---|---|
| アラートのポップアップを開く・閉じる（未読があれば履歴） | Ctrl+Alt+L・トップバーのベル / Esc |
| アラートを作る / 直す | Ctrl+Alt+A・Insert / E（ダイアログ: 条件の行で ← → が値・O が ≥ と ≤、Tab で鳴り方の行へ移り Space で切り替え、Ctrl+Enter で作る） |
| 有効と停止 / 消す / 元に戻す（10 秒以内） | Space / Delete / Ctrl+Z |
| 銘柄を開く（ポップアップを閉じてチャートに出す。銘柄ジャンプと同じ規則） | Enter |
| アラートと履歴の切り替え / 履歴を既読に / 成立中だけ | H / R / Ctrl+Shift+F |
| 更新して判定する（擬似。2 件が鳴る） | F5 |

`alerts.html#popup`・`#history`・`#dialog`・`#fired` で状態を指定できる（スクリーンショット用）。

## ポートフォリオのペインのモック

`portfolio.html` は保有をダッシュボードで見せるペイン（[../design-portfolio.md](../design-portfolio.md)）のモック。一つのファイルで動く（`file://` で開ける）。上の帯で幅（S・M・L）・テーマ・色の向き・動き・状態（記録 1 年半・記録 3 日・読み込み中・保有なし）を切り替える。下に「配当の分析」（ドーナツ・年間配当と見込みの推移・増減要因・分類ごとのアコーディオンの表）が続く（PgDn）。キーは Tab（カード）・Alt+1〜6（期間）・← →（十字線・表の開閉）・↑ ↓ PgUp PgDn（一覧）・P・B・E・G（分類）・H・T（寄与の期間）・S（並べ替え）・PgUp PgDn（概要 ／ 配当の分析）・F5（擬似の更新。変わった桁をめくる）・Enter。資産推移で ← → を押すと、ヒーロー・損益寄与・資産構成がその日の値に連動する。`#size=L&light&focus=c-hist&cross=330`・`#div&focus=c-dtab&open=REIT`・`#contrib=2` のようにハッシュで状態を決められる。状態ごとのスクリーンショットは `portfolio-shots/`。

## 配当シミュレータのペインのモック

`simulator.html` は配当シミュレータのペイン（[../design-simulator.md](../design-simulator.md)）のモック。一つのファイルで動く（`file://` で開ける）。上の帯で幅（S・M・L）・テーマ・色の向き・範囲（P2 までの構想 ／ P1 だけ）・状態（通常・計算中・銘柄なし・過去が 0 件）を切り替える。計算の入力（基準日・元本・受取と再投資・税・業種・試算の方式・期間・出どころ）を変えるたびに、読み込み中を最短 400ms 出してから全部を一度に出す（設計 7.6）。値は種つきの乱数で作り、計算（買い持ち・受取と再投資・税・同業種の均等の群・1306・偶然との比較・横ばいとストレス・年ごとに引く帯）はモックの中で実際に回している。キーは PgUp PgDn（過去 ／ これからのタブ）・Tab（カード）・Alt+1〜4（基準日 ／ 期間）・← →（十字線・月。Shift で 12 か月 ／ 5 年）・Home End・N（前提へ。見出しの札と同じ）・↑ ↓（表）・L（出どころ）・A（元本）・R（受取 ⇔ 再投資）・X（税）・B（比べる相手）・G（33 ⇔ 17 業種）・M（試算の方式）・P（円 ⇔ %）・V（受取の目安 ⇔ 権利確定月）・S（並べ替え）・Enter・Esc。`#fwd&focus=fcal`・`#p1&size=M&light`・`#base=2&reinvest&cross=110` のようにハッシュで状態を決められる。

## 株価ボードのペインのモック

`board.html` は株価ボード（[../design-quote-board.md](../design-quote-board.md)。要求 §6.21）のモック。今のヒートマップのペインに「ヒートマップ ⇔ カード」の切り替えを足したもので、既定はヒートマップ。東証のマーケットセンターの株価ボードに倣い、銘柄をカードで並べて一望する。一つのファイルで動く（`file://` で開ける）。

- 値は日足の終値と前日比（円・%）。見出しに「11/13(金)終値 / 前日比 11/12(木)終値」（狭いときは前半だけ）を狭くても残し、場中の値ではないことを示す。表示する値は指標の表（`metrics`）とマーケット一覧の東証の行にあるものだけ（始値・高値・安値・出来高は出さない）。為替は終値の概念が無く誤解を招くので出さない。
- 1 行目は指数のカード 3 枚（日経平均・TOPIX 連動ETF・東証REIT 連動ETF）を同じ大きさで並べる。その下に騰落の帯（選挙速報のように上昇の数を棒の左・下落の数を右に大きく、棒の下に変わらず・単純平均）。
- カードは銘柄名・終値・前日比（円と%）。コードは出さず、ツールチップと下の 2 行（選んだ銘柄。キーボードでも同じ値が読める）に出す。最新の日足が無い銘柄は薄くして日付を出す。
- 一覧の出どころは 時価総額 上位（株式 90・J-REIT 10）・★・保有・スクリーニング条件。見出しの名前は表示に合わせ、先頭の切り替えのボタンはアイコンだけ（名前はツールチップ）。ヒートマップは今のペインのまま（業種の中へ Enter・戻る Esc はモックでは省略）。
- キーは V（ヒートマップ ⇔ カード。ペインの右上のボタンでも）・← → ↑ ↓ PgUp PgDn Home End（選ぶ）・Ctrl+Shift+F（★のみ）。カードでは G / Shift+G・Ctrl+PgDn / Ctrl+PgUp（一覧）・S（並べ替え）・B（分類）・+ −（大きさ）・I（指数のカード）。ヒートマップでは P（期間）。F5 はアプリ全体の取得（モックでは次の営業日の日足が届く。光らせない）。
- 上の帯で表示・幅（S・M・L）・テーマ・色の向き・状態を切り替える。`#view=card`・`#view=card&size=S&light&src=hold&tile=1`・`#view=card&group=sector` のようにハッシュで状態を決められる。

## 銘柄情報ペインの見直しのモック

`info.html` は銘柄情報ペインの見直し案。上に今のアプリのスクリーンショット（`info-before/`。`node scripts/shot-info-sizes.mjs` で撮る）、下に新しい案を、同じ枠の大きさ（XS 360×640・S 520×520・M 760×460・L 1100×620・XL 1500×640）で並べる。上のボタンで銘柄（保有・アラートあり / REIT / 値が一部無い）を切り替えられる。`py -m http.server` などで開く（画像を読むため）。

## ニュースのペインのモック

`news.html` はニュースのペイン（[../design-news.md](../design-news.md)）のモック。一つのファイルで動く（`file://` で開ける）。上の帯で画面（マーケットのタブ・単体 S / M / L・設定・初回起動）・状態（通常・初回取得中・オフライン・一部失敗・未回答・切っている・管理者が停止）・言語・テーマ・密度を切り替える。マーケットのタブではニュースは左の列のランキングの下。日本語の表示でも Bloomberg（英語のまま・要約なし・© 表示）が既定でオン。翻訳の機能は無く、見出しをコピーして別のアプリで訳す。キーは ↑ ↓ PgUp PgDn Home End（選ぶ）・Enter（開く）・G / Shift+G・Ctrl+PgUp / PgDn（タブ）・/（絞り込み）・Ctrl+C（選んだ見出しをコピー）・Ctrl+Alt+C（表示中の見出しをまとめてコピー）・P（プレビュー）・R（確かめる）・N（設定）・F5（擬似の新着）。設定では ↑ ↓・Space・D。見出しと要約はすべて架空（出所の名前だけ実在）。

## スクリーニングの条件を選ぶダイアログのモック

`fields.html` は条件を選ぶダイアログの見直し案（分類のタブ・検索・説明・使用中と新しい指標の印）。今の画面は `fields-before/picker.png`、案のスクリーンショットは `fields-after/`。`#cat=income&sel=5`・`#q=保有` などで状態を指定できる。

## チャートの下の段（MACD・RSI）のモック

`indicators.html` はチャートの下の段（MACD・RSI）の見せ方の試作。A が今のアプリ、B〜F が案。チャートのライブラリを読むので、`py -m http.server` などで手元のサーバーから開く（`file://` では動かない）。値はすべて架空（種つきの乱数）。
