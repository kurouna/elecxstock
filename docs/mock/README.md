# 画面モック

要求仕様（[../requirements.md](../requirements.md)）の画面デザインを決めるためのモック。`index.html` をブラウザか Electron で開く。

- データはすべて架空（`mock-data.js`）。銘柄名は実在だが、価格・配当・指標は乱数。
- フォントはモックだけ Google Fonts から読む（アプリでは同梱する）。
- `lightweight-charts.standalone.production.js` は TradingView Lightweight Charts 5.3.0（Apache-2.0。ライセンス全文は `lightweight-charts.LICENSE`）。

## アラートのモック（P3）

`alerts.html` はアラート（[../requirements.md](../requirements.md) §6.14・[../design-alerts.md](../design-alerts.md)）の画面のモック。チャートのライブラリを読むので、`py -m http.server` などで手元のサーバーから開く（`file://` では動かない）。

| 操作 | キー |
|---|---|
| アラートのポップアップを開く・閉じる（未読があれば履歴） | Ctrl+Alt+L・トップバーのベル / Esc |
| アラートを作る / 直す | Ctrl+Alt+A・Insert / E（ダイアログ: 条件の行で ← → が値・O が ≥ と ≤、Tab で鳴り方の行へ移り Space で切り替え、Ctrl+Enter で作る） |
| 有効と停止 / 消す / 元に戻す（10 秒以内） | Space / Delete / Ctrl+Z |
| 銘柄を開く（ポップアップを閉じてチャートに出す。銘柄ジャンプと同じ規則） | Enter |
| アラートと履歴の切り替え / 履歴を既読に / 成立中だけ | H / R / Ctrl+Shift+F |
| 更新して判定する（擬似。2 件が鳴る） | F5 |

`alerts.html#popup`・`#history`・`#dialog`・`#fired` で状態を指定できる（スクリーンショット用）。

## パフォーマンス比較のペインのモック

`perf.html` は、基準日を 100 として複数の銘柄のその後の値動きを比べるペイン（`perf`。設計は [../design-perf.md](../design-perf.md)）のモック。一つのファイルで動く（ハッシュで状態を決めるときは `py -m http.server` などで開く）。

- 左上（幅 236px）は基準日（大きく。実際に 100 にした日）・その下に「〜 終わりの日」の 1 行・年初〜20 年前の札だけ。日付を押す（キーでは Enter）とカレンダーが開き、月と年を送って日を選ぶ（休場日は薄く、選べない範囲は消す。終わりの日には「今日」）。打った日と 100 にした日が違うとき（休場日・月足）だけ理由を 1 行出す。画面にキーの案内は出さない（キー操作はある）。基準日と終わりの日は逆転させない。
- 左下は銘柄の一覧（1 行に色・コード・短い名前・値と、行の右の「−」で外す。5 銘柄まで。色は足した順に銘柄に付け、並べ替え・非表示で塗り直さない。並びは終わりの日の値で決め、十字線を動かしても入れ替えない。選択は銘柄で持つ）と比べる相手（灰色で、色の枠を使わない。1306 は実線・1343 は破線）。**銘柄は銘柄ジャンプで足す**: 見出しの「＋」・Insert・数字キーでアプリの既存の銘柄ジャンプ（ここではまねて描く）が開き、候補の行の「＋ パフォーマンス比較」か Ctrl+Enter で足す（ウォッチリストに足すのと同じ口。Enter はリンク色のチャートに出す）。見出しの「取り込む」（I）でウォッチリスト・保有・スクリーニング条件の結果からまとめて置き換える。下に選んだ行の詳細を固定の高さで出す。
- 表し方（100 ⇔ %）・価格のみ ⇔ 配当込み・通常 ⇔ 対数はチャートの見出しの右。日足 ／ 月足は見出しの札（説明はツールチップ）。
- 右端の札は、いつも線の終点（終わりの日）の値で、名前と値を 1 つだけ（100 のときは指数、% のときは騰落率）。十字線（← →）の日の値は、一覧と、十字線の脇の値の順の小箱で読む。一覧にフォーカスすると選んだ線以外を薄くし、H で選んだ線だけ色を残す。
- 基準日が日足の保存期間より前なら、日足の前の月だけ月末の終値（月次）を使い、それより後は日足で継ぐ（横軸は時間に比例。継ぎ目に「ここから日足」）。月次の点は、その月の最終営業日が基準日以前の月から。見出しに「月次の精度 〜YYYY/MM」。配当込みで 10 年より前を含むときは「配当込みは YYYY/MM から」と注意を出す。基準日にデータの無い銘柄（基準日より後に上場）は一覧に「データなし」と出し、線を描かない。
- 画像の保存は既存の設定「チャートの画像の保存」（FR-C11。既定オフ）に相乗りする。オンのときだけ見出しのボタンと、チャートにフォーカスしたときの S が効き、保存する画像（題・基準日・価格の種類・出典の 1 行を描き足す）をプレビューで見せる。
- 第 2 段（上の帯の「P1 だけ」で隠せる）: 比較の組（K で今の基準日と銘柄を覚え、取り込みのダイアログから開く。メモリだけでアプリを閉じると消える）・詳細の年率と最大下落率・基準日の前も薄く描く（R）。
- 系列の色は 5 色（藍・橙・水色・赤紫・黄緑）。陽線の赤・陰線の青の色相を避け、dataviz の検証の道具で「全部の組」を、ダーク（地の色 #101318）とライト（#ffffff）のそれぞれで確かめた（色覚の型を模した差 ΔE ≥ 9.2・通常の差 ≥ 18.2・地の色に 3:1 以上）。ライトは同じ色相で明るさだけ合わせた。6 色以上では、赤・青に近い色を使わずに全部の組を通す組が見つからなかったため、上限を 5 銘柄にした。
- キー（画面には出さない）は Tab（基準日 → 一覧 → チャート）・Alt+1〜6（年初・1・3・5・10・20 年前）・P・T・L・H・B（比べる相手）・Insert か 1〜9（銘柄ジャンプ。Ctrl+Enter で足す・Enter でリンク色のチャートに出す）・I（取り込む）。基準日では ← → ↑ ↓ PgUp PgDn で日付を直接動かし、Enter・Space でカレンダー（← → 日・↑ ↓ 週・PgUp PgDn 月・Shift+PgUp PgDn 年・Home End 月の初め／終わり・数字で yyyymmdd・Enter で決める・Esc）。一覧では ↑ ↓・Space（表示）・Delete（外す）・S（並べ替え）・Enter（チャートへ）。チャートでは ← →（Shift で 1 か月）・Home End・Esc・S（画像）。
- 上の帯で幅（S・M・L）・テーマ・色の向き・保存期間（3 ／ 10 年）・画像の保存の設定・範囲・状態（通常・読み込み中・銘柄なし）・例（1〜4）を切り替える。`#ex=2&light&save&size=M`・`#ex=3&ret=10&total&log`・`#focus=list&cross=2025-06-30` のようにハッシュで状態を決められる。

## イベントスタディのペインのモック

`evstudy.html` は、条件が成り立った日のその後を全銘柄・全期間で数える研究用のペイン（`evstudy`。設計はまだない）のモック。一つのファイルで動く（`file://` でも開けるが、ハッシュで状態を決めるときは `py -m http.server` などで開く）。

- 左の列で出来事の条件（スクリーナーの `Condition` と同じ形。過去の日に作り直せる価格・出来高の指標だけを選べ、PER・PBR などは理由を付けて選べない）と測り方（対象・比べる相手・約定・間隔・期間）を決め、Ctrl+Enter で計算する。定義を変えると、前の結果は薄く残る。
- 本体には、要約の帯（件数・中央値・プラスになった割合・同じ日をまとめた t 値・偶然との比較・データのある銘柄）、出来事のあとの超過リターン（BHAR。−20〜+250 営業日・中央値と 25〜75%・10〜90% の帯・無作為の群）、何日後ごとの表、分布、分けて見る（年・業種・規模）、出来事の集中、出来事の一覧、前提を並べる。
- 試行の記録で、試した条件の数と「偶然でも 1 つは 95%点を超える確率」を出す（データの覗き見の目安）。
- 値は種つきの乱数で作った 90 銘柄 × 10 年の架空の日足で、条件の判定・BHAR・偶然との比較（200 回）・同じ日をまとめた t 値はモックの中で実際に計算している。
- キーは Tab（列・カード）・Ctrl+Enter（計算）・Ctrl+O（保存した条件）・E（定義。狭いときは引き出し）・U B L O Y（対象・相手・約定・間隔・期間）・Alt+1〜5（何日後）・← →（日。Shift で 10 日）・M（中央値 ⇔ 平均）・G（年 ⇔ 業種 ⇔ 規模）・S（並べ替え）・Enter（チャートへ / その行で絞る）・N（前提）・Esc。定義の列では ↑ ↓・← →（値）・O（≥ ⇔ ≤）・A（かつ ⇔ または）・F（指標）・Insert・Delete。
- 上の帯で幅（S・M・L）・テーマ・色の向き・範囲（P2 までの構想 ／ P1 だけ）・状態（通常・計算中・0 件・保存期間 3 年）・条件（1〜5 の例）を切り替える。`#size=M&light&preset=3&h=2&focus=ev`・`#state=short`・`#p1&cross=40` のようにハッシュで状態を決められる。

## 株価ボードのペインのモック

`board.html` は株価ボード（[../design-quote-board.md](../design-quote-board.md)。要求 §6.21）のモック。今のヒートマップのペインに「ヒートマップ ⇔ カード」の切り替えを足したもので、既定はヒートマップ。東証のマーケットセンターの株価ボードに倣い、銘柄をカードで並べて一望する。一つのファイルで動く（`file://` で開ける）。

- 値は日足の終値と前日比（円・%）。見出しに「11/13(金)終値 / 前日比 11/12(木)終値」（狭いときは前半だけ）を狭くても残し、場中の値ではないことを示す。表示する値は指標の表（`metrics`）とマーケット一覧の東証の行にあるものだけ（始値・高値・安値・出来高は出さない）。為替は終値の概念が無く誤解を招くので出さない。
- 1 行目は指数のカード 3 枚（日経平均・TOPIX 連動ETF・東証REIT 連動ETF）を同じ大きさで並べる。その下に騰落の帯（選挙速報のように上昇の数を棒の左・下落の数を右に大きく、棒の下に変わらず・単純平均）。
- カードは銘柄名・終値・前日比（円と%）。コードは出さず、ツールチップと下の 2 行（選んだ銘柄。キーボードでも同じ値が読める）に出す。最新の日足が無い銘柄は薄くして日付を出す。
- 一覧の出どころは 時価総額 上位（株式 90・J-REIT 10）・★・保有・スクリーニング条件。見出しの名前は表示に合わせ、先頭の切り替えのボタンはアイコンだけ（名前はツールチップ）。ヒートマップは今のペインのまま（業種の中へ Enter・戻る Esc はモックでは省略）。
- キーは V（ヒートマップ ⇔ カード。ペインの右上のボタンでも）・← → ↑ ↓ PgUp PgDn Home End（選ぶ）・Ctrl+Shift+F（★のみ）。カードでは G / Shift+G・Ctrl+PgDn / Ctrl+PgUp（一覧）・S（並べ替え）・B（分類）・+ −（大きさ）・I（指数のカード）。ヒートマップでは P（期間）。F5 はアプリ全体の取得（モックでは次の営業日の日足が届く。光らせない）。
- 上の帯で表示・幅（S・M・L）・テーマ・色の向き・状態を切り替える。`#view=card`・`#view=card&size=S&light&src=hold&tile=1`・`#view=card&group=sector` のようにハッシュで状態を決められる。

## ダイアログの見直しのモック

`palette.html`（コマンドバー Ctrl+K）・`shortcuts.html`（ショートカット一覧 F1）・`panetype.html`（ペインの種類を変える Ctrl+Shift+N）・`settings.html`（設定 Ctrl+,）は、[../design-dialogs.md](../design-dialogs.md) の見直し案のモック。一つのファイルで動く（`file://` で開ける）。見た目は `launcher.css`、照合（空白で分けた語の AND・ひらがな ⇔ カタカナ）とキーの表記は `launcher.js`、アクション・ペインの種類・ショートカット・架空の銘柄は `launcher-data.js` を共有する。各ページの上の帯でフォーカス中のペイン・テーマなどを切り替え、下に今との違いとキーの表を出す。`palette.html#q=保有`・`shortcuts.html#key=Ctrl+Shift+N`・`settings.html#tab=data` のようにハッシュで状態を決められる。

## 銘柄情報: 利回りの変化の内訳（info-yield.html）

`info-yield.html` は、銘柄情報の配当（分配金）の欄に「利回りの変化の内訳」を足す案のモック（設計は [../design-yield-breakdown.md](../design-yield-breakdown.md)）。一つのファイルで動く（`py -m http.server` などで開く）。値はすべて架空。

- 欄: N 年前（5 年 ⇔ 最長。N）から今までの利回りの変化を、目盛りの言葉（「← 利回りを下げた ｜ 押し上げた →」）と棒 3 本（1 株配当・株価・利回り。どれも利回りを押し上げた向きを右）で出す。
  一言（「主に株価が下がったため」「増配が株価の上昇を上回った」など。判定の言葉は使わない）と、配当と株価の平面の小さな図。今が無配なら「今は無配のため、内訳を出せません」。
  配当を途中で始めた・再開した銘柄は、12 か月の配当が 0 だった最後の月の 12 か月後から数える。
- 「i」: ポインタを載せるか ? で読み方のツールチップ（式・棒の向き・平面の向きの図・特別配当も含むこと）。
- V か小さな図を押すと、ペインの上に平面を広げる（横 = 1 株配当（直近 12 か月）・縦 = 株価の両対数。斜めの線は同じ利回り。← → で月を選ぶと、その月までの内訳を右に出す。右に常に「読み方」）。
  上の帯の「狭い（600×360）」では、V でペインを最大化してから開き、Esc で元の大きさに戻る。
- 例: 8951（価格の下落で利回りが上がった）・8058（増配より株価の上昇が大きい）・8002（今は無配）・9434（配当を途中で始めた。最長で見る）。
- モックとアプリの違い: 十字線はモックでは位置で持つ（アプリは月で持つ）。開いている間に最大化を戻したとき・ほかのペインを最大化したときに層を閉じる扱いと、層を開いたまま銘柄を替える（数字で銘柄ジャンプ）のはモックに無い。
- 先に作った単独のペインの案は `divprice.html`（銘柄情報に入れることにした）。
