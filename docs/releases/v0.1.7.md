# elecxstock 0.1.7（ベータ版 / Beta）

v0.1.6 からの変更点です。初回に取得する日足の保存期間の既定を 5 年から 3 年にし、初回の取得を軽くしました。/ Changes since v0.1.6: the default daily history fetched on first run is now 3 years instead of 5, making the first fetch lighter.

> **ご注意 / Notice**
>
> - 株価・配当などのデータは Yahoo Finance の非公式 API から取得しています。遅延・欠損・誤りがあり得ます。個人の利用の範囲でお使いいただき、取得したデータを再配布しないでください。/ Prices and dividends come from the unofficial Yahoo Finance API and may be delayed, missing or wrong. Use it for personal use only and do not redistribute the data.
> - 本アプリは投資助言ではありません。/ This app is not investment advice.
> - 保有・ウォッチリスト・アラート・資産推移の記録は `%APPDATA%\elecxstock\` に暗号化せずに保存します。BitLocker などのディスク暗号化を使い、このフォルダを共有や同期の場所に置かないでください。/ Holdings, watchlists, alerts and the asset history are stored unencrypted under `%APPDATA%\elecxstock\`; use disk encryption such as BitLocker and keep the folder out of shared or synced locations.

## 変わったこと / Changes

- 日足の保存期間の既定を **3 年** にしました（1〜10 年から選べるのは同じです）。初回の画面に「保存期間はあとから設定の『データ』でいつでも変更できます」と出すようにしました。すでに使っている方の設定（保存期間）は変わりません。/ The default daily history is now **3 years** (still selectable from 1 to 10). The first-run screen now notes that the period can be changed any time in Settings → Data. Existing installs keep their current setting.
- 保存期間の始まりに 31 日の余裕を足しました。3 年ちょうどでは営業日がわずかに足りず、3 年の騰落率・配当込みの騰落率・最大下落率が出ないためです。/ The retention window now starts 31 days earlier so that 3-year returns, total returns and max drawdown have enough trading days.
- 月足の長期表示（上場以来の月次系列）は今までどおりで、保存期間が短くても 60 か月移動平均などは描けます。/ Long-term monthly charts still use the separate monthly series, so 60-month averages draw even with a shorter daily history.

## インストール / Install

`elecxstock-0.1.7-setup.exe` をダウンロードして実行します（Windows 10/11、x64）。v0.1.6 の上に入れ直すと、データはそのまま残ります。/ Download and run `elecxstock-0.1.7-setup.exe` (Windows 10/11, x64). Installing over v0.1.6 keeps your data.

- コード署名をしていないため、初回は SmartScreen の警告が出ます（「詳細情報」→「実行」）。/ The installer is not code-signed, so SmartScreen warns on first run ("More info" → "Run anyway").
- macOS・Linux は未検証です。/ macOS and Linux are untested.
