# elecxstock 0.1.18（ベータ版 / Beta）

v0.1.17 からの変更点です。ポートフォリオのペインの見た目の不具合（見出しの重なり・表のはみ出し・グラフの欠け）を直しました。新しい機能はありません。/ Changes since v0.1.17: layout fixes for the portfolio pane (overlapping headings, tables running off the card, a cut-off chart). No new features.

> **ご注意 / Notice**
>
> - 株価・配当などのデータは Yahoo Finance の非公式 API から取得しています。遅延・欠損・誤りがあり得ます。個人の利用の範囲でお使いいただき、取得したデータを再配布しないでください。/ Prices and dividends come from the unofficial Yahoo Finance API and may be delayed, missing or wrong. Use it for personal use only and do not redistribute the data.
> - 本アプリは投資助言ではありません。株価ボードの値は日足の終値で、場中の値ではありません。/ This app is not investment advice. The quote cards show daily closing prices, not intraday prices.
> - 保有・ウォッチリスト・アラート・資産推移の記録・トレンドラインは `%APPDATA%\elecxstock\` に暗号化せずに保存します。BitLocker などのディスク暗号化を使い、このフォルダを共有や同期の場所に置かないでください。/ Holdings, watchlists, alerts, the asset history and trend lines are stored unencrypted under `%APPDATA%\elecxstock\`; use disk encryption such as BitLocker and keep the folder out of shared or synced locations.
> - ニュースの見出しは各配信元のものです。記事の利用は各配信元の規約に従ってください。/ Headlines belong to each source; use articles under each source's terms.

## 直したこと / Fixes

- **カードの見出しの重なり** / **Overlapping card headings**: フル HD の画面などで、資産構成の見出しが 2 行になり、下の「上位 5 銘柄」の行に重なっていました。見出しは 1 行に保ち、幅が足りないときは分類の切り替えを「業種 ▾」のボタン 1 つにたたみます（押すと次の分類）。十字線の日の印は、資産構成では集中度の行に、損益寄与では注記の日付に出します。配当シミュレータの見出しも重ならないようにしました。/ On Full HD screens the allocation heading wrapped and overlapped the stats row. Headings stay on one line; when narrow, the group switch folds into a single "Sector ▾" button (press to cycle). The crosshair-day marker moved to the stats row and to the contribution note. Dividend simulator headings no longer overlap either.
- **表のはみ出し** / **Tables running off the card**: 分類ごとの資産と配当の表は、ペインの幅ではなく表の幅で列を出し分けます。ペインが約 1180px のときや、M の幅で右の列が切れていました。/ The asset table and the dividend table choose their columns by their own width instead of the pane width; right-hand columns were cut off at around 1180px and at medium widths.
- **配当の内訳のドーナツ** / **Dividend donut**: ペインを狭くすると、ドーナツが一部しか出ていませんでした。/ The donut was cut off when the pane was narrow.
- **十字線の日の高さ** / **Height on the crosshair day**: 資産推移で十字線の日を動かすと、評価額の数字が 2 行になったり、今日の要約が消えたりして、下のカードがずれていました。数字はカードの幅に合わせた大きさで 1 行に収め、今日の要約は場所を取ったまま隠します。/ Moving the crosshair day could wrap the total value onto two lines or remove today's summary, shifting the cards below; the value now fits on one line and the summary keeps its space while hidden.
- **資産推移** / **Asset history**: 記録があると、L の幅でキーの案内がカードの下からはみ出していました。/ With records, the key hints overflowed the history card at large widths.
- 英語の損益寄与の期間 "Since buy" を "All" にしました。/ The contribution period "Since buy" is now "All".

## 連携するツールの方へ / For tools that read the data

- DB の表・利用者のデータの JSON の形・`STORE_VERSION` は変わっていません。/ The database tables, the user-data JSON and `STORE_VERSION` are unchanged.
- `src/renderer/lib/folio.ts` に `contribNoteDay` を足しました。/ `src/renderer/lib/folio.ts` gains `contribNoteDay`.

## インストール / Install

`elecxstock-0.1.18-setup.exe` をダウンロードして実行します（Windows 10/11、x64）。v0.1.17 の上に入れ直すと、データはそのまま残ります。/ Download and run `elecxstock-0.1.18-setup.exe` (Windows 10/11, x64). Installing over v0.1.17 keeps your data.

- コード署名をしていないため、初回は SmartScreen の警告が出ます（「詳細情報」→「実行」）。/ The installer is not code-signed, so SmartScreen warns on first run ("More info" → "Run anyway").
- 通信先は前の版と同じです。/ The app connects to the same hosts as before.
- macOS・Linux は未検証です。/ macOS and Linux are untested.
