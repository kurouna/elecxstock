# elecxstock 0.1.13（ベータ版 / Beta）

v0.1.12 からの変更点です。**配当シミュレータ**のペインを足しました。銘柄情報から Yahoo Finance の銘柄のページを開けるようにし、ポートフォリオの配当の表を見やすくしました。/ Changes since v0.1.12: a new **dividend simulator** pane, a link from symbol info to the stock's Yahoo Finance page, and a tidier dividend table in the portfolio.

> **ご注意 / Notice**
>
> - 株価・配当などのデータは Yahoo Finance の非公式 API から取得しています。遅延・欠損・誤りがあり得ます。個人の利用の範囲でお使いいただき、取得したデータを再配布しないでください。/ Prices and dividends come from the unofficial Yahoo Finance API and may be delayed, missing or wrong. Use it for personal use only and do not redistribute the data.
> - 本アプリは投資助言ではありません。配当シミュレータの値はすべて過去のデータからの試算で、将来の結果を約束するものではありません。/ This app is not investment advice. The dividend simulator only shows estimates from past data and promises nothing about the future.
> - 保有・ウォッチリスト・アラート・資産推移の記録・トレンドラインは `%APPDATA%\elecxstock\` に暗号化せずに保存します。BitLocker などのディスク暗号化を使い、このフォルダを共有や同期の場所に置かないでください。/ Holdings, watchlists, alerts, the asset history and trend lines are stored unencrypted under `%APPDATA%\elecxstock\`; use disk encryption such as BitLocker and keep the folder out of shared or synced locations.
> - ニュースの見出しは各配信元のものです。記事の利用は各配信元の規約に従ってください（多くの配信元は個人の非商用の利用に限っています）。/ Headlines belong to each source; use articles under each source's terms (most allow personal, non-commercial use only).

## 変わったこと / Changes

- **配当シミュレータ**（新しいペイン）: 1 銘柄、またはスクリーナーの結果・保存したスクリーニング条件・ウォッチリスト・保有の銘柄群について、次の 2 つを試算します。/ **Dividend simulator** (new pane): for one stock, or a group from the screener results, a saved screen, a watchlist or your holdings, it estimates:
  - **過去**: 1・3・5・10 年前（または日付）に買っていたら今いくらか。受取 ／ 再投資・税・積立・均等 ／ 利回りに比例した配分を選べます。TOPIX（1306 NEXT FUNDS TOPIX 連動型上場投信）と同業種の均等の群と比べ、超過分を規模・業種・銘柄選びに分けます。/ **Past**: what it would be worth now if bought 1, 3, 5 or 10 years ago (or on a date), with cash or reinvested dividends, tax, regular investing and equal or yield-weighted allocation. It compares with TOPIX (the 1306 ETF) and an equal-weight group from the same sectors, and splits the difference into size, sector and stock selection.
  - **これから**: N 年の配当の見込み（横ばい・伸びを見込む・直線トレンド試算、減配シナリオ、10〜90% の帯）。/ **Ahead**: the dividend outlook for N years (flat, growth or linear-trend estimates, a dividend-cut scenario and a 10–90% band).
  - スクリーナーと保有のタブの初期のレイアウトに入っています。前の版から使っている方は、コマンドバー（Ctrl+K）の「このタブのレイアウトを初期状態に戻す…」で出すか、ペインの種類を「配当シミュレータ」に変えてください。キーは F1 の一覧にあります。/ It is part of the default Screener and Holdings tab layouts. If you are upgrading, use "Reset this tab's layout to preset…" in the command bar (Ctrl+K) or change a pane's type to "Dividend simulator". Its keys are in the shortcut list (F1).
- **銘柄情報から Yahoo Finance を開く**: 見出しの ⓘ の右のボタン（ペインの中では **O**）で、その銘柄のページを既定のブラウザで開きます。日本語の画面では Yahoo!ファイナンス、それ以外では Yahoo Finance です（指数には出しません）。/ **Open in Yahoo Finance from symbol info**: the button right of ⓘ in the header (or **O** in the pane) opens the stock's page in your browser — Yahoo!ファイナンス for the Japanese UI, Yahoo Finance otherwise (not shown for indices).
- **ポートフォリオの配当の表**: 「年間（税引後）」「前年比」「1 株配当（5 年）」の列で、棒を左、数字を右にそろえました。1 株配当の右端の棒は、金色をやめて増配 = 陽線の色・減配 = 陰線の色にしました（設定のローソク足の色に従います）。/ **Portfolio dividend table**: bars now line up on the left and numbers on the right in the annual, year-over-year and 5-year dividend-per-share columns. The last dividend-per-share bar uses the candle colors (up for a raise, down for a cut) instead of gold.

## インストール / Install

`elecxstock-0.1.13-setup.exe` をダウンロードして実行します（Windows 10/11、x64）。v0.1.12 の上に入れ直すと、データはそのまま残ります。/ Download and run `elecxstock-0.1.13-setup.exe` (Windows 10/11, x64). Installing over v0.1.12 keeps your data.

- コード署名をしていないため、初回は SmartScreen の警告が出ます（「詳細情報」→「実行」）。/ The installer is not code-signed, so SmartScreen warns on first run ("More info" → "Run anyway").
- 通信先は前の版と同じです。/ The app connects to the same hosts as before.
- macOS・Linux は未検証です。/ macOS and Linux are untested.
