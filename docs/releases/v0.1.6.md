# elecxstock 0.1.6（ベータ版 / Beta）

v0.1.5 からの変更点です。保有の金額と数量を隠す「プライバシーモード」を入れました。画面共有や録画のときに使えます。ほかに「このアプリについて」のリンクと、文言を直しました。/ Changes since v0.1.5: a new privacy mode hides holding amounts and quantities, handy for screen sharing and recording. The About page links and some wording are also fixed.

> **ご注意 / Notice**
>
> - 株価・配当などのデータは Yahoo Finance の非公式 API から取得しています。遅延・欠損・誤りがあり得ます。個人の利用の範囲でお使いいただき、取得したデータを再配布しないでください。/ Prices and dividends come from the unofficial Yahoo Finance API and may be delayed, missing or wrong. Use it for personal use only and do not redistribute the data.
> - 本アプリは投資助言ではありません。/ This app is not investment advice.
> - 保有・ウォッチリスト・アラート・資産推移の記録は `%APPDATA%\elecxstock\` に暗号化せずに保存します。BitLocker などのディスク暗号化を使い、このフォルダを共有や同期の場所に置かないでください。/ Holdings, watchlists, alerts and the asset history are stored unencrypted under `%APPDATA%\elecxstock\`; use disk encryption such as BitLocker and keep the folder out of shared or synced locations.

## 新しいこと / New

- **プライバシーモード**: トップバーの目のボタンか Ctrl+Shift+H で切り替えます。ポートフォリオ・保有のペイン・銘柄情報の保有欄で、資産の大きさが分かる値（評価額・取得額・損益額・配当額・口座ごとの額などの金額と、保有の数量）を `****` で隠します。損益率・構成比・利回りなどの % と、平均取得単価・株価は隠しません。NISA の枠のバーと配当の目標の達成率も、長さから額が分かるので隠します。設定に残るので、再起動してもオンのままです。フリーのウィンドウにも効きます（切り替えは 1 枚目のウィンドウで）。/ **Privacy mode**: toggle it with the eye button in the top bar or Ctrl+Shift+H. In the Portfolio, Holdings and Symbol info panes, amounts (value, cost, gains, dividends, per-account totals) and holding quantities show as `****`. Percentages, average cost and prices stay visible. The NISA allowance bar and the dividend-goal progress are hidden too, since their length reveals amounts. The setting persists across restarts and also applies to Free windows (toggle it from the main window).

## 変わったこと / Changes

- 設定の「このアプリについて」で、データ源の「Yahoo Finance」をリンクにしました（日本語の画面では Yahoo!ファイナンス、英語では Yahoo Finance を開きます）。Lightweight Charts の帰属表示は、`https://www.tradingview.com/` の文字をリンクにしました（初回の画面も同じ）。/ In Settings → About, "Yahoo Finance" is now a link (finance.yahoo.co.jp in Japanese, finance.yahoo.com in English), and the Lightweight Charts attribution links the `https://www.tradingview.com/` text itself (also on the first-run screen).
- ポートフォリオの「記録前の試算」のボタンに、何を計算しているかのツールチップを付けました。試算に使うのは最初に記録した日の保有なので、「現在の保有で」としていた説明を直しました。/ The Portfolio "Estimate before records" button now has a tooltip explaining the estimate. It uses the holdings on the first recorded day, so the old "current holdings" wording is corrected.
- 日本語の画面で「版」を「バージョン」に、「窓」を「ウィンドウ」にしました（「新しいバージョンを知らせる」など）。/ Japanese UI: 版 is now バージョン and 窓 is now ウィンドウ.

## インストール / Install

`elecxstock-0.1.6-setup.exe` をダウンロードして実行します（Windows 10/11、x64）。v0.1.5 の上に入れ直すと、データはそのまま残ります。/ Download and run `elecxstock-0.1.6-setup.exe` (Windows 10/11, x64). Installing over v0.1.5 keeps your data.

- コード署名をしていないため、初回は SmartScreen の警告が出ます（「詳細情報」→「実行」）。/ The installer is not code-signed, so SmartScreen warns on first run ("More info" → "Run anyway").
- macOS・Linux は未検証です。/ macOS and Linux are untested.
