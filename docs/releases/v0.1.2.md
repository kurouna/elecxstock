# elecxstock 0.1.2（ベータ版 / Beta）

v0.1.1 からの変更点です。保有の全体を見るポートフォリオのタブを足しました。資産推移を毎日記録し、資産構成・損益寄与・配当の分析を 1 つのタブにまとめています。/ Changes since v0.1.1: a new Portfolio tab records your asset history every day and brings allocation, contribution and dividend analysis together in one place.

> **ご注意 / Notice**
>
> - 株価・配当などのデータは Yahoo Finance の非公式 API から取得しています。遅延・欠損・誤りがあり得ます。個人の利用の範囲でお使いいただき、取得したデータを再配布しないでください。/ Prices and dividends come from the unofficial Yahoo Finance API and may be delayed, missing or wrong. Use it for personal use only and do not redistribute the data.
> - 本アプリは投資助言ではありません。/ This app is not investment advice.
> - 保有・ウォッチリスト・アラート・資産推移の記録は `%APPDATA%\elecxstock\` に暗号化せずに保存します。BitLocker などのディスク暗号化を使い、このフォルダを共有や同期の場所に置かないでください。/ Holdings, watchlists, alerts and the asset history are stored unencrypted under `%APPDATA%\elecxstock\`; use disk encryption such as BitLocker and keep the folder out of shared or synced locations.

## 新機能 / New

### ポートフォリオのタブ（Ctrl+Shift+9）/ Portfolio tab

- **概要** — 評価額（現金を除く）と今日の増減、含み損益・取得額・トータル損益（含み＋実現＋受取配当）・最高値から・前回の記録から・PER・β を上にまとめます。口座区分（NISA 成長投資枠・つみたて投資枠・旧 NISA・特定・一般）の構成比を円グラフで出し、真ん中に NISA の割合を出します。/ Overview: market value (excluding cash) and today's change, unrealized and total P/L (unrealized + realized + dividends received), drawdown from peak, change since the last record, P/E and beta, plus a ring chart of account types with the NISA share in the middle.
- **資産推移の記録** — 毎日の更新・初回の取り込み・保有を書いたときに、その日の評価額・取得額・保有の明細を記録します。期間の内訳（期首 → 入出金 → 評価損益の増減 → 期末）を出し、P で % 表示（時間加重の収益率の概算）、B で日経平均・TOPIX 連動 ETF（1306）と比べます。E で記録を始める前の推移を今の保有から試算して参考に出します。← → で日を動かすと、評価額・資産構成・損益寄与がその日の値になります。/ Asset history: each daily update, the first import and every holdings change record that day's value, cost and positions. See the period breakdown (start → deposits → valuation change → end), switch to % (approximate time-weighted return) with P, compare with the Nikkei 225 or the TOPIX ETF (1306) with B, and estimate the time before recording from today's holdings with E. Moving the day with ← → shows that day's value, allocation and contribution.
- **資産構成と損益寄与** — 資産構成は業種・17 業種・口座・種別・銘柄で分けたツリーマップ（G で切り替え、色は含み損益率か前日比）と、集中度（最大保有比率・上位 5 銘柄・実効銘柄数）・景気敏感とディフェンシブの割合。損益寄与は今日・今月・今年・取得来（T で切り替え）。/ Allocation as a treemap by sector, TOPIX-17 sector, account, kind or stock (G switches; colored by unrealized P/L or daily change) with concentration figures; contribution for today, this month, this year or since purchase (T switches).
- **配当の分析（PgDn）** — 年間配当（税引後）と前年比、今後 12 か月の配当見込み（月ごと。← → で月を選ぶとその月の銘柄と額）、増減の要因（増配・減配・新規・買い増し・売却。足すと現在と一致）、配当の内訳（ドーナツ）と分類ごとの表（G で分類、S か列名で並べ替え、→ で開く）。NISA で非課税になった額も出します。/ Dividend analysis: annual dividends after tax with year-on-year change, a 12-month outlook by month, a waterfall of what changed (raises, cuts, new, added, sold), a breakdown donut and a grouped table (G groups, S or a column header sorts, → expands), plus the tax saved by NISA.
- 項目・行・タイルを選ぶ（クリックでも）と、同じリンク色のチャートと銘柄情報に出ます。選んだ銘柄は他のカードでも明るく残ります。/ Selecting an item, row or tile (by key or click) shows it on the chart and symbol info with the same link color, and highlights it across the other cards.

### レイアウト / Layouts

- プリセットのリンク色をタブの並びの順に振りました（マーケット 1・探して見比べるタブ 2・インカム 3・保有とポートフォリオ 4）。スクリーナーで選んだ銘柄が MTF などのチャートにも出ます。保存したレイアウトは変えません。/ Preset link colors now follow the tab order (Market 1, the explore and compare tabs 2, Income 3, Holdings and Portfolio 4), so a symbol picked in the screener also shows on the MTF charts. Saved layouts are unchanged.

## 直したこと / Fixes

- 取得で値が変わって並びが入れ替わっても、一覧（スクリーナー・ウォッチリスト・ランキング・保有・配当カレンダー・ヒートマップ・ポートフォリオ）で選んでいる銘柄が別の銘柄に変わらないようにしました。/ The selected row in lists (screener, watchlist, ranking, holdings, dividend calendar, heatmap, portfolio) stays on the same stock when a data update reorders the rows.
- データの更新のときに、一覧の行が一瞬入れ替わって跳ねていたのを直しました（指標は新しい値が届いてから置き換えます）。/ Rows no longer jump briefly during data updates; metrics are replaced only after the new values arrive.
- スクリーナーで条件・列を変えると選んでいる行が先頭に戻る、チャートで対数目盛りや調整を切り替えると ← でずらした表示が戻る、のを直しました。/ Editing screener conditions or columns no longer jumps the selection to the top, and toggling log scale or adjustment on a chart keeps the panned view.
- スクリーナー: 無効な条件があると「または」のまとまりがずれて条件が緩むことがあったのを直しました。% の指標どうしの相対条件は ± ポイントで指定します。表示している単位（pt・×）を付けて打った値も読みます。権利確定月が — や NaN になることがあったのを直しました。/ Screener: an invalid condition no longer loosens "or" groups; relative conditions between % fields use ± points; values typed with the shown units (pt, ×) are accepted; record months no longer show — or NaN.
- 開発版やテストの起動で、タスクバーにインストールした版が Electron と出ることがあったのを直しました。/ Development and test runs use a separate app ID, so the installed app no longer appears as Electron on the taskbar.

## 既知の問題 / Known issues

- 評価額のカードの「TOPIX」の前日比は、TOPIX 連動 ETF（1306）の前日比です（TOPIX そのものは取得できません）。次の版で「TOPIX ETF」と表示します。/ The "TOPIX" change on the value card is that of the TOPIX ETF (1306), as TOPIX itself is not available; the next version labels it "TOPIX ETF".

## インストール / Install

`elecxstock-0.1.2-setup.exe` をダウンロードして実行します（Windows 10/11、x64）。v0.1.1 の上に入れ直すと、データはそのまま残ります。/ Download and run `elecxstock-0.1.2-setup.exe` (Windows 10/11, x64). Installing over v0.1.1 keeps your data.

- コード署名をしていないため、初回は SmartScreen の警告が出ます（「詳細情報」→「実行」）。/ The installer is not code-signed, so SmartScreen warns on first run ("More info" → "Run anyway").
- ポートフォリオのタブは、保存してあるレイアウトにも 9 つ目のタブとして加わります。資産推移の記録は入れ直した日から始まります（それより前は E の試算で参考に出せます）。/ The Portfolio tab is added to saved layouts as the ninth tab. The asset history starts on the day you install; press E to estimate earlier dates from your current holdings.
- macOS・Linux は未検証です。/ macOS and Linux are untested.
