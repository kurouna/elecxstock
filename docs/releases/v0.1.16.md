# elecxstock 0.1.16（ベータ版 / Beta）

v0.1.15 からの変更点です。株価ボードの下の 2 行の表示と、画面の部品どうしで見た目が混ざっていた不具合を直し、Electron を更新しました。新しい機能はありません。/ Changes since v0.1.15: fixes for the quote cards' detail lines and for styles leaking between parts of the screen, plus an Electron update. No new features.

> **ご注意 / Notice**
>
> - 株価・配当などのデータは Yahoo Finance の非公式 API から取得しています。遅延・欠損・誤りがあり得ます。個人の利用の範囲でお使いいただき、取得したデータを再配布しないでください。/ Prices and dividends come from the unofficial Yahoo Finance API and may be delayed, missing or wrong. Use it for personal use only and do not redistribute the data.
> - 本アプリは投資助言ではありません。株価ボードの値は日足の終値で、場中の値ではありません。/ This app is not investment advice. The quote cards show daily closing prices, not intraday prices.
> - 保有・ウォッチリスト・アラート・資産推移の記録・トレンドラインは `%APPDATA%\elecxstock\` に暗号化せずに保存します。BitLocker などのディスク暗号化を使い、このフォルダを共有や同期の場所に置かないでください。/ Holdings, watchlists, alerts, the asset history and trend lines are stored unencrypted under `%APPDATA%\elecxstock\`; use disk encryption such as BitLocker and keep the folder out of shared or synced locations.
> - ニュースの見出しは各配信元のものです。記事の利用は各配信元の規約に従ってください。/ Headlines belong to each source; use articles under each source's terms.

## 直したこと / Fixes

- **株価ボード** / **Quote cards**: 下の 2 行（選んだ銘柄の詳しい値）が 1 行に横に並び、後ろが切れていました（v0.1.15 の既知の問題）。1 行目に銘柄・コード・市場と業種・終値・前日比、2 行目に前日終値・売買代金・52 週の安値と高値・時価総額・日付を出します。/ The two detail lines at the bottom sat side by side on one line and were cut off (known issue in v0.1.15). Line 1 now shows the name, code, market and sector, close and day change; line 2 the previous close, turnover, 52-week range, market cap and date.
- **見た目の混ざり** / **Styles leaking between parts**: ダイアログ用の見た目が、同じ名前の部品を使うペインにも当たっていました。条件を選ぶダイアログの検索欄の文字が大きすぎたのを直しました。ポートフォリオの配当の表・配当シミュレータの表は、見た目を変えずに一覧の表の見た目から切り離しました。/ Dialog styles also applied to panes using the same class names; the search box in the condition picker no longer uses an oversized font. The portfolio dividend table and the dividend simulator table keep their look but no longer depend on the list-table styles.

## そのほか / Other

- Electron を 45.4.1 に、Svelte を 5.58.1 に更新しました。/ Updated Electron to 45.4.1 and Svelte to 5.58.1.

## 連携するツールの方へ / For tools that read the data

- DB の表・利用者のデータの JSON の形・`STORE_VERSION` は変わっていません。/ The database tables, the user-data JSON and `STORE_VERSION` are unchanged.

## インストール / Install

`elecxstock-0.1.16-setup.exe` をダウンロードして実行します（Windows 10/11、x64）。v0.1.15 の上に入れ直すと、データはそのまま残ります。/ Download and run `elecxstock-0.1.16-setup.exe` (Windows 10/11, x64). Installing over v0.1.15 keeps your data.

- コード署名をしていないため、初回は SmartScreen の警告が出ます（「詳細情報」→「実行」）。/ The installer is not code-signed, so SmartScreen warns on first run ("More info" → "Run anyway").
- 通信先は前の版と同じです。/ The app connects to the same hosts as before.
- macOS・Linux は未検証です。/ macOS and Linux are untested.
