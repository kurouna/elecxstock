# elecxstock 0.1.19（ベータ版 / Beta）

v0.1.18 からの変更点です。基準日を 100 として複数の銘柄の値動きを 1 枚に重ねる「パフォーマンス比較」のペインを足しました。/ Changes since v0.1.18: a new "Performance comparison" pane that overlays several stocks rebased to 100 on a base date.

> **ご注意 / Notice**
>
> - 株価・配当などのデータは Yahoo Finance の非公式 API から取得しています。遅延・欠損・誤りがあり得ます。個人の利用の範囲でお使いいただき、取得したデータを再配布しないでください。/ Prices and dividends come from the unofficial Yahoo Finance API and may be delayed, missing or wrong. Use it for personal use only and do not redistribute the data.
> - 本アプリは投資助言ではありません。パフォーマンス比較は過去の値動きの比較で、将来の値動きを示すものではありません。/ This app is not investment advice. The performance comparison shows past prices and does not indicate future prices.
> - 保有・ウォッチリスト・アラート・資産推移の記録・トレンドラインは `%APPDATA%\elecxstock\` に暗号化せずに保存します。BitLocker などのディスク暗号化を使い、このフォルダを共有や同期の場所に置かないでください。/ Holdings, watchlists, alerts, the asset history and trend lines are stored unencrypted under `%APPDATA%\elecxstock\`; use disk encryption such as BitLocker and keep the folder out of shared or synced locations.
> - ニュースの見出しは各配信元のものです。記事の利用は各配信元の規約に従ってください。/ Headlines belong to each source; use articles under each source's terms.

## 新しいこと / New

- **パフォーマンス比較**（ペイン `perf`）/ **Performance comparison** (pane `perf`): 基準日の終値を 100 として、5 銘柄までのその後の値動きを 1 枚のチャートに重ねます。/ Rebases up to five stocks to 100 on a base date and overlays them on one chart.
  - 基準日は日付を押すか Enter で開くカレンダー、← → ↑ ↓ PgUp PgDn、年初・1・3・5・10・20 年前の札（Alt+1〜6）で選びます。休場日は直前の営業日にします。/ Pick the base date from a calendar (click the date or press Enter), with the arrow keys and PgUp/PgDn, or with the YTD / 1 / 3 / 5 / 10 / 20-year chips (Alt+1–6). Market holidays use the previous session.
  - 銘柄は「＋」・Insert・数字キーの銘柄ジャンプ（Enter でこのペインに足す）か、コマンドバーで足し、行の「−」・Delete で外します。ウォッチリスト・保有・スクリーニング条件の結果からまとめて取り込めます（I）。/ Add stocks with the symbol jump (＋, Insert or digits, then Enter) or the command bar, remove them with − or Delete, or import from a watchlist, holdings or a saved screen (I).
  - 比べる相手に TOPIX（1306）・東証REIT指数（1343）の連動 ETF を灰色の線で出せます（B）。/ Show the TOPIX (1306) and TSE REIT Index (1343) ETFs as grey benchmark lines (B).
  - 100 ⇔ 騰落率 %（P）、価格のみ ⇔ 配当込み（T）、通常 ⇔ 対数（L）。線の右端に名前と値の札、十字線（← →）の日の値は脇の小箱と一覧に出します。一覧で選んだ線を太くし（H で選んだ線だけ色）、Enter で同じリンク色のチャートに出します。/ 100 ⇔ % (P), price ⇔ with dividends (T), linear ⇔ log (L). Name and value labels at the line ends; the crosshair day's values (← →) in a box and the list. The selected line is emphasized (H colors only it), and Enter shows it in the chart with the same link color.
  - 日足の保存期間より前を基準日にすると、その前は月末の終値（月次）で継ぎ、「ここから日足」の印を出します。配当込みで配当の記録より前を含むときは注意を出します。/ Base dates before the daily range are joined with month-end closes, marked "daily from here". With dividends, a note shows where the dividend record starts.
  - 線の色は騰落の赤・青を避け、色覚の違いでも見分けやすい 5 色です。/ The five line colors avoid the up/down red and blue and stay distinguishable for color-vision differences.
  - 基準日・銘柄・表し方に名前を付けて覚えられます（K。今はアプリを閉じると消えます）。/ Remember the base date, stocks and display as a named set (K; forgotten when the app closes for now).
  - チャートの画像の保存（設定 > チャート。既定 OFF）にも対応しています。ファイル名は `elecxstock-perf-<基準日>-<終わりの日>.png`。/ Chart image saving (Settings > Charts, off by default) works here too, as `elecxstock-perf-<base>-<end>.png`.
- **「比較」のひな形** / **"Compare" shape**: マイレイアウトの新しいページと、フリーのウィンドウ（Ctrl+Alt+N）の初めの形に「比較」（パフォーマンス比較と日足のチャート。リンク 2）を足しました。ペインの種類を変える（Ctrl+Shift+N）からも置けます。/ New pages in Pages and free windows (Ctrl+Alt+N) can start from "Compare" (the performance pane with a daily chart, link 2). It can also be placed with Change pane type (Ctrl+Shift+N).

## 変わったこと / Changes

- 銘柄ジャンプとコマンドバーで銘柄を足す先を、フォーカス中のペインに聞くようにしました。ウォッチリストは今までどおり（Enter で表示、Ctrl+Enter でリストに足す）、パフォーマンス比較は Enter でも足します。/ The symbol jump and the command bar now ask the focused pane where to add a symbol. Watchlists work as before (Enter shows, Ctrl+Enter adds to the list); the performance pane also adds on Enter.

## 連携するツールの方へ / For tools that read the data

- DB の表・利用者のデータの JSON の形・`STORE_VERSION` は変わっていません。/ The database tables, the user-data JSON and `STORE_VERSION` are unchanged.
- `bars.get` の結果に `divFrom`（配当の記録の始まり）と `monthlyFetched`（月次系列を取ったか）を足しました。/ `bars.get` results gain `divFrom` (where the dividend record starts) and `monthlyFetched` (whether the monthly series has been fetched).

## インストール / Install

`elecxstock-0.1.19-setup.exe` をダウンロードして実行します（Windows 10/11、x64）。v0.1.18 の上に入れ直すと、データはそのまま残ります。/ Download and run `elecxstock-0.1.19-setup.exe` (Windows 10/11, x64). Installing over v0.1.18 keeps your data.

- コード署名をしていないため、初回は SmartScreen の警告が出ます（「詳細情報」→「実行」）。/ The installer is not code-signed, so SmartScreen warns on first run ("More info" → "Run anyway").
- 通信先は前の版と同じです。/ The app connects to the same hosts as before.
- macOS・Linux は未検証です。/ macOS and Linux are untested.
