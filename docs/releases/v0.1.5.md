# elecxstock 0.1.5（ベータ版 / Beta）

v0.1.4 からの変更点です。不具合の修正が中心です。製品版で「既定の条件を戻す」（Ctrl+Shift+R）が効かなかったこと、大引け後の当日の足が消えることがあったことを直しました。スクリーナーのタブの下のチャートは週足になりました。/ Changes since v0.1.4, mostly fixes: "restore defaults" (Ctrl+Shift+R) now works in the installed app, today's after-close bar is no longer lost, and the Screener tab's lower chart is now weekly.

> **ご注意 / Notice**
>
> - 株価・配当などのデータは Yahoo Finance の非公式 API から取得しています。遅延・欠損・誤りがあり得ます。個人の利用の範囲でお使いいただき、取得したデータを再配布しないでください。/ Prices and dividends come from the unofficial Yahoo Finance API and may be delayed, missing or wrong. Use it for personal use only and do not redistribute the data.
> - 本アプリは投資助言ではありません。/ This app is not investment advice.
> - 保有・ウォッチリスト・アラート・資産推移の記録は `%APPDATA%\elecxstock\` に暗号化せずに保存します。BitLocker などのディスク暗号化を使い、このフォルダを共有や同期の場所に置かないでください。/ Holdings, watchlists, alerts and the asset history are stored unencrypted under `%APPDATA%\elecxstock\`; use disk encryption such as BitLocker and keep the folder out of shared or synced locations.

## 変わったこと / Changes

- スクリーナーのタブ（Ctrl+Shift+2）の右のチャート 2 枚を、上は日足・下は週足にしました（どちらも日足で、同じチャートが 2 枚出ていました）。保存したレイアウトは変えません。新しい並びにするには、そのタブで「レイアウトを初期状態に戻す」を使うか、下のチャートで W を押してください。/ The Screener tab (Ctrl+Shift+2) now shows a daily chart above and a weekly chart below; both were daily before. Saved layouts are unchanged: reset the tab's layout, or press W on the lower chart.

## 直したこと / Fixes

- インストールした版で、スクリーニング条件の一覧（Ctrl+O）の Ctrl+Shift+R「既定の条件を戻す」が何もしなかったのを直しました。再読み込みを止めるための処理が、このキーを画面に届けていませんでした。再読み込みは引き続き無効です。/ In the installed app, Ctrl+Shift+R "restore defaults" in the screens list (Ctrl+O) did nothing, because the reload block also kept the key from the page. Reload stays disabled.
- 大引け後の更新で、気配から補った当日の足（「仮」）が、同じ更新で日足を取り直した銘柄では消え、翌日の更新まで当日の足が無いままになることがあったのを直しました。/ Today's provisional bar, filled from the quote after the close, was lost when the same update also re-fetched that stock's daily bars, leaving no bar for today until the next day.
- Yahoo が混み合ったとき（429・5xx）と、通信が切れたとき・戻ったときを、ログ（`%APPDATA%\elecxstock\logs`）に書くようにしました。/ Provider errors (429/5xx), going offline and coming back are now written to the log (`%APPDATA%\elecxstock\logs`).
- 同じミリ秒に続けて保存したとき、利用者のデータの世代（バックアップ）が上書きされて 1 つ減ることがあったのを直しました。/ Two saves within the same millisecond no longer overwrite each other's backup generation.
- テストの無かった要求 17 件にテストを付けました（日足の取り直しの幅・取得失敗の記録・銘柄名の正規化・権利確定月・書式・安全策など）。/ Tests now cover 17 more requirements, including the daily re-fetch window, failure records, name normalization, record months, formatting and the security settings.

## インストール / Install

`elecxstock-0.1.5-setup.exe` をダウンロードして実行します（Windows 10/11、x64）。v0.1.4 の上に入れ直すと、データはそのまま残ります。/ Download and run `elecxstock-0.1.5-setup.exe` (Windows 10/11, x64). Installing over v0.1.4 keeps your data.

- コード署名をしていないため、初回は SmartScreen の警告が出ます（「詳細情報」→「実行」）。/ The installer is not code-signed, so SmartScreen warns on first run ("More info" → "Run anyway").
- macOS・Linux は未検証です。/ macOS and Linux are untested.
