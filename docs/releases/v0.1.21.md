# elecxstock 0.1.21（ベータ版 / Beta）

v0.1.20 からの変更点です。株価ボードのカードの大きさを 7 段に広げ、設定画面の「全データを削除して取り直す」と「新しいバージョンを確かめる」の表示を直しました。/ Changes since v0.1.20: the quote board's cards now come in seven sizes, and the settings screen shows progress and results for "Delete all data and refetch" and "Check for a new version" properly.

> **ご注意 / Notice**
>
> - 株価・配当などのデータは Yahoo Finance の非公式 API から取得しています。遅延・欠損・誤りがあり得ます。個人の利用の範囲でお使いいただき、取得したデータを再配布しないでください。/ Prices and dividends come from the unofficial Yahoo Finance API and may be delayed, missing or wrong. Use it for personal use only and do not redistribute the data.
> - 本アプリは投資助言ではありません。/ This app is not investment advice.
> - 保有・ウォッチリスト・アラート・資産推移の記録・トレンドラインは `%APPDATA%\elecxstock\` に暗号化せずに保存します。BitLocker などのディスク暗号化を使い、このフォルダを共有や同期の場所に置かないでください。/ Holdings, watchlists, alerts, the asset history and trend lines are stored unencrypted under `%APPDATA%\elecxstock\`; use disk encryption such as BitLocker and keep the folder out of shared or synced locations.
> - ニュースの見出しは各配信元のものです。記事の利用は各配信元の規約に従ってください。/ Headlines belong to each source; use articles under each source's terms.

## 変わったこと / Changes

- **株価ボードのカードの大きさが 7 段になりました** / **Seven card sizes on the quote board**: これまでの 3 段の下に 1 段、上に 3 段を足しました（+ − で切り替え）。いちばん小さい段はより多くの銘柄を一度に並べ、大きい段は終値・銘柄名・前日比の文字も大きくして、離れた画面からも読めます。これまでの大きさはそのまま残ります。/ One smaller and three larger sizes join the previous three (switch with + and −). The smallest fits more symbols at once; the larger ones also enlarge the close, name and change so they read from across the room. Your current size is kept.
  - − ＋ のツールチップに今の段（「大きさ 3/7」）を出します。いちばん小さい・大きい段では、その方向のボタンを押せない見た目にします。/ The − and + tooltips show the current size ("Size 3/7"), and the button for a direction you cannot go further is greyed out.
  - 大きい段を狭いペインに置いても、カードがペインからはみ出さないようにしました。/ Large sizes no longer overflow narrow panes.

## 直したこと / Fixes

- 「全データを削除して取り直す」で、削除が終わるまでステータスバーに「全データを削除しています…」を出すようにしました。削除している間はボタンを押せない見た目にし、もう一度押しても確かめのダイアログを開きません。/ "Delete all data and refetch" now shows "Deleting all market data…" in the status bar until deletion finishes. The button is greyed out meanwhile and does not reopen the confirmation.
- 設定画面の「新しいバージョンを確かめる」の結果を、トーストではなくボタンの下に出すようにしました（ダイアログの暗転の向こうで見えにくかったため）。/ The result of "Check for a new version" in settings now appears under the button instead of in a toast hidden behind the dialog's dimming.
  - 通信に失敗したときに「最新のバージョンです」と出ていたのを直し、「新しいバージョンを確かめられませんでした」と出します。/ A failed check no longer says "You are on the latest version"; it says "Could not check for updates".
  - 確かめている間はボタンを押せない見た目にし、前に知ったダウンロードのページへのリンクを、食い違う結果の横に並べないようにしました。/ The button is greyed out while checking, and an earlier download link is no longer shown next to a result that contradicts it.
- ほかの知らせ（トースト）がダイアログの暗転の下に隠れていたのを直しました。/ Toasts are no longer hidden under a dialog's dimming.
- 押せない見た目のボタンや、一杯で足せない銘柄ジャンプ・コマンドバーの「＋」が、マウスを載せると明るくなっていたのを直しました。/ Greyed-out buttons, and the "+" for a full list in stock jump and the command bar, no longer light up on hover.

## 連携するツールの方へ / For tools that read the data

- DB の表・利用者のデータの JSON の形・`STORE_VERSION` は変わっていません。/ The database tables, the user-data JSON and `STORE_VERSION` are unchanged.
- レイアウトの株価ボードの状態 `qbSize` は 0〜6 の整数になりました（これまでは 1〜3。1〜3 の意味は同じ）。/ The quote board's layout state `qbSize` is now an integer from 0 to 6 (previously 1–3, which keep their meaning).

## インストール / Install

`elecxstock-0.1.21-setup.exe` をダウンロードして実行します（Windows 10/11、x64）。v0.1.20 の上に入れ直すと、データはそのまま残ります。/ Download and run `elecxstock-0.1.21-setup.exe` (Windows 10/11, x64). Installing over v0.1.20 keeps your data.

- コード署名をしていないため、初回は SmartScreen の警告が出ます（「詳細情報」→「実行」）。/ The installer is not code-signed, so SmartScreen warns on first run ("More info" → "Run anyway").
- 通信先は前の版と同じです。/ The app connects to the same hosts as before.
- macOS・Linux は未検証です。/ macOS and Linux are untested.
