# elecxstock 0.1.14（ベータ版 / Beta）

v0.1.13 からの変更点です。外部のコードレビューで見つかった不具合を中心に、配当シミュレータ・チャート・フリーのウィンドウ・データの保全まわりを直しました。新しい機能はありません。/ Changes since v0.1.13: bug fixes found in an external code review, mainly in the dividend simulator, charts, free windows and data safety. No new features.

> **ご注意 / Notice**
>
> - 株価・配当などのデータは Yahoo Finance の非公式 API から取得しています。遅延・欠損・誤りがあり得ます。個人の利用の範囲でお使いいただき、取得したデータを再配布しないでください。/ Prices and dividends come from the unofficial Yahoo Finance API and may be delayed, missing or wrong. Use it for personal use only and do not redistribute the data.
> - 本アプリは投資助言ではありません。配当シミュレータの値はすべて過去のデータからの試算で、将来の結果を約束するものではありません。/ This app is not investment advice. The dividend simulator only shows estimates from past data and promises nothing about the future.
> - 保有・ウォッチリスト・アラート・資産推移の記録・トレンドラインは `%APPDATA%\elecxstock\` に暗号化せずに保存します。BitLocker などのディスク暗号化を使い、このフォルダを共有や同期の場所に置かないでください。/ Holdings, watchlists, alerts, the asset history and trend lines are stored unencrypted under `%APPDATA%\elecxstock\`; use disk encryption such as BitLocker and keep the folder out of shared or synced locations.
> - ニュースの見出しは各配信元のものです。記事の利用は各配信元の規約に従ってください（多くの配信元は個人の非商用の利用に限っています）。/ Headlines belong to each source; use articles under each source's terms (most allow personal, non-commercial use only).

## 直したこと / Fixes

- **配当シミュレータ** / **Dividend simulator**
  - 利回りに比例した配分で無配の銘柄が混ざると、その銘柄が同業種の 1 位と出たり、「偶然との比較」が出なくなったりしていました。/ With yield-weighted allocation, a non-paying stock in the group was ranked first in its sector and the "compared with chance" card broke.
  - データの誤りと見られる値の飛ばし方を直しました（上に外れてすぐ戻る値も飛ばします）。/ Spikes that jump up and come straight back are now skipped as data errors, like downward ones.
  - プライバシーモードで、保有を出どころにしたときの目標の達成率も隠すようにしました。基準日に未来の日付を選べないようにし、図の右端の目盛りと終点の札が重ならないようにしました。シナリオ（K）をマウスでも開けるボタンを足しました。/ Privacy mode now also hides goal progress for holdings; future base dates can no longer be picked; axis labels no longer overlap the end label; a button opens scenarios (K) with the mouse.
- **チャート** / **Charts**
  - 一目均衡表の先の雲に十字線を置くと、チャートが止まることがありました。/ Hovering the future Ichimoku cloud could crash the chart.
  - 日足・週足・月足を切り替えたとき、前の時間軸の表示範囲を引き継いで、ずれた位置を出していました。/ Switching daily/weekly/monthly kept the previous range and showed the wrong place.
  - チャートグリッドで拡大している間の操作（F・Space・Delete・C・X、差し替え・外す・ページ送り）と、並べ替え（Alt+← →）を直しました。テーマやローソク足の色を変えたとき、グリッドとマーケットの小さなチャートを描き直すようにしました。/ Fixed actions while a chart-grid tile is zoomed (F, Space, Delete, C, X, replace, remove, paging) and reordering (Alt+← →); the grid and market mini charts now redraw when the theme or candle colors change.
  - トレンドラインを動かしたあと、十字線やドラッグの状態が残ることがありました。対数目盛りで ↑↓ で動かすと線の傾きが変わっていました。/ The crosshair or drag state could stay behind after moving a trend line, and ↑↓ on a log scale changed the line's slope.
- **フリーのウィンドウ（2〜4 枚目）** / **Free windows**: 銘柄ジャンプやコマンドバーのスクリーニング条件で、レイアウトが 1 枚目用のものに替わってしまうことがありました。利用者のデータを書く操作は、Core の側でも 1 枚目だけに絞りました。/ Jumping to a symbol or picking a saved screen from the command bar could replace the layout with the main window's; writes to your data are now limited to the main window in Core as well.
- **操作** / **Keyboard and focus**
  - 初回の確認を、Esc・Ctrl+K・トレイの「設定」・通知のクリックで同意せずに閉じられました。/ The first-run notice could be closed without agreeing via Esc, Ctrl+K, the tray's Settings or a notification.
  - ペインを最大化したままドロワーを開く・F6・Alt+矢印で移ると、最大化したペインの裏で操作していました。/ Opening a drawer, F6 or Alt+arrows while a pane was maximized acted behind it.
  - IME で変換を始めるキーを取り違えることがありました。ダイアログを閉じたあと、フォーカスをペインに戻すようにしました。狭いウィンドウ・大きな表示倍率でダイアログが見切れないようにしました。/ Keys that start IME composition are ignored; focus returns to the pane after closing a dialog; dialogs no longer get cut off in narrow windows or at large zoom.
- **一覧** / **Lists**: 並べ替え・★のみ表示・スクリーニング条件の切り替えで先頭に戻らないことがありました（そのとき ★ などの操作が、光っている行ではなく前の銘柄に効いていました）。CSV の権利確定月が最初の月だけになっていました。プライバシーモードで損益の符号が見えていました。丸めて 0 になる値に色が付いていました。/ Sorting, star-only and switching screens now go back to the top (and actions apply to the highlighted row); CSV now lists every record month; privacy mode no longer shows the sign of gains; values that round to zero are no longer colored.
- **アラート** / **Alerts**: EPS・BPS が 0 以下の銘柄で、条件までの距離と作るときの既定のしきい値がおかしくなっていました（距離は円の差で出します）。/ Distance and the default threshold were wrong for stocks with zero or negative EPS/BPS (the distance is now shown in yen).
- **データの保全** / **Data safety**: 壊れた settings.json（中身が null・数など）を既定値で読み、次の保存で上書きしていました（今は退避して読み取り専用で起動します）。読み取り専用のときに、取り込みの前の記録を消すことがありました。ファイルの保存・読み込みに失敗したとき、キャンセルと区別して知らせるようにしました。/ A broken settings.json (null, a number…) was read as defaults and overwritten on the next save — it is now set aside and the app starts read-only; read-only mode no longer deletes the pre-import backup; failed file saves and opens are now reported instead of looking like a cancel.
- **ニュース** / **News**: 取っている途中でオフにすると、残りのフィードが失敗として記録されていました。途中で切れたフィードで、前の見出しを空で上書きしていました。言語を切り替えたとき、ペインを出していなくても設定のフィードの一覧に反映されるようにしました。/ Turning news off mid-fetch recorded the remaining feeds as failures; a truncated feed wiped the previous headlines; changing the language now updates the feed list in Settings even when the pane is hidden.
- **その他** / **Other**: 終了がもっと確実になりました。2/29 を含む年の計算・月足の配当の調整・通信先の確かめ方（リダイレクトで資格情報を渡さない）を直しました。/ Quitting is more reliable; fixed date math around Feb 29, monthly dividend adjustment and redirect handling (no credentials sent to other origins).

## 連携するツールの方へ / For tools that read the data

- `src/shared/alerts.ts` の `distanceOf` が、金額の指標で今の値かしきい値が 0 以下のとき、新しい種類 `kind: 'yen'`（円の差）を返します（`AlertView['distance']['kind']` に `'yen'` を足しました）。率の指標は今までどおり `'pt'` です。/ `distanceOf` in `src/shared/alerts.ts` now returns a new `kind: 'yen'` (a yen difference) for money fields when the current value or the threshold is zero or below; rate fields still use `'pt'`.
- 指標の登録表: `risk.beta` の型を `number`（小数 2 桁）に、`holding.pnlPct` を符号つきにしました。スクリーナーは数でない値（NaN・Infinity）を欠損として扱います。/ Field registry: `risk.beta` is now type `number` (2 decimals) and `holding.pnlPct` is signed; the screener treats NaN and Infinity as missing.
- `jobs` 表の `status` に、リトライを待つ間 `'waiting-offline'`・`'provider-paused'` が入るようになりました（以前からある値です）。/ The `jobs.status` column now holds `'waiting-offline'` or `'provider-paused'` while waiting to retry (both existing values).
- DB の表・利用者のデータの JSON の形・`STORE_VERSION` は変わっていません。/ The database tables, the user-data JSON and `STORE_VERSION` are unchanged.

## インストール / Install

`elecxstock-0.1.14-setup.exe` をダウンロードして実行します（Windows 10/11、x64）。v0.1.13 の上に入れ直すと、データはそのまま残ります。/ Download and run `elecxstock-0.1.14-setup.exe` (Windows 10/11, x64). Installing over v0.1.13 keeps your data.

- コード署名をしていないため、初回は SmartScreen の警告が出ます（「詳細情報」→「実行」）。/ The installer is not code-signed, so SmartScreen warns on first run ("More info" → "Run anyway").
- 通信先は前の版と同じです。/ The app connects to the same hosts as before.
- macOS・Linux は未検証です。/ macOS and Linux are untested.
