# elecxstock 0.1.0（ベータ版 / Beta）

初めてのベータ版です。日本株と J-REIT のデータを手元の PC に取り込み、チャートを並べて見比べ、条件で絞り込むための主な機能がそろいました。
不具合や使いにくいところがあれば、[Issues](https://github.com/kurouna/elecxstock/issues) で知らせてください。/
This is the first beta. The main features for keeping Japanese equity and J-REIT data on your PC, comparing charts side by side and screening are in place.
Please report bugs and rough edges in [Issues](https://github.com/kurouna/elecxstock/issues).

以下は v0.0.5 からの変更点です（v0.0.6 はリリースの検査で止め、公開していません。その変更もこの版に入っています）。/
Changes since v0.0.5 follow (v0.0.6 was stopped at the release check and not published; its changes are included here).

## 新機能 / New

- **日々の更新で、ウォッチリストと保有の銘柄を先に更新** — 一括気配を指数 → ウォッチリストと保有の銘柄 → そのほかの順に取り、その銘柄の日足の取り直しもすぐに行います。更新を始めてすぐに、見ている銘柄の値が新しくなります。/ The daily update fetches quotes for indices, then your watchlist and holdings symbols, then the rest, and re-fetches their daily bars right away, so the symbols you watch are fresh first.
- **更新の最後に取りこぼしを確認** — 初回と日々の更新の最後に 1 回だけ、気配を取れなかった銘柄（バッチの失敗・応答に無い）と日足が欠けた銘柄を取り直します。/ At the end of the initial and daily updates, one final pass re-fetches quotes that failed or were missing and daily bars that are still missing.
- **スクリーナーの★のみ表示** — ほかの一覧と同じく Ctrl+Shift+F で、結果を★の銘柄だけにできます。/ Ctrl+Shift+F shows only ★ symbols in the screener results, as in other lists.
- **タイトルバーのボタンでフリーのウィンドウを開く** — Ctrl+Alt+N と同じです。/ A title-bar button opens a Free window, same as Ctrl+Alt+N.

## 改善 / Improvements

- 保有に入れたスタンダード・グロース・ETF の銘柄も、市場によらず取得します。保有のフォームで足しても、設定の「利用者の銘柄」には入れません。/ Standard, Growth and ETF symbols in your holdings are now fetched; adding them in the holding form no longer puts them into the user-instrument list.
- 狭いペインでも、見出しに閉じるボタンと銘柄名を必ず出します。入りきらない操作は「⋯」のメニューにまとめ、チャートは表示期間 → 指標 → D/W/M → 前日比 → 終値の順に省きます。/ Narrow pane headers always keep the close button and the symbol; other actions move into a "⋯" menu, and chart headers drop period, indicators, D/W/M, change and close in that order.
- 狭いフリーのウィンドウでも、タイトルバーの窓の名前が切れません。/ The Free window name in the title bar stays readable in narrow windows.
- リンク色を外した一覧（Ctrl+0）は、行を動かしてもチャートに銘柄を送りません。/ Lists unlinked with Ctrl+0 no longer drive charts.
- 保有フォームの銘柄の候補は、下の欄を押し下げずに重ねて出します。配当カレンダーは月の銘柄をすべて並べます。未保存の 3 択のダイアログは矢印キーで選べます。/ Holding-form candidates overlay the form instead of pushing it down; the dividend calendar lists every symbol of a month; the unsaved-changes dialog works with arrow keys.

## 修正 / Fixes

- 月足の「配当込み」で、日足の期間より前の月足が調整されず、境目に段差が出ていました。/ Monthly total-return charts no longer show a step where the monthly series meets the daily bars.
- 楽天証券の CSV で、5 桁のコード（優先株・種類株）を読み飛ばしていました。/ The Rakuten CSV import no longer skips five-character codes.
- 一括の取り込み・元に戻す・利用者の銘柄・保存期間・スクリーンの変更が、フリーのウィンドウに反映されていませんでした。/ Bulk import, undo, user instruments, retention and screen changes now reach Free windows.
- スクリーン一覧で末尾を消すと Enter が効かなくなっていました。/ Deleting the last screen in the list no longer breaks Enter.
- チャートグリッドの − / ＋ のボタンが、ラベルと逆の動きをしていました。/ The grid − / + buttons now match their labels and keys.
- 保有のフォームでコードを打ってすぐ Tab を押すと、打ち途中の候補（例: 130A のつもりが 1306）が選ばれることがありました。/ In the holding form, pressing Tab right after typing a code could pick a stale candidate (e.g. 1306 instead of 130A).
- 保有の書き出しとログのファイル名の日付を、日本時間にしました。/ Holdings export and log file names use the JST date.

## そのほか / Other

- 著作権者の表示を「elecxzy project」にしました。/ The copyright holder is now "elecxzy project".
- テスト・デモ・スクリーンショットのデータは、すべて実際の市場データと無関係な架空の値にしました。/ Test, demo and screenshot data are entirely fictitious and unrelated to real market data.
- 紹介動画用のデモ（`npm run demo`）を足しました。/ Added a keyboard-driven demo for the introduction video (`npm run demo`).

## インストール / Install

`elecxstock-0.1.0-setup.exe` をダウンロードして実行します（Windows 10/11、x64）。コード署名をしていないため、初回は SmartScreen の警告が出ます（「詳細情報」→「実行」）。データは残ったまま上書きで入れ直せます。/ Download and run `elecxstock-0.1.0-setup.exe` (Windows 10/11, x64). The installer is not code-signed, so SmartScreen warns on first run ("More info" → "Run anyway"). Installing over an older version keeps your data.
