# elecxstock 0.1.20（ベータ版 / Beta）

v0.1.19 からの変更点です。Yahoo へのリクエストの間隔を縮めて、初回の取得・数日空けたあとの更新を速くしました。為替・暗号資産に出ていた「！」（異常値の疑い）の誤りも直しました。/ Changes since v0.1.19: shorter request intervals to Yahoo make the first fetch and updates after a few days away faster, and the false "!" (suspected bad data) on FX and crypto is gone.

>
> - 株価・配当などのデータは Yahoo Finance の非公式 API から取得しています。遅延・欠損・誤りがあり得ます。個人の利用の範囲でお使いいただき、取得したデータを再配布しないでください。/ Prices and dividends come from the unofficial Yahoo Finance API and may be delayed, missing or wrong. Use it for personal use only and do not redistribute the data.
> - 本アプリは投資助言ではありません。/ This app is not investment advice.
> - 保有・ウォッチリスト・アラート・資産推移の記録・トレンドラインは `%APPDATA%\elecxstock\` に暗号化せずに保存します。BitLocker などのディスク暗号化を使い、このフォルダを共有や同期の場所に置かないでください。/ Holdings, watchlists, alerts, the asset history and trend lines are stored unencrypted under `%APPDATA%\elecxstock\`; use disk encryption such as BitLocker and keep the folder out of shared or synced locations.
> - ニュースの見出しは各配信元のものです。記事の利用は各配信元の規約に従ってください。/ Headlines belong to each source; use articles under each source's terms.

## 変わったこと / Changes

- **取得が速くなりました** / **Faster fetching**: Yahoo へのリクエストの間隔を 1.0 秒 + 0〜0.3 秒から 0.4 秒 + 0〜0.15 秒にしました（並列にはせず、1 件ずつ順に送ります）。初回の取得（日足）は約 35〜40 分から約 15 分に、数日アプリを起動しなかったあとの更新は約 40 分から約 15 分になります。/ The interval between Yahoo requests drops from 1.0 s + 0–0.3 s to 0.4 s + 0–0.15 s, still one request at a time. The first fetch (daily bars) takes about 15 minutes instead of 35–40, and an update after a few days away about 15 minutes instead of 40.
  - Yahoo から回数の制限（429）を受けたら、24 時間は前の間隔（1.0 秒 + 0〜0.3 秒）に戻します。/ After a rate-limit response (429) from Yahoo, the previous interval (1.0 s + 0–0.3 s) is used for 24 hours.
  - 初回の取得と「全データを削除して取り直す」の確認に出る所要時間を、この間隔から計算するようにしました。/ The time estimates in the first-run dialog and the "delete all and refetch" confirmation now follow these intervals.
- **TOPIX の代わりの ETF を 1306 から 1308 に替えました** / **The TOPIX proxy is now 1308 instead of 1306**: Yahoo の 1306 の日足は 2026-03-30 の分割の前後で調整が二重にかかっているため、分割の無い 1308 を使います（マーケット・ポートフォリオ・パフォーマンス比較・配当シミュレータの比べる相手）。/ Yahoo's 1306 daily bars are adjusted twice around the 2026-03-30 split, so the split-free 1308 is used instead (market board, portfolio, performance comparison and dividend simulator benchmarks).

## 直したこと / Fixes

- ドル/円・ユーロ/円・ビットコイン/円に「！」（異常値の疑い）が出ていたのを直しました。Yahoo の 24 時間の市場の日足は、終値が高値・安値のわずかに外になることがあり、取り直しても変わりません。為替・暗号資産・海外の指数では、終値 0 以下と出来高が負だけを異常値として見ます。**次の更新（F5）で「！」が消えます**。/ Fixed a false "!" (suspected bad data) on USD/JPY, EUR/JPY and BTC/JPY. Yahoo's daily bars for 24-hour markets can close slightly outside the high–low range, and refetching does not change that. For FX, crypto and overseas indexes only a zero or negative close and a negative volume count as bad data. **The "!" disappears on the next update (F5).**
- 「！」の説明に、取り直しの実際の操作（Shift+F5 か、コマンドバー（Ctrl+K）の「選択銘柄を取り直す」）を出すようにしました。キーの割り当てを変えていれば、そのキーを出します。/ The "!" tooltip now names the actual way to refetch (Shift+F5 or "Refetch the selected symbol" in the command bar, Ctrl+K), following your key assignments.
- コマンドバーで「取り直し」「再取得」と打っても、取り直しのコマンドが見つかるようにしました。/ Typing "取り直し" or "reload" in the command bar now finds the refetch commands.

## 連携するツールの方へ / For tools that read the data

- DB の表・利用者のデータの JSON の形・`STORE_VERSION` は変わっていません。/ The database tables, the user-data JSON and `STORE_VERSION` are unchanged.
- ポートフォリオ・パフォーマンス比較・配当シミュレータなどの比べる相手（TOPIX の代わり）が `JP:1306` から `JP:1308` に変わりました。/ The TOPIX benchmark used by the portfolio, performance comparison, dividend simulator and others changes from `JP:1306` to `JP:1308`.
- 為替・暗号資産・海外の指数の行の `metrics.anomaly` は、終値 0 以下・出来高が負のときだけ 1 になります（次の更新で計算し直されます）。/ For FX, crypto and overseas index rows, `metrics.anomaly` is now 1 only for a zero or negative close or a negative volume (recomputed on the next update).

## インストール / Install

`elecxstock-0.1.20-setup.exe` をダウンロードして実行します（Windows 10/11、x64）。v0.1.19 の上に入れ直すと、データはそのまま残ります。/ Download and run `elecxstock-0.1.20-setup.exe` (Windows 10/11, x64). Installing over v0.1.19 keeps your data.

- コード署名をしていないため、初回は SmartScreen の警告が出ます（「詳細情報」→「実行」）。/ The installer is not code-signed, so SmartScreen warns on first run ("More info" → "Run anyway").
- 通信先は前の版と同じです。/ The app connects to the same hosts as before.
- macOS・Linux は未検証です。/ macOS and Linux are untested.
