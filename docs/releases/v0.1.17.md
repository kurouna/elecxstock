# elecxstock 0.1.17（ベータ版 / Beta）

v0.1.16 からの変更点です。ポートフォリオに分類ごとの資産の表と「同じ銘柄をまとめる」を足し、コマンドバー・ショートカット一覧・ペインの種類・設定のダイアログを作り直しました。資産推移の記録と分割の扱い、ペインのフォーカスの枠も直しています。/ Changes since v0.1.16: an asset table by group and "Combine same stock" in the portfolio, redesigned command bar, shortcut list, pane picker and settings, plus fixes to the asset history, stock-split handling and the pane focus frame.

## 新しいこと / New

- **ポートフォリオ: 分類ごとの資産** / **Portfolio: assets by group**: 保有のペインの列（数量・取得単価・現在値・前日比・評価額・評価損益・損益率・構成比・取得利回り）を、銘柄・業種・17 業種・市場区分・種別・口座でまとめた表です。資産構成と分類を共有し、どちらで替えても両方が変わります。閉じた分類の行には中の銘柄の構成を出し、S・Shift+S で並べ替え、← → Space・Shift+← → で開け閉めします。/ A table with the holdings columns grouped by stock, sector, 17 sectors, market, type or account. It shares its grouping with the treemap; collapsed group rows show what is inside. S / Shift+S sort, ← → Space and Shift+← → expand or collapse.
- **ポートフォリオ: 同じ銘柄をまとめる** / **Portfolio: Combine same stock**: 資産構成・分類ごとの資産・損益寄与・配当の表に、カードごとのチェックを置きました（既定はオン。キーは A）。外すと、NISA と特定など複数の口座で持つ銘柄を口座ごとの行・タイルにし、口座の色の点を付けます。/ Each of the treemap, the asset table, contributions and the dividend table has its own checkbox (on by default, key A). Turn it off to split stocks held in several accounts into one row or tile per account, marked with account-colored dots.
- **ダイアログの作り直し** / **Redesigned dialogs**:
  - コマンドバー（Ctrl+K）: 範囲のチップと接頭辞（> # @）、再起動をまたぐ「最近」、使えない操作の理由、ペインの種類と中のキーも探せます。/ Command bar (Ctrl+K): scope chips and prefixes (> # @), recent items kept across restarts, reasons when an action is unavailable, pane types and in-pane keys as results.
  - ショートカット一覧（F1）: 文字かキーを押して絞り込み、いまのペインを先頭に、変えたキーに印。/ Shortcut list (F1): filter by text or by pressing a key, the current pane first, rebound keys marked.
  - ペインの種類（Ctrl+Shift+N）: 線画のカードと「何が起きるか」の 1 行。分割でも使います。/ Pane type (Ctrl+Shift+N): cards with line drawings and a line saying what will happen; also used when splitting.
  - 設定: 全タブを探す・既定に戻す・見本・キーだけの操作。/ Settings: search across tabs, reset to default, previews, keyboard-only navigation.

## 直したこと / Fixes

- **分割の扱い** / **Stock splits**: CSV を取り込んだあとに分割があると、保有のペインの評価額・損益が分割の前の株数のままでした。株数・取得単価・CSV の現在値を今の基準に換算します。権利落ち日の場中や休日に取り込んだとき・権利落ち日の朝に、資産推移とポートフォリオの評価額が分割の比率だけずれることがあったのも直しました。/ After a split, the holdings pane valued CSV holdings at the pre-split share count; quantities, average cost and the CSV price are now converted. The asset history and portfolio value no longer jump by the split ratio when importing on an ex-date or on the ex-date morning.
- **資産推移の記録** / **Asset history**: 休日や取引時間中に保有を変えたあと、アプリを起動し直すと前の取引日の確定した記録が書き換わっていました。保有が同じでも実現損益・受取配当が変わったら、その日の記録を書き直します。/ Restarting after changing holdings on a holiday or during trading no longer overwrites the previous session's final record; a change in realized gains or dividends received now updates the day's record.
- **時間加重の概算** / **Time-weighted return**: 小さな元手に大きく買い増した日に少し下がると、−95% や符号の反転のような値になっていました。買いは日の初め、売りは日の終わりとみなして数えます。/ A large top-up on a small base could show −95% or a flipped sign; buys now count at the start of the day and sells at the end.
- **ペインのフォーカスの枠** / **Pane focus frame**: キーで操作しているときの枠の一部が、表の選んだ行などに隠れていました。チャートグリッド・マーケット・資産構成のタイルとドロワーの枠も同じく直しました。/ Parts of the keyboard focus frame were hidden by selected table rows and similar content; the same fix applies to chart-grid, market and treemap tiles and the drawer.
- **ポートフォリオのそのほか** / **Portfolio, other**: Tab の順をペインの幅ごとの画面の並びに合わせ、チェックやボタンを押したあともキーが効くようにしました。無配に転じた銘柄の 5 年の 1 株配当、損益の棒の目盛り、配当の内訳のスクロール、予定の ↑ ↓、十字線の日の見出しの高さ、プライバシーモードのツールチップの符号なども直しています。/ Tab follows the on-screen order at each width, keys keep working after clicking checkboxes or buttons, and several display issues are fixed (5-year DPS after a dividend cut, P/L bar scale, dividend list scrolling, ↑ ↓ for events, heading height on the crosshair day, signs in tooltips in privacy mode).
- **選択の欄** / **Selects in panes**: チャートの表示期間・チャートグリッドの出どころ・ランキングの指標をマウスで選んだあと、ペインのキーが効かなくなっていました。/ Pane keys stopped working after choosing the chart period, the grid source or the ranking metric with the mouse.

## 連携するツールの方へ / For tools that read the data

- DB の表と `STORE_VERSION` は変わっていません。/ The database tables and `STORE_VERSION` are unchanged.
- 設定（`settings.json`）に `paletteRecent`（コマンドバーの最近）を足しました。/ `settings.json` gains `paletteRecent` (command bar recents).
- Core の保有の一覧（`portfolio.list`）は、CSV を取り込んだあとの分割で数量・取得単価・現在値を換算し、`importedAt` を最後の分割の日に寄せて返します。取引（`lots`）のある保有も同じです。アプリから保存し直すと、この値がファイルに残ります。/ `portfolio.list` converts quantity, average cost and price by splits after import and moves `importedAt` to the last split date (also for lot-based holdings); saving from the app writes these values.
- 損益寄与の今月・今年（`FolioContribRow`）に口座ごとの値 `accts` を足しました。`src/renderer/lib/folio.ts` の `divRows`・`contribRows`・`allocTiles` に口座ごとに分けるかの引数（省略できます）を足し、`DivRow` に `shares` を足しました。/ `FolioContribRow` gains per-account `accts`; `divRows`, `contribRows` and `allocTiles` take an optional split flag, and `DivRow` gains `shares`.
