# elecxstock 0.0.5

v0.0.4 からの変更点です。/ Changes since v0.0.4.

（v0.0.4 はリリースの検査で止まり、インストーラは公開されませんでした。v0.0.4 の変更もこの版に入っています。/ v0.0.4 was not published because the release check failed; its changes are included in this version.）

## 新機能 / New

- **マルチモニタ（フリーのウィンドウ）** — Ctrl+Alt+N でタブなしの「フリー 2〜4」を開き、2 枚目以降のモニタにチャートを並べられます。初期の形はチャートグリッド・4 分割・MTF + 銘柄情報・チャート 1 枚から選べます。/ Open up to three tabless Free windows (Ctrl+Alt+N) to line up charts on other monitors; start from a chart grid, four charts, MTF + symbol info or one chart.
- **銘柄を送る** — 1 枚目の一覧からタイルやチャートへドラッグするか、Ctrl+Alt+Enter で選んだ銘柄をフリーのウィンドウへ送ります。/ Drag symbols from the main window, or send the selection with Ctrl+Alt+Enter.
- **窓をまたぐリンク** — フリーのウィンドウでリンク色を付けたチャートは、1 枚目で選んだ同じ色の銘柄を追います。/ Linked charts in Free windows follow the symbol picked in the main window.
- **窓ごとの記憶** — 並び・位置（モニタの組み合わせごと）・文字の大きさ（Ctrl+Alt+= / - / 0）を窓ごとに覚え、次の起動で開き直します。Ctrl+F6 で窓を移れます。/ Layout, position per monitor setup and text size are remembered per window and restored; Ctrl+F6 cycles windows.

## 改善 / Improvements

- フリーのウィンドウで★・◆を付けると、1 枚目のリストにすぐ反映されます。設定・リストの編集は 1 枚目で行います。/ ★/◆ toggled in a Free window show up in the main window at once; settings and list edits stay in the main window.
- Ctrl+Shift+Q はどの窓からでもアプリ全体を終え、終了の前に全窓の保存を待ちます。/ Ctrl+Shift+Q quits from any window and waits for every window to save first.
- モニタを外したときは、その画面にあった窓を主モニタへ戻します。/ Windows on a removed display move back to the primary display.
