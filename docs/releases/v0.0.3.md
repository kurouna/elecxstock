# elecxstock 0.0.3

v0.0.2 からの変更点です。/ Changes since v0.0.2.

## 新機能 / New

- **保有タブ（Ctrl+Shift+8）と楽天証券 CSV の取り込み** — 楽天証券の「保有商品一覧（すべて）」の CSV を取り込むと、保有がその内容に置き換わります（国内株式。前の記録は元に戻せます）。評価額・評価損益・前日比・年間配当の見込み（税引後）・口座区分ごとの小計を表示します。保有の JSON で別の PC へ移せます。/ Holdings tab and Rakuten Securities CSV import: each import replaces holdings (domestic stocks, undoable). Shows value, P/L, day change, after-tax dividends and per-account subtotals. Move to another PC with the holdings JSON.
- **ウォッチリストの「保有」タブ** — 保有している銘柄を一覧・チャートで追えます。/ A read-only Holdings list in the watchlist.
- **フリータブ（Ctrl+Shift+7）** — 分割を重ねて自由に並べ、リンク色の無いチャートはそれぞれ自分の銘柄を持ちます。C キー・見出しの銘柄名で銘柄を変えられます。/ Free tab: free-form splits; unlinked charts keep their own symbol; change it with C.
- **ペインを画面の端へ** — ドラッグで画面の外側の端に落とすと、新しい列・行を足せます（コマンドバーからも）。/ Drop a pane on the workspace edge to add a new column or row.
- **銘柄のドラッグ＆ドロップ** — ウォッチリスト・スクリーナーの行をグリッドのタイルやチャートに落として表示できます。/ Drag symbols onto grid tiles and charts.
- **グリッドのページ送り** — ‹ › ボタンと、ページの端を越える矢印キーでめくれます。/ Grid paging buttons and arrow keys that wrap pages.
- **銘柄ジャンプからお気に入り・リストに追加**（☆ / Ctrl+D、＋ / Ctrl+Enter）、**確認ダイアログの矢印キーと Enter**、**Ctrl+Shift+Q で終了**。/ Favorite and add-to-list from symbol jump, arrow keys in confirm dialogs, quit with Ctrl+Shift+Q.

## 改善 / Improvements

- **銘柄情報** — 広いペインでは左に指標（配当・割安度・値動き）、右に配当の推移。配当は暦年ごとの合計の棒（年途中・減配の印つき）で、Y キーで回ごとに切り替え、矢印で棒を選べます。/ Symbol info: metrics left, dividend chart right on wide panes; annual dividend bars with partial-year and cut marks; Y toggles per payout.
- **レイアウトの統一** — どのタブもウォッチリスト・スクリーナーを左の列（グリッド・フリーは左のドロワー）に置きます。「サイズを戻す」は形が変わっても正しい比率に戻ります。/ Watchlist and screener always in the left column or drawer; size reset matches splits by content.
- **ツールバー** — 説明文のボタンを、ツールチップ付きのアイコンボタンにしました。/ Icon toolbar buttons with tooltips.
- **フォーカスの枠** — キーで操作しているときだけ出します（設定で常に表示も可）。ステータスバー・ドロワーの表示も見直しました。/ Focus outline only while using the keyboard; status bar and drawer polish.
- **速さ** — 指標の再計算は直近の日足だけを読み（約 5 倍速）、グリッドのタイルも必要な本数だけ読みます。保存期間を縮めたあとの使用量の表示も正しくなりました。/ Faster metrics recompute and grid reads; correct disk usage after shrinking retention.

## 修正 / Fixes

- 取得中に閉じても、Core が取得を止めて DB を閉じてから終わり、次の起動で続きから再開します。分割後の月足の取り直しも失われません。/ Quitting mid-fetch now stops Core cleanly and resumes next time; post-split monthly refetch is never lost.
- 銘柄ジャンプのあとの Ctrl+D が前の銘柄を外していた不具合、ドロワーから戻すとペインが別の場所に入る不具合、グリッドの拡大から戻れない不具合などを直しました。/ Fixed Ctrl+D after a jump, drawer return position, grid zoom exit and more.
- 上場廃止・取得対象外になった銘柄をスクリーナー・ランキング・ヒートマップから外しました。/ Delisted and untracked symbols are excluded from screener, ranking and heatmap.

海外市場の銘柄（米国株など）は対象外です（理由は docs/requirements.md §1.2）。/ Overseas stocks are out of scope (see docs/requirements.md §1.2).
