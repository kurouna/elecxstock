# elecxstock 0.1.9（ベータ版 / Beta）

v0.1.8 からの変更点です。**ペインの最大化とタブの切り替えに控えめな動き**を付け、**F11 の全画面**が効くようにしました。/ Changes since v0.1.8: **subtle motion for maximizing panes and switching tabs**, and **F11 full screen** now works.

> **ご注意 / Notice**
>
> - 株価・配当などのデータは Yahoo Finance の非公式 API から取得しています。遅延・欠損・誤りがあり得ます。個人の利用の範囲でお使いいただき、取得したデータを再配布しないでください。/ Prices and dividends come from the unofficial Yahoo Finance API and may be delayed, missing or wrong. Use it for personal use only and do not redistribute the data.
> - 本アプリは投資助言ではありません。/ This app is not investment advice.
> - 保有・ウォッチリスト・アラート・資産推移の記録は `%APPDATA%\elecxstock\` に暗号化せずに保存します。BitLocker などのディスク暗号化を使い、このフォルダを共有や同期の場所に置かないでください。/ Holdings, watchlists, alerts and the asset history are stored unencrypted under `%APPDATA%\elecxstock\`; use disk encryption such as BitLocker and keep the folder out of shared or synced locations.

## 新しいこと / New

- **ペインの最大化と戻す**（Ctrl+Shift+Enter・Esc）: 元の場所との間を短く動きます（広げる 0.15 秒・戻す 0.12 秒）。どのペインが広がったか・どこへ戻ったかを目で追えます。/ **Maximize and restore** (Ctrl+Shift+Enter, Esc) now move briefly between the pane and its place (0.15 s / 0.12 s), so you can follow which pane grew and where it went back.
  - 大きさは一度で変え、動かすのは位置だけなので、チャートの描き直しは 1 回で済みます。キーのフォーカスの枠も消えません。/ The size changes at once and only the position moves, so charts redraw once; the keyboard focus ring stays visible.
- **タブの切り替え**: 下線が選んだタブへ滑り、中身が少し（16px）滑って入ります。右のタブへ移れば右から、左なら左から（0.2 秒）。ドロワーのタブ（Ctrl+Tab）も同じです。/ **Switching tabs**: the underline slides to the selected tab and the content slides in slightly (16 px) from the side of the tab you moved to (0.2 s). Drawer tabs (Ctrl+Tab) work the same way.
  - 続けて押しても画面は暗くなりません。マイレイアウトのページどうしは滑らせず、出すだけです。/ Pressing repeatedly does not dim the screen. Switching between pages of the Pages tab only fades in.
- **動きを止める**: 設定の「動きを減らす」か、Windows のアニメーションの設定（「アニメーション効果」をオフ）で、これらの動きはすべて止まります。/ **Turning it off**: "Reduce motion" in Settings or the Windows animation setting turns all of this off.
- **F11 の全画面**: F11 で窓を全画面にし、もう一度押すと戻ります（これまで効いていませんでした）。/ **F11 full screen**: F11 makes the window full screen and back (it did nothing before).

## 直したこと / Fixes

- 最大化したペインを閉じる・ドロワーへ移す・レイアウトを初期状態に戻すと、最大化の状態が残り、次の Esc が効かず「サイズを戻す」も押せないままになっていたのを直しました。/ Closing a maximized pane, moving it to a drawer or resetting the layout left the maximized state behind, so the next Esc did nothing and "Reset sizes" stayed disabled.
- 最大化したまま分割・まだ無いペインを開く・ドロワーを開くと、結果が最大化したペインの裏に隠れていたのを、最大化を解いて見せるようにしました。/ Splitting, opening a new pane or opening a drawer while a pane was maximized happened behind it; the pane is now restored so you can see the result.

## インストール / Install

`elecxstock-0.1.9-setup.exe` をダウンロードして実行します（Windows 10/11、x64）。v0.1.8 の上に入れ直すと、データはそのまま残ります。/ Download and run `elecxstock-0.1.9-setup.exe` (Windows 10/11, x64). Installing over v0.1.8 keeps your data.

- コード署名をしていないため、初回は SmartScreen の警告が出ます（「詳細情報」→「実行」）。/ The installer is not code-signed, so SmartScreen warns on first run ("More info" → "Run anyway").
- macOS・Linux は未検証です。/ macOS and Linux are untested.
