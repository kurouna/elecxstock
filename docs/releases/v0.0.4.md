# elecxstock 0.0.4

v0.0.3 からの変更点です。/ Changes since v0.0.3.

## 新機能 / New

- **保有の編集** — 保有タブで Insert・E・Delete で足す・直す・外す（楽天証券以外でも使えます）。/ Add, edit and remove holdings in the Holdings tab.
- **スクリーナーの保有の条件** — 「保有」と保有の損益率で絞り込めます。条件の並べ替え（↑↓・Alt+↑↓）、指標の変更（クリック・F）。/ Screener conditions for held symbols and holding P/L %; reorder and change fields.
- **チャートの表示期間** — どのチャートでも 3 か月〜全期間を選べます（Alt+1〜6。グリッドと同じ選び方）。/ Visible period for every chart (Alt+1-6), same picker as the grid.
- **配当の推移を 10 年分** — 月次系列から日足の保存期間より前の配当も取り込みます。/ Up to 10 years of dividend history.
- **銘柄情報の拡充** — 益利回り・ROE・EPS/BPS・騰落率・200 日線乖離・移動平均の交差・出来高倍率と、持っている銘柄の保有。/ Richer symbol info, including your holding.

## 改善 / Improvements

- タブの並びを マーケット・スクリーナー・グリッド・MTF・トリプル・インカム・保有・フリー に。数字はキーの形で表示。/ Tabs reordered; shortcut digits shown as keycaps.
- コマンドバー・銘柄ジャンプで選んだ銘柄は、今のタブに出せなければ MTF タブで表示。/ Picked symbols open in MTF when the current tab can't show them.
- 一覧・銘柄情報からも C キーで表示する銘柄を変えられます。/ C changes the symbol from list panes and symbol info.
- ツールチップ・★のみ表示・用語・空の表示・キーの表示をペイン間でそろえました。F5 は更新中・最新のときに知らせます。/ Consistent tooltips, toggles, terms and empty states; F5 reports when data is up to date.
- データ源と免責は設定の「このアプリについて」に移しました。/ Data source and disclaimer moved to Settings > About.
