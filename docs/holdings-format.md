# 保有の JSON の形式（FR-H8〜H10）

elecxstock が書き出す・取り込む「保有の記録」のファイルの形式です。別の PC への移行とバックアップに使います。

> **個人の資産情報です。** ファイルを他人と共有しないでください。アプリがこのファイルを外部に送ることはありません。

## 例

```json
{
  "format": "elecxstock.holdings",
  "version": 1,
  "exportedAt": "2026-11-13T12:05:00.000Z",
  "app": "elecxstock 0.0.2",
  "holdings": [
    {
      "code": "8058",
      "name": "三菱商事",
      "account": "nisa_growth",
      "quantity": 300,
      "avgCost": 2680.5,
      "lots": [{ "date": "2024-03-04", "side": "buy", "quantity": 300, "price": 2680.5, "fee": 0 }]
    },
    { "code": "8951", "name": "日本ビルファンド投資法人", "account": "tokutei", "quantity": 10, "avgCost": 118400, "broker": "○○証券" }
  ]
}
```

## 項目

| 項目         | 型                      | 必須 | 内容                                                                             |
| ------------ | ----------------------- | ---- | -------------------------------------------------------------------------------- |
| `format`     | `"elecxstock.holdings"` | ○    | 形式の名前。ほかの値のファイルは取り込まない                                     |
| `version`    | 整数                    | ○    | 形式の版。今は `1`。アプリより新しい版のファイルは取り込まない（古い版は読める） |
| `exportedAt` | ISO 8601                |      | 書き出した日時（UTC）                                                            |
| `app`        | 文字列                  |      | 書き出したアプリの版                                                             |
| `holdings`   | 配列                    | ○    | 保有（銘柄 × 口座区分ごとに 1 件）                                               |

`holdings` の各要素:

| 項目         | 型     | 必須 | 内容                                                                                                                                                                                           |
| ------------ | ------ | ---- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `code`       | 文字列 | ○    | 証券コード（4〜5 桁、英字を含んでもよい。例 `7203`・`130A`・`94345`）                                                                                                                          |
| `name`       | 文字列 |      | 銘柄名（確認用。証券会社の CSV から取り込んだときは CSV の銘柄名）                                                                                                                             |
| `account`    | 文字列 | ○    | 口座区分: `nisa_growth`（NISA 成長投資枠）・`nisa_tsumitate`（つみたて投資枠）・`nisa_legacy`（旧 NISA）・`tokutei`（特定）・`ippan`（一般）                                                   |
| `quantity`   | 数     | ○    | 保有数量                                                                                                                                                                                       |
| `avgCost`    | 数     | ○    | 平均取得単価（円）                                                                                                                                                                             |
| `lots`       | 配列   |      | 取引の履歴（旧版で手入力したもの。今の版は証券会社の CSV から保有を作るので作らない）。あれば数量と平均取得単価は取引から計算し直す（下記）                                                    |
| `broker`     | 文字列 |      | 証券会社。CSV から取り込んだときは `rakuten`                                                                                                                                                   |
| `price`      | 数     |      | CSV の現在値（円）。アプリの中だけで持ち、日足が無い銘柄の評価額に使う。**書き出しには含めない**（市場データのため、FR-H8）                                                                    |
| `importedAt` | 文字列 |      | CSV を取り込んだ日時（ISO 8601）。数量・取得単価はこの日の株数の基準。取り込んだあとに分割があると、アプリは数量・取得単価を今の基準に換算して扱い、保存し直すとこの値を最後の分割の日に寄せる |
| `note`       | 文字列 |      | メモ                                                                                                                                                                                           |

`lots` の各要素: `date`（`YYYY-MM-DD`、約定日）・`side`（`buy` / `sell`）・`quantity`・`price`（円）・`fee`（円、任意）。

## 計算のきまり（FR-H5）

- 平均取得単価は**移動平均法**で計算する。
- **手数料は買いの取得価額に含める**。売りの手数料と税は含めない（売っても平均取得単価は変わらない）。
- 取引の後に株式分割があれば、数量 × 分割係数・単価 ÷ 分割係数で今の基準にそろえる（日足と同じ分割調整済みの基準）。
- すべて売って数量が 0 になったら、平均取得単価も 0 に戻す。

## 取り込み（FR-H9）

1. 1 件ずつ検証し、「追加・更新・変わらない・取り込めない（知らないコード・不正な値・重複）」を示して確認する。
2. 取り込み方を選ぶ: **今の記録に合わせる**（同じ銘柄・口座区分は置き換え、ほかは残す）か **すべて置き換える**。
3. 取り込む前の記録は残してあり、「保有の取り込みを元に戻す」で戻せる。

## 版を上げるとき

形式を変えたら `version` を上げ、古い版を読む移行を `src/core/holdings.ts` に書く。項目を足すだけなら版は上げない（知らない項目は取り込みで捨てる）。

## 楽天証券の CSV（FR-H11）

保有は楽天証券の「保有商品一覧（すべて）」の CSV（`assetbalance(all)_*.csv`、Shift_JIS）を取り込んで作る。取り込むたびに保有はすべて CSV の内容に置き換わる（前の記録は世代として残し、元に戻せる）。読むのは「■ 保有商品詳細」の表の「種別」が「国内株式」の行で、「銘柄コード・ティッカー」「銘柄」「口座」「保有数量」「平均取得価額」「現在値」の欄を見出しの名前で探す。資産合計欄の「国内株式」の行の「実現損益[円]」「配当金・分配金・利金[円貨]」は参考の累計として持つ。

## 証券会社の CSV の累計（`meta`、任意）

最後に取り込んだ証券会社の CSV の情報。別の PC で取り込むと、保有タブの「CSV の累計」に同じ値が出る。

```json
"meta": { "broker": "rakuten", "importedAt": "2026-11-13T17:42:59.504Z", "realized": 1159970, "dividends": 3499686 }
```

`realized`（実現損益、円）・`dividends`（受け取った配当金・分配金、円）は CSV の資産合計欄の「国内株式」の行。無ければ `null`。

銘柄の一覧に無いコード（書き出した PC で足した ETF など）も取り込み、取り込んだ PC で銘柄として足してデータを取りにいく。

## 資産推移の記録（`history`、任意）

ポートフォリオのペインの資産推移（[design-portfolio.md](design-portfolio.md) §5）。作り直せないので、保有と一緒に書き出して別の PC へ移せるようにする。取り込むと**日付で混ぜる**（記録が補完値に勝ち、同じ種類なら新しく書いたほう。丸ごと置き換えない）。読めない記録は取り込まず、保有の取り込みは止めない。

```json
"history": [
 { "d": "2026-11-13", "src": "rec", "final": true, "value": 1500000, "cost": 1300000,
   "pos": [{ "code": "7203", "acct": "tokutei", "qty": 100, "cost": 13000 }],
   "realized": 0, "received": 0, "at": 1794731000000 }
]
```

| 項目                    | 内容                                                                                   |
| ----------------------- | -------------------------------------------------------------------------------------- |
| `d`                     | 日付（日本時間の YYYY-MM-DD。取引日）                                                  |
| `src`                   | `rec`（記録）/ `fill`（起動しなかった日を前の保有 × その日の終値で補った値）           |
| `final`                 | その日の終値がそろっていたか（`false` は次の記録で書き直す）                           |
| `stale`                 | 取得に失敗した銘柄があった（任意）                                                     |
| `value` / `cost`        | 評価額・取得額（円）                                                                   |
| `pos`                   | その日の保有（`code`・`acct` 口座区分・`qty` その日の株数の基準・`cost` 平均取得単価） |
| `realized` / `received` | 実現損益・受取配当の累計（証券会社の CSV。任意）                                       |
| `at`                    | 書いた時刻（ミリ秒）                                                                   |

値はすべて例（架空）。
