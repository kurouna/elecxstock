# チャートの描画（トレンドライン）の設計

FR-C8（描画ツール。P3）のうち、まずトレンドラインを作るための設計。水平線・価格帯は同じ作りに後から足せるようにしておく。
[design-p3.md](design-p3.md) §5 の下書きをこの文書で置き換えた。要求は requirements.md の FR-C13〜C20（§9）、キーは §6.5.4。

状態: **草案 第 2 版**（2026-11-18。Fable 5.2・Opus 5.5 のレビューを反映。決めたことは §11）。

---

## 1. 調査: 一般的なトレーディングツールの操作

### 1.1 TradingView（事実上の標準）

| 場面 | 操作 |
| --- | --- |
| 道具を選ぶ | 左のツールバーのトレンドラインの道具。キーは **Alt+T**（水平線 Alt+H・垂直線 Alt+V・十字 Alt+C・フィボナッチ Alt+F） |
| 引く | **始点をクリック → 線がポインタに付いてくる → 終点をクリック**（押したまま離す、でも引ける） |
| 吸着（マグネット） | 弱・強の 2 段（既定はオフ）。近い足の **始値・高値・安値・終値** に端点が付く。**Ctrl を押している間だけ**入れる・外す（引くときも直すときも） |
| 角度の固定 | **Shift** を押しながら引くと水平か 45 度 |
| 引いた直後 | その線が選ばれた状態になる。端点に **2 つの取っ手**（と中点）が出る |
| 直す | 取っ手をドラッグで端点だけ、線の本体をドラッグで全体が動く。Shift+ドラッグで縦か横だけ。**Ctrl+ドラッグで複製** |
| 選んだ線の操作 | **浮かぶツールバー**（色・太さ・線種・設定・アラート・ロック・削除）と右クリックのメニュー。ダブルクリックで設定 |
| キー | **← → ↑ ↓ で選んだ線を動かす**、Delete で消す、Ctrl+Z で戻す、Ctrl+C / Ctrl+V で写す、Ctrl+クリックで複数を選ぶ、**Ctrl+Alt+H ですべての描画を隠す** |
| 設定のダイアログ | スタイル（色・不透明度・太さ・線種・両端の矢印・**左右への延長**・中点・**価格ラベル**・統計＝値幅・変化率・本数・期間・角度。統計は選んだときだけ、が既定）／テキスト／**座標**（2 点の足と価格を数字で打つ）／**表示する時間軸** |
| その他 | 連続して引くモード、すべてロック、同じ銘柄のチャートで描画を同期、オブジェクトツリー（図形の一覧）、**トレンドラインのアラート**（線を価格が横切ったら） |

### 1.2 ほかのツール

- **AG Charts（金融チャートのツールバー）**: ツールを選んでクリックで置き、浮かぶツールバーで色・線種、設定で延長。キーは Delete / Backspace で消す、**矢印で 1px、Ctrl か Shift で 10px 動かす**、Ctrl+Z / Ctrl+Y、Shift で 45 度。図形は状態として `{ type, start: { x: 日付, y: 価格 }, end }` で保存・復元できる。
- **楽天証券 マーケットスピード II（2024-12 の更新）**: **始点・終点を近くの足の高値・安値に吸着**、**描画モードを続けて連続描画**、描いた図形の色・線種・太さの確認と変更、が足された。
- **Lightweight Charts（本アプリのライブラリ）**: 描画の道具は持たない。Series Primitives（`ISeriesPrimitive`）で自前に描く。`hitTest` はポインタの形と `hoveredObjectId` に使えるだけで、ドラッグは自前で作る。

### 1.3 「標準」としてそろえる点

1. **2 点で引く**（クリック・クリック。ドラッグでも）。引く途中は線がポインタに付いてくる。Esc でやめる。
2. **端点は足の OHLC に吸着できる**（修飾キーで一時的に入れる・外す）。TradingView は既定でオフだが、国内のツールは吸着を足しており、トレンドラインは山と谷を結ぶものなので、このアプリでは既定でオン（弱）にする（§4）。
3. 引いた線は **選ばれた状態** になり、**端点の取っ手** と **本体** で直せる。
4. 選んだ線は **矢印で動かす・Delete で消す・Ctrl+Z で戻す**。
5. 設定は **色・太さ・線種・左右への延長・価格ラベル**。必要なら座標を数字で直す。
6. 図形は **銘柄に結び付き**、時間軸を替えても同じ日付・価格の所に出る。

## 2. このアプリでの方針

- **キーだけで引けることを先に作る**（FR-KB4）。既存の **キーボード十字線（X）** を描画のカーソルに広げ、キーだけでも実用になるように **山・谷へ跳ぶ** 移動を足す。
- **マウスの操作は TradingView にそろえる**（クリック・クリック、取っ手のドラッグ、右クリックでメニュー）。
- **キーも分かる所は TradingView にそろえる**（Alt+T・Delete・矢印・Ctrl+Z）。単キーはこのアプリの決まり（`e.code`・IME・JIS の記号を使わない。FR-KB5）に合わせる。
- 浮かぶツールバーは作らない。代わりに **図形のメニュー**（`chartMenu` と同じ作り。キーでもマウスでも開く）にする。
- **2 枚目以降の窓（フリー 2〜4）でも引ける**。
- データは **線ごとに色・太さ・線種を持てる形** にする。ただし選ぶ UI はフェーズ 2（フェーズ 1 は既定の見た目だけ）。
- フェーズ 1 は **トレンドラインだけ**（§10）。

## 3. 操作（キー）

チャートのペインの中のキー（ペインの中のキーなので割り当ては固定。FR-KB6）。

### 3.1 状態

```
            Alt+T                Enter               Enter
  通常 ───────────▶ 始点 ───────────▶ 終点 ───────────▶ 選択（見るだけ）
   ▲  ◀──Esc───────┘  ◀──Esc─────────┘                   │  ▲
   │                                                      │  │ Space（なし に戻る）
   │                                              Space   ▼  │
   └───────────Esc／フォーカスが外れる────────────── 選択（動かす: 全体 → 始点 → 終点）
  通常 ──G──▶ 選択（見るだけ）
```

- **選択（見るだけ）**: 取っ手が出るだけで、← → は今までどおり表示のスクロール。引いた直後もこの状態（矢印を押して線が動いて驚かないため）。
- **選択（動かす）**: Space で入り、全体 → 始点 → 終点 → 見るだけ、の順に替わる。動かす対象を取っ手の印で示す。
- 画面の下（凡例の行）に、いまの状態で効くキーの案内を出す。案内の行は出し入れせず、場所を取ったままにする（CLAUDE.md の「選んだときだけ出す行」）。
- 状態の遷移は表として `src/shared/drawings.ts` の純粋な関数に置き、L1 で確かめる。

### 3.2 引く（始点・終点）

| キー | 動き |
| --- | --- |
| **Alt+T** | 引き始める。カーソルはキーボード十字線の足（無ければ表示中の最後の足）の高値 |
| **← →** | 足を 1 本ずつ（Shift で 10 本） |
| **Ctrl+← →** | 前・後の **山か谷**（前後 5 本で高値が最大・安値が最小の足）へ跳ぶ。跳んだ先が山なら高値、谷なら安値に付く |
| **PageUp / PageDown** | 1 画面ずつ |
| **Home / End** | 表示中の最初・最後の足 |
| **↑ ↓** | その足の OHLC を **値の大きい順**（同じ値はまとめる）に移る。種類がラインのときは終値だけ |
| **Shift+↑ ↓** | 吸着を外して価格を動かす（表示の高さの 1/100。Ctrl+Shift で 1/10） |
| **Enter** | 点を決める。始点を決めると、始点からカーソルまで線が付いてくる |
| **Esc** | 終点のときは始点に戻る。始点のときはやめる |

- カーソルが表示の端へ出たら、見えるように表示をずらす。
- 終点に始点と同じ足を選んで Enter したときは決めず、「別の足を選んでください」と案内の行に出す。
- 未来（最後の足より右）には点を置けない（延長だけで先へ伸ばす）。

### 3.3 選ぶ・直す

| キー | 動き |
| --- | --- |
| **G / Shift+G** | 図形を順に選ぶ（グリッドの G と同じ型）。順は **表示範囲に掛かる図形を先に、十字線（無ければ右端）に近い順**。範囲の外の図形を選んだら、そこへ表示をずらす |
| **Space** | 選択（見るだけ）→ 全体 → 始点 → 終点 → 見るだけ |
| **← →**（動かす） | 対象を足 1 本ずつ（Shift で 10 本、Ctrl で山・谷へ。始点・終点のとき） |
| **↑ ↓**（動かす） | 始点・終点: OHLC の値の大きい順に移る。全体: 表示の高さの 1/100（Shift で 1/10） |
| **Shift+↑ ↓**（始点・終点） | 吸着を外して動かす |
| **E** | 延長を なし → 右 → 左右 → なし の順に替える |
| **Delete** | 消す |
| **Enter** | 図形のメニュー（§5） |
| **Ctrl+Z / Ctrl+Y** | 戻す・やり直す（§7.4） |
| **Esc** | 選択を外す |

### 3.4 チャート全体

| キー | 操作 |
| --- | --- |
| **I** のメニュー | 「描画」の項目: トレンドラインを引く・図形を選ぶ・この銘柄の描画をすべて消す（確かめのダイアログ。消した後も Ctrl+Z で戻せる） |
| **Ctrl+Alt+H**（フェーズ 2） | **このペインで** 描画を隠す・出す（`pane.state.drawingsHidden`。銘柄ではなくペインの設定） |

### 3.5 キーの照合の順と衝突

- `ChartView.key()`（`ChartView.svelte:571`）と `chartKey`（`chartMenu.ts:136`）は Ctrl・Alt 付きを最初に捨てている。**描画のキー（Alt+T・Ctrl+Z・Ctrl+Y・Ctrl+← →）はその前で受ける**。
- 全体のアクションはペインより先に照合される（`commands.ts:968` → `974`）。利用者が keymap で描画のキーを奪わないよう、**`PANE_RESERVED`（`lib/keys.ts:65`）に Alt+T・Ctrl+Y（フェーズ 2 で Ctrl+Alt+H）を足す**。
- 全体の Ctrl+Z（アラート・ページ・サイズの取り消し。10 秒の間。`commands.ts:954-967`）より先に、**チャートのペインにフォーカスがあり描画の取り消しの履歴があるときは描画を戻す**。
- 引いている途中・動かしている途中は、D / W / M・A・T・C（`Chart.svelte:36`・`chartMenu.ts`）を受けたら、**引いている途中ならやめ**てから切り替える（足の番号と価格の空間が変わるため）。選択は図形の ID で保つ。
- Alt 単体ではメニューに移らない（`setApplicationMenu(null)`。`main/index.ts:698`）。
- 既存のチャートのキー（D W M S C L A T I X + − 0 ← → Alt+1〜6）とアプリ全体のアクションのどれとも重ならないことを、キーの衝突のテストで確かめる。

## 4. 操作（マウス）

| 操作 | 動き |
| --- | --- |
| Alt+T・I のメニューから引き始める | ポインタが十字になる |
| クリック（始点）→ 動かす → クリック（終点） | 引く。押したまま動かして離しても引ける |
| 吸着 | 既定で **弱**（足の OHLC から 8px 以内なら付く）。**Ctrl を押している間は外す**。種類がラインのときは終値だけ |
| 右の余白（未来）でクリック | 最後の足に丸める |
| 線の上に載せる | ポインタが手の形（`hitTest`。線から 6px 以内） |
| 線をクリック | 選ぶ（見るだけ）。取っ手を出す |
| 取っ手・本体のドラッグ | 端点だけ・全体を動かす |
| 右クリック | 図形のメニュー |
| 何もない所をクリック・Esc | 選択を外す。引いている途中ならやめる |

- **ドラッグは自前**: host にキャプチャ段階の pointer イベントを付け、ドラッグの間だけ `handleScroll`・`handleScale` を止める。
- **座標は表示倍率をそろえる**: `clientX` は倍率が掛かり、`coordinateToLogical`・`coordinateToPrice` は掛からない。`lib/pointer.ts`（`localX`）を通し、8px・6px も同じ空間で比べる。倍率 1 以外でもテストする。
- Shift の 45 度は入れない（価格と時間の軸では角度が表示の縮尺で変わる）。
- ダブルクリックの「設定」はフェーズ 2（設定の UI と一緒に）。

## 6. 描く

### 6.1 足の番号（x）

- **日付 → 足の論理番号は自前で計算する**（チャートの時刻の API を使わない）。一目均衡表をオンにすると `extendTime` が暦日の間隔で未来の時刻を足す（`ChartView.svelte:217-227`）ので、ライブラリの時刻から求めると一目のオン・オフで位置が変わる。
- 足の日付はその期間の最初の取引日（`series.ts:21`・`31`）。点の日付は **「その日以前で最後の足」** に合わせる（`ChartView.svelte:410` の配当・分割の印と同じ）。休日の日付も同じ規則で前の足になる。
- **足の範囲の外**（保存期間より前の日足、タイルの範囲の外、未来への延長）は外挿する。日足は `calendar.ts` の営業日の数（`tradingDaysBetween`）、週足・月足は週・月の数で、負の番号や最後の足より先の番号にする。`logicalToCoordinate` は範囲の外の番号も座標にできる。
- **週足・月足で吸着した点** は、その足の最初の取引日として保存される。日足に替えると、高値・安値の日から左にずれて見える。フェーズ 1 はこれを仕様として F1・文書に書き、フェーズ 2 で Core から極値の日を引いて保存する。
- **2 点が同じ足になる**（日足で同じ週に引いた線を週足で見る、など）ときは、傾き・延長・価格ラベルを求めず、その足の位置に短い縦の線として描く（NaN を出さない）。

### 6.2 価格（y）と調整（FR-D2・FR-D3）

- **点の価格は、その日の未調整の価格で持つ**（`raw`）。分割調整済みの表示では `raw ÷ splitFactor(date, splits)`（`core/series.ts:72`）で求める。
  - 足と分割の一覧は同じ取得の結果なので矛盾しない。後から分割があっても、取り直した分割の一覧で自動的に換算され、保存した値は書き換えない。
  - 「作った日（basis）」で持つ方式（アラートのしきい値）は採らない。データを取り直す前に分割の後の日付で引くと、取り直した後に比率の分だけずれるため。
- 「未調整」の表示では `raw` をそのまま使う。
- 「配当込み」の表示: フェーズ 1 は **出さない**（比較の表示と同じ扱い。案内を出す）。フェーズ 2 で Core から足ごとの「配当込み ÷ 分割調整」の係数を返してもらい換算する（配当込みは後ろから掛けていく計算で、日足の範囲の前は月次の系列になるため。`series.ts:106-112`）。
- 引く・直すのは「分割調整」と「未調整」の表示で行える。保存の前に、表示の価格を点の日付の係数で `raw` に直す。
- 比較の表示（% 目盛り）では描画を出さず、Alt+T・G は「比較の表示では引けません」と知らせる。

### 6.3 線の形

- 線は **画面の座標で直線**（TradingView と同じ）。対数軸でも画面で真っ直ぐに引く。
- **延長は px で計算する**（価格で外挿すると、対数軸で 0 以下になり座標にできない）。描く範囲で切る。
- 線が通る価格は時間軸と軸の種類で変わる。**正の定義は「日足の営業日の番号で、引いたときの軸の種類（`log`）で補う」** とし、図形に `log` を持たせる（価格ラベルとフェーズ 3 のトレンドラインのアラートが使う）。
- **価格ラベル**: 右の目盛りに、表示中の最後の足の位置での線の価格を出す（`priceAxisViews`）。延長が無く、その足が線の範囲の外なら出さない。アラート・目標利回りのラベルと重なるときはライブラリの重なりの処理に任せる。
- **目盛りの範囲は広げない**（`autoscaleInfo` を実装しない。目標利回りの線と同じ。FR-C12）。

### 6.4 部品

- `src/renderer/lib/drawings/primitive.ts`: `ISeriesPrimitive` を実装し、1 つのプリミティブがその銘柄の図形をすべて描く（線・取っ手・引いている途中の線・価格ラベル・`hitTest`）。`main` の series に `attachPrimitive` し、`build()` で作り直すたびに付け直す（`alertLines` と同じ）。
- `src/shared/drawings.ts`: 純粋な関数。日付 → 論理番号（外挿を含む）、価格の換算（`raw` ↔ 表示）、OHLC の吸着の順、山・谷の検出、延長の端（px）、線の価格、線までの距離（hitTest は呼ぶだけ）、状態の遷移の表、座標の入力の検証。
- `ChartView.svelte` は状態（いまの状態・カーソル・選んだ図形の ID）を持ち、計算は上の関数を呼ぶだけ。
- **マルチ時間軸のチャート**（`MtfChart`）: 3 枚とも描くが、**キーを受けているアクティブな 1 枚だけが引く・選ぶ**。Tab で移ったら、前の 1 枚の途中の状態はやめる。
- **画像の保存（S）**: 線は写す。取っ手・引いている途中の線・案内は写さない（保存の間だけ消す）。
- **グリッドのタイル**（`gridDraw.ts`。フェーズ 1b）: 設定は作らず **常に出す**。1px・価格ラベルなし・選べない。比較の表示（`scale === 2`）では出さない。タイルは右の余白が無くクリップもしていない（`gridDraw.ts:88-89`）ので、描く範囲に `clip()` を掛ける。タイルの `Bars` は最後の count 本だけで分割も無い（`service.ts:369-380`）ので、Core が **表示の空間に換算済みの点** を返す（アラートの `adjusted` と同じ。`service.ts:801`）。
- E2E のため、チャートの要素に `data-drawings`（JSON。図形ごとに保存の値と表示の値、選んでいる図形の ID）と `data-draw-state`（状態・カーソルの日付と価格）を出す（キャンバスの中は読めない）。

## 7. 保存と同期

### 7.1 形式

利用者のデータ `drawings.json`: `Record<InstrumentId, Drawing[]>`。書き出し・取り込みの対象にする。

```ts
type DrawingPoint = { date: string; raw: number }   // その日の未調整の価格（円）
type DrawingStyle = {
  color?: string                                    // トークン名（'--draw-1' など）。無ければ既定
  width?: 1 | 2 | 3
  dash?: 'solid' | 'dashed' | 'dotted'
}
type TrendDrawing = DrawingStyle & {
  id: string
  kind: 'trend'
  a: DrawingPoint                                   // a.date <= b.date に正規化して保存
  b: DrawingPoint
  extend: 'none' | 'right' | 'left' | 'both'
  priceLabel: boolean
  log: boolean                                      // 引いたときの軸（線の価格の正の定義。§6.3）
  created: string                                   // アラートと同じ形式（api.ts:231）
  updated: string
}
type Drawing = TrendDrawing                         // 後で HLineDrawing | BandDrawing を足す
```

- zod は `kind` の `discriminatedUnion`。色・太さ・線種は省略できる（フェーズ 1 は書かない。既定を後で変えられる）。色はトークン名だけを通す。
- 読み込みは図形ごとに検証し、**知らない `kind` の図形は読み飛ばしつつファイルには残す**（古い版が新しい版のファイルを読んでも消さない）。
- 価格は正の数、日付は `YYYY-MM-DD`。銘柄ごとの本数の上限は 100（`ALERT_LIMIT` と同じ作り）。
- `USER_FILE_SCHEMAS` に足す。ファイルが無いときは空。`STORE_VERSION` は上げない（ファイルが増えるだけ）。

### 7.2 Core のメソッド

1 本ずつ書く（ファイルを丸ごと送らない）。

| メソッド | 動き |
| --- | --- |
| `drawings.all()` | すべての銘柄の図形（renderer のストアが起動時と変更の知らせで読む） |
| `drawings.create(id, drawing)` | 足す（ID が既にあれば失敗。取り消しで戻すときは元の ID で足す） |
| `drawings.update(id, drawing, expected)` | 直す。`expected`（読んだときの `updated`）が今の値と違えば失敗し、新しい値を返す |
| `drawings.remove(id, drawingId, expected)` | 消す（同じく `expected` を確かめる） |
| `drawings.clear(id)` | その銘柄の図形をすべて消し、消したものを返す（取り消し用） |
| `drawings.tile(ids, tf, count, adj)`（1b） | タイル用に、表示の空間に換算した点を返す |

- `src/core/changes.ts` の `CHANGES` と `user.changed` の `kind` に `drawings` を足し、知らせに **銘柄の ID** も入れる。
- **フリー 2〜4 でも書ける**。`dispatch.ts` の窓の制限（アラートだけを止める正規表現。`dispatch.ts:36-48`）には足さない。design-multimonitor.md §3.3 と CLAUDE.md の「フリー N は読むだけ」に例外として書き足し、L3 で「フリーの窓から書ける」を確かめる。

### 7.3 renderer のストアと書く回数

- 窓ごとに `app.drawings: Record<InstrumentId, Drawing[]>` を置く（`app.alerts` と同じ）。同じ窓のほかのタブ・MTF の 3 枚・タイルはここから読む。ほかの窓の変更は `user.changed`（`from: slot` で自分の変更は読み直さない）で取り直す。
- 動かすときは **ストアを先に変えて描き、書くのはまとめて**: 矢印の連打は最後の押下から 300ms 後、ドラッグは離したとき、選択を外したときに `update` を 1 回。
- `update` が `expected` の違いで失敗したら（ほかの窓で直された・消された）、手元の変更を捨てて新しい値にし、「ほかの窓で変更されました」と知らせる。
- **編集中の図形** には、ほかの窓からの知らせを当てない（書き終わってから当てる）。

### 7.4 取り消し

- 単位は 1 操作（引く、ドラッグ 1 回、矢印の連打 1 回、消す、すべて消す）。
- 履歴は **ペインの ID と銘柄ごと** にストアに置く（銘柄を替えると `{#key id}` で ChartView が作り直されるため。`Chart.svelte:81`）。窓を閉じるまで。
- 逆操作は `create` / `update` / `remove` を `expected` 付きで呼ぶ。ほかの窓で変わっていて戻せないときは飛ばして知らせる。

### 7.5 その他

- 上場廃止・コードの変更で残った図形は消さない（フェーズ 3 で「銘柄の無い図形」を掃除する操作を考える）。全データの削除では消す。
- **elecxstock-cli**: 利用者のデータの JSON が増える。リリースのノートに書く（CLI で読む必要は今のところ無い）。

## 11. 決めたこと（第 1 版の未決の点）

| 点 | 決定 | 理由 |
| --- | --- | --- |
| 引き始めるキー | **Alt+T**（`PANE_RESERVED` に足す） | TradingView と同じ。メニューバーが無いので Alt でメニューに移らない。Shift+T は T（種類の切り替え）の押し間違いが起きる |
| 図形を選ぶキー | **G / Shift+G**、表示範囲の中で十字線に近い順 | グリッドの G と同じ型。`[` `]` は FR-KB5 に反する |
| マウスの吸着の既定 | **弱（8px）** | 強だと自由な位置に置くたびに Ctrl が要る |
| フリー 2〜4 | **引ける**（利用者の決定） | — |
| グリッドのタイル | **常に出す**（設定は作らない。フェーズ 1b） | 設定 3 か所の追加に見合わない |
| 線ごとの色 | **データは持てる形、UI はフェーズ 2**（利用者の決定） | — |
| 価格の持ち方 | **点の日付の未調整の価格**（basis 方式をやめた） | 分割の前後の取得のずれに強く、未調整の表示がそのままになる |

### レビューで分かれた点
