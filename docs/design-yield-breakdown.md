# 利回りの変化の内訳（設計）

銘柄情報のペインの配当（分配金）の欄に、「N 年前から今までの利回りの変化は、配当の動きによるものか、株価の動きによるものか」を出す欄を足す。
あわせて、配当と株価の平面（横 = 1 株配当、縦 = 株価）を小さく添え、V で広げて見られるようにする。要求は FR-I11（§9）。
モックは [mock/info-yield.html](mock/info-yield.html)（[説明](mock/README.md)）。値はすべて架空。単独のペインの案（[mock/divprice.html](mock/divprice.html)）は採らなかった（§10）。

- 状態: 設計（2026-11-24）。Fable 5.2・Opus 5.5 のレビュー（1・2 回目）を反映済み
- 関連: 実績利回り（FR-I1〜I4）・利回りの範囲（FR-I6。`info.extra` の `yieldRange`）・月次系列（FR-D7）・配当の記録の範囲（`divCoverFrom`。[design-perf.md](design-perf.md) §3.4）

## 1. 方針

- **利回りが変わった理由を分ける**。利回り = 1 株配当 ÷ 株価なので、利回りは増配でも株価の下落でも上がる。今の画面は「今の利回り」と「その範囲」しか見せず、
  上がった・下がったのが配当のせいか株価のせいかが分からない。これを棒と一言で出す。
- **結論は棒と一言で伝え、平面は確かめたい人が広げて見る**。モックで確かめたとおり、平面は初めて見ると意味が分からない。欄には棒と一言、小さな図を置き、
  説明は「i」（ツールチップ）と、広げた平面の右の「読み方」に出す。
- **データは今あるものだけ**: 月末の終値（日足の保存期間の中は日足、それより前は月次系列）と、配当の記録（約 10 年）。通信先・DB の表・列は増やさない。
- **計算は純粋な関数**（月の点と内訳は `src/shared/yieldPath.ts`、平面の形は `src/renderer/lib/yieldPlane.ts`）。コンポーネントは描くだけ。
- **判定をしない**。「割安」「買い時」などの言葉は使わない。一言は「どちらの動きが大きかったか」だけを言う（§3.3）。

## 2. 画面

### 2.1 欄（配当の欄の中、「利回りの N 年の範囲」の棒の下）

```
利回りの変化の内訳  2021/11 → 今（5 年）  (i)                         V で広げる
4.11% → 5.59%  +1.48 pt                                        ┌──────────┐
              ← 利回りを下げた ｜ 押し上げた →                   │  平面の   │
1株分配金      ━━━━━━━━━━━━|██                 +6%           │ 小さな図  │
株価           ━━━━━━━━━━━━|██████████        −22%           │           │
利回り         ━━━━━━━━━━━━|████████████      +36%           └─⤢ 広げる─┘
利回りは上がった。主に株価が下がったため
```

- 見出し: 「利回りの変化の内訳」・期間（「YYYY/MM → 今（N 年）」。N は実際の年数）・「i」のボタン・右に「V で広げる」。
- 1 行目: 始まりの利回り → 今の利回りと、差（pt）。
- 棒の上に**いつも**目盛りの言葉「← 利回りを下げた ｜ 押し上げた →」（初めて見て「−22% なのに右」で迷わないように）。
- 棒 3 本: **1 株配当（REIT は 1 口分配金）**・**株価**・**利回り**。どれも「利回りを押し上げた向きを右」に描く（配当は増えると右、株価は下がると右、利回りは上がると右）。
  配当と株価の 2 本を足すと利回りの 1 本になる（ln の和。§3.2）ので、向きの決まりは 3 本目を見れば分かる。右に増減率（+6%・−22%・+36%）。
  棒の長さは `min(|ln 比|, s) / s × 半分`、`s = max(|lD|, |lP|, |lY|, 0.15)`（小さな変化を大げさに描かない）。
- 一言（§3.3）。
- 右に平面の小さな図（132×100。両対数・同じ利回りの線・軌跡・始まりと今の点だけ。文字は無し）。押すと広げる。
- 期間 N: **5 年（既定）⇔ 最長**（ある分すべて。今の作りでは最長およそ 9 年。§3.1）。欄でも広げた平面でも **N** で切り替える（ペインの状態 `ydSpan`。§6）。
  見出しには必ず実際の年数を出す（5 年に足りなければ「（2 年）」）。上の「利回りの N 年の範囲」とは期間が違うので、どちらも年数を書いて区別する。
- **配当を始めた・再開した銘柄**: 始まりの月とその前の 11 か月の中に、12 か月の配当が 0 の月があるときは、**その最後の 0 の月の 12 か月後**（12 か月の窓が初めて丸ごと配当のある期間に入る月）から数え、
  見出しを「YYYY/MM（配当が出始めて 1 年）→ 今」にする（始めた・再開したのどちらも）（窓が埋まる途中から数えると、12 か月の合計が埋まっていくだけで増配に見えるため。始まりの点が 0 でなくても、埋まる途中なら同じ）。そこから今まで 13 点に満たなければ欄を出さない。
  **今の側も同じ**: 今の前の 11 か月に 12 か月の配当が 0 の月がある（1 年以内に再開して、今の 12 か月が埋まっていない）ときは欄を出さない（埋まっていない今の合計で減配に見せない。レビューの指摘）。
- **今が無配**（今の 12 か月の配当が 0）: 「今は無配のため、内訳を出せません」の 1 行だけ。欄の高さは保つ（棒・一言・小さな図の場所を取ったまま `visibility: hidden` で見えなくする。CLAUDE.md の決まり）。
- 欄を出さない: 正の配当の記録が無い（指数・無配のまま）・点が 13 か月未満。分配金のある ETF は出す（分配金の利回りの内訳として読める）。
- REIT は「配当」を「分配金」、「1 株配当」を「1 口分配金」と書く（棒の名前・一言・読み方・平面の見出しと軸・読み取りの行。§4）。

### 2.2 「i」の説明（ツールチップ）

- 「i」にポインタを載せている・フォーカスしている間は出す。「i」のクリックかペインで **?**（`e.code === 'Slash'` と Shift。IME の変換中は無視）で**留める**（ポインタが離れても消えない）。
  留めたものは、もう一度（クリック・?）・Esc・欄の外のクリックで消す。留めたら、読み方の全体が見える所までスクロールする（下のほうで開くとペインの下で切れるため）。
- 中身: 式「利回り = 1 株配当 ÷ 株価」・「配当が増えても株価が下がっても利回りは上がる」・棒の向き（株価は下がると右）・平面の向きの小さな図
  （→ 増配・↓ 株価が下がった・斜めに沿う = 変わらず）・「配当は直近 12 か月の合計で、特別配当も含む」・「過去の値の動きで、将来を示すものではない」。
- `title` 属性ではなく、ペインの中の要素として出す（図を入れるため）。位置は欄の見出しの下に CSS で固定する（欄の左端・見出しの 30px 下。幅は `min(380px, 100%)`）。
  ポインタの位置に出す `tipBeside` は使わない（? のキーでも出すのでポインタの位置が無く、欄と一緒にスクロールさせたいため。実装で変えた）。

### 2.3 広げた平面（V か小さな図を押す。Esc で閉じる）

- ペインの見出しの下を覆う層（ペインの中。ほかのペインは操作できる）。**ペインが狭い・低い（幅 900px 未満か高さ 420px 未満）ときは、ペインを最大化してから開く**
  （`lib/paneMax.ts` の `setMaximized`。開く前から最大化していたら何もしない。ドロワーのペインは最大化できないので、その場で開く）。自分で最大化したかを一時の印に持つ。
  - Esc で閉じるとき: 印があり、**今もこのペインが最大化されているときだけ**戻す（`setMaximized(null)`）。
  - 開いている間にこのペインが最大化でなくなったら（Ctrl+Shift+Enter・タブやページの切り替え・ペインを動かす・閉じる）、層を閉じて印を消す（狭いペインに層を残さない）。
    自分で最大化したときだけでなく、**利用者が先に最大化してから開いたとき**も同じ。最大化していないペインで開いている間に**ほかのペイン**が最大化されたら閉じる（最大化したペインの上に層を出さない）。
  - 銘柄が替わって欄の出ない銘柄になったら、層を閉じ、印があれば動きなしで戻す（`clearMaximized`。`$effect` の中で判断するので、`flushSync` する `setMaximized` は呼ばない）。
  - 平面の大きさは、最大化の動きが終わってから ResizeObserver の `clientWidth`・`clientHeight` で決める（`getBoundingClientRect` は動きの途中で縮んでいる。CLAUDE.md の決まり）。
- 見出し: 「<コード> <名前> — 配当と株価の平面」・説明「横 = 1 株配当（直近 12 か月）、縦 = 株価。点は毎月」・期間（5 年 ⇔ 最長。N）・閉じる。
- 左: 平面（両対数。x と y の 1 px あたりの倍率を同じにし、同じ利回りの線が 45° の平行線になる）。
  - 同じ利回りの線: 1 pt ごと（1〜12%）、右か上の端に「N%」。始まりと今の利回りの線は破線で強調し、札（「YYYY/MM の利回り X%」「今の利回り X%」）。
  - 軌跡: 毎月の点を線でつなぎ、古い → 新しいで色を濃く、太く。配当が 0 の月で線を切る。毎年 1 月に年の札。今の点は大きく「今 X%」。
  - 札（始まりと今の利回り・今の点・年）は、枠からはみ出す側を避けて反対側に出す（`labelPos`。文字の幅は `textWidth` で見積もる）。余白より狭い枠では描かない（`toXY` も幅・高さを 1 px で下限にする）。
  - 向きの手がかり: 右下に「↘ 利回りが高い」、左上に「↖ 利回りが低い」。軸の名前。
  - 十字線: ← →（Shift で 1 年）・Home End で月を選ぶ。**月（`m`）で持つ**（取得で点が増えても同じ月に留まる）。取得で期間の始まりが動いてその月が期間の外になったら、選んでいないことにする（`cursorIn`。上の読み取り・十字線・右の内訳をそろえる。期間を N で替えたときは十字線を消す）。上の行に「YYYY/MM · 株価 · 配当 · 利回り」。
- 右（300px）: **読み方**（いつも出す。図と 3 行）・選んだ月までの内訳（始まり → その月。棒 3 本。始まりの月を選んだときは ±0 の内訳で、欄の高さを変えない）・一言・キーの案内・注意。
  最大化しても窓が狭い（幅 900px 未満）ときは、読み方を平面の下に積む。
- 対数でない軸（通常の目盛り）は持たない（平面の意味が両対数にあるため。レビューで削った）。

### 2.4 期間の長さ（実際に届く長さ）

| データ                 | 点のある範囲                                                                                           |
| ---------------------- | ------------------------------------------------------------------------------------------------------ |
| 月次系列あり（ふつう） | 配当の記録の始まり（`divCoverFrom` = 月次系列を取った日の 10 年前）の 1 年後から → **最長およそ 9 年** |
| 月次系列がまだ無い     | 日足の保存期間の始まりの 1 年後から（既定の 3 年なら**およそ 2 年**）                                  |
| 上場して間もない       | 最初の足の 1 年後から（それより前は 12 か月分の配当がそろわない）                                      |

月次系列が無い銘柄は、銘柄情報を開いたときに 1 回だけ取得を頼む（§3.1）。届けば取得の知らせで描き直す。

## 3. データと計算

### 3.1 月ごとの点（Core。`info.extra` に足す）

- `info.extra` の結果に `yieldPath: YieldPoint[] | null` を足す。`YieldPoint = { m: 'YYYY-MM', d: JstDate, price: number, div12: number }`（古い順）。
- **株価（月末の終値。分割調整済み・価格のみ）**: `src/shared/yieldPath.ts` の `monthCloses(daily, monthly)`。
  - 日足のある月は、その月の**最後の足**の終値と日（`d`）。今月は最新の足。
  - 日足の始まりの月より前は、月次系列の終値。日は**その月の最終営業日**（月次系列の日付は月の初めなので、そのまま使わない）。
  - `bars('M')`（`mergeMonthly`）は日付が月の初めで、`adjust`・`toBars` の重い処理もするので**使わない**。Core は `repo.daily`（保存期間の日足）と `repo.monthly` を読むだけ。
- **12 か月の配当（`div12`）**: 終わった月は**月で数える**: 権利落ち日の月が `m` の 11 か月前〜`m` の配当の合計（月末の日付で 1 年を切ると、月末近くの権利落ち日が
  年によって 2 回入ったり抜けたりするため）。**今月の点だけ**は、指標の実績利回り（`metrics.ts`）と同じ「最新の足の日の 1 年前より後〜その日」で数え、上の KPI の利回りと一致させる。
  0 以下の配当は使わない。配当の金額は株価と同じ分割の基準（FR-I2。分割のあとは月次系列も取り直す: `needMonthly`）。
- **点を出す月**: 12 か月の窓がすべて、配当の記録の範囲と株価の範囲の中にある月だけ。窓の始まり（`m` の 11 か月前の月の初め。今月は最新の足の日の 1 年後ろ）が、
  `max(divFrom, 最初の足（月次を含む）の日)` 以後。記録の無い月を 0 と数えると、増配に見えるため。
- **配当が 1 回も無い銘柄**（正の配当の記録が無い）は、日足を読む前に `null` を返す（ETF・指数も同じ）。
- **月次系列の取得**: 月次系列が無く（`fetchState.lastMonthly` が空）Yahoo のシンボルがあるとき、この起動で銘柄ごとに **1 回だけ** 取得を頼む
  （`askDiv10` と同じ作り。`'refetch'` で `M:<id>`。取得の対象の銘柄だけ）。↑↓ で一覧をめくっても、同じ銘柄で何度も頼まない。失敗しても、次の起動まで頼み直さない。
  月足のチャートが頼んだ取得（`'monthly'`）が待っていれば頼まず、月足のチャートも、こちらの取り直しが待っていれば頼まない（同じ月次系列を二度取らない。`jobs.isPending`）。
- 計算は `yieldPath(closes, dividends, coverFrom, firstBar)`（純粋な関数。`src/shared/yieldPath.ts`）。Core は材料を読んで呼ぶだけ。今（asOf）は最後の足の日。
  `firstBar` は実際の最初の足の日（日足と月次系列の早い方）を渡す（`closes` の日は月の最後の足・月次は月末に直してあるので、そのまま使うと最初の月を 1 か月遅く数える）。
  `info.extra` で読んだ配当をそのまま渡す（二度読まない）。

### 3.2 内訳（`yieldBreakdown(path, i0, i1)`）

- `lD = ln(div12[i1] / div12[i0])`、`lP = ln(price[i1] / price[i0])`、`lY = lD − lP`（利回りの ln 比）。
- 表示の増減率は `exp(lD) − 1`・`exp(lP) − 1`・`exp(lY) − 1`、差は `yield[i1] − yield[i0]`（pt）。
- どちらかの `div12` が 0 なら `null`。
- 始まり `spanStart(path, years)`: 今の月の `years` 年前の月（`'max'` なら最初の点）。その点と前の 11 か月に `div12` が 0 の点があれば、最後の 0 の点の 12 か月後へ進め、なくなるまで繰り返す（§2.1）。
  返す値に、実際の年数と「配当を始めて 1 年から数えた」かどうか。今の `div12` が 0 か、始まりから今まで 13 点に満たなければ null。

### 3.3 一言（`yieldCaption(b)` は文言のキーと値を返す。判定の言葉は使わない）

| 条件（`lD`・`lP`・`lY` は §3.2。「小さい」は ±2% 未満の ln 比）                              | 文言（ja）                                                                                                                                          |
| -------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| `lD` も `lP` も小さい                                                                        | 配当も株価もほぼ変わらない                                                                                                                          |
| `lY` が小さい（配当と株価が同じ割合で同じ向きに動いた）                                      | 利回りはほぼ変わらない（配当 X%・株価 Y% がそろって動いた）                                                                                         |
| 配当と株価が利回りを**押す向きが同じ**（`lD` と `−lP` の符号が同じ）か、**どちらかが小さい** | 利回りは上がった／下がった。配当と株価の両方による（大きい方が 1.5 倍以上なら「主に配当が増えた／減ったため」「主に株価が下がった／上がったため」） |
| 押す向きが**逆**（どちらも小さくない）                                                       | 利回りは上がった／下がった。<大きい方>が<小さい方>を上回った（例: 「増配が株価の上昇を上回った」「株価の下落が減配を上回った」）                    |

### 3.4 平面の形（`src/renderer/lib/yieldPlane.ts`）

- `planeBox(points, w, h, pad)`: x（配当）・y（株価）の対数の範囲。15% の余白を足し、**1 px あたりの倍率を x と y で同じ**にする（狭い方を広げる）。
- `isoLines(box, yields)`: 同じ利回りの線（株価 = 配当 ÷ 利回り）を、枠の中の線分で返す。札の位置（右か上の端）。
- `trail(points, box)`: 線分の列（配当 0 の月で切る）と、色の割合（0 → 1）・太さ。
- `cursorStep(path, m, key, shift)`: 十字線の月を動かす（← → は 1 か月、Shift で 12 か月、Home End）。

## 4. 色・文字

- 配当 = `--yd-div`（紫）、株価 = `--yd-px`（灰）、利回り = `--yd-y`（フォーカスの青）。**騰落の `--up` / `--down` は使わない**（増減の良し悪しを色で言わない）。
- 軌跡は `--yd-old` → `--yd-new` の 1 色の明るさの段（`color-mix`）、今の点は `--yd-now`。同じ利回りの線は `--yd-iso`、札は `--yd-iso-t`。ダーク・ライトの両方を `app.css` に足す。
- 文言は ja / en。ja は助詞で終えない。REIT は「1 口分配金」「分配金」。

## 5. 操作（FR-KB4）

| 場所               | キー                                                                    |
| ------------------ | ----------------------------------------------------------------------- |
| 銘柄情報（ペイン） | **V** 平面を広げる・**?**（Shift+/）読み方の出し入れ・**N** 5 年 ⇔ 最長 |
| 広げた平面         | ← →（Shift で 1 年）月・Home End・**N** 5 年 ⇔ 最長・**Esc** 閉じる     |

- 欄が出ていない銘柄では V・?・N は効かない（`false` を返して、ほかに回す）。
- 広げた平面を開いている間は、層の後ろのペインのキー（↑↓・PgUp PgDn・← → の配当の棒・Y・O・V・?）は平面が受けて何もしない。
  ほかのキー（数字の銘柄ジャンプ・C の銘柄の切り替え・Tab など）と Ctrl などの組み合わせは全体のアクションへ通す（開いたまま銘柄を替えられるように）。
- 期間（N）は内訳が出ているときだけ受ける（今が無配の欄では効かない）。
- **Esc の順**: 広げた平面を閉じる → 読み方を消す → 配当の棒の選択を消す → （ペインが返さなければ）全体の「最大化を戻す」。
- 銘柄が替わったら、十字線を消す（平面は開いたまま、新しい銘柄で描き直す。欄が出ない銘柄なら閉じる）。
- F1 の一覧（`lib/shortcuts.ts` の `info` の段）と requirements.md §6.5 の銘柄情報の行に足す。

## 9. 要求の案（requirements.md の FR-I に足す）

- FR-I11（P3）: 銘柄情報の配当の欄に「利回りの変化の内訳」を出す。N 年前（5 年か最長。足りなければある分）から今までの利回りの変化を、1 株配当の増減・株価の増減・利回りの変化の
  棒（利回りを押し上げた向きを右）と一言に分け、配当と株価の平面（両対数・同じ利回りの線）を小さく添える。i（?）で読み方、V で平面を広げ、月ごとの内訳を ← → で読める。
  今が無配のときは内訳を出さない。判定の言葉は使わない。

## 10. 決めたこと・見送ったこと

- **単独のペインにせず、銘柄情報に入れる**（2026-11-23 の利用者の判断）。平面だけでは初めて意味が分からない（モックで確かめた）ので、結論は棒と一言、平面は広げて見る。
- **説明は「i」と、広げた平面の右の「読み方」**（同日の利用者の判断）。
- **棒は「利回りを押し上げた向きを右」にそろえ、目盛りの言葉をいつも出し、利回りの棒も並べる**（レビューで、目盛りの言葉なしでは「−22% なのに右」で迷うとの指摘）。
- **期間は 5 年 ⇔ 最長**（配当の記録は約 10 年で、12 か月の窓の分だけ短くなり、10 年は届かない。レビューの指摘）。
- **12 か月の配当は月で数える**（月末の日付で切ると、月末近くの権利落ち日が 2 回入る・抜ける。レビューの指摘）。今月だけ指標と同じ日付の窓。
- 月末の点で描く（日ごとにすると、株価の揺れで軌跡が走り書きになる）。配当は直近 12 か月の合計で、配当落ちの月に段で変わる（ならさない）。
- 削った: 通常の目盛りの軸（L）。
- 受け入れた: 月次系列がまだ無い銘柄は、日足の保存期間（既定 3 年）の分だけで点を出す。その前に配当を始めていたかは分からないので、取得が届くまでの間だけ、始めた直後の窓の埋まりを増配として描くことがある（月次系列が届けば直る）。
- 受け入れた: 銘柄を替えた直後、新しい銘柄の材料が届くまでの一瞬は前の銘柄の欄を出したままにする（ほかの欄（利回りの範囲など）と同じ。消すと欄の高さが変わる）。
- 受け入れた: 配当の記録の始まり（約 10 年前）から 11 か月の間に配当を始めた銘柄は、記録の前に払っていたかを区別できないので、始まりを動かさない（最長で見たときだけ起こりうる）。
