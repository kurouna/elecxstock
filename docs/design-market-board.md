# マーケット一覧（設計）

日本・海外の指数、為替、金利、商品、暗号資産の値を 1 枚の表で見るペイン（`board`）。要求は [requirements.md](requirements.md) の
FR-MB1〜MB5 と FR-U6。マーケットのタブでは、左の列の上にあったウォッチリスト（お気に入り）をこのペインに置き換える。

## 1. 方針

- **見た目と操作はウォッチリストに揃える**。区分のタブ（ウォッチリストのリストのタブと同じ形）・件数と列の選択の段・
  一覧の表（`table.grid` と `RowCells`）・キー（↑↓・Ctrl+PageUp/PageDown・← → と S・Ctrl+Shift+C・Enter）を同じにする。
  列は指標の登録表から作る今の列（`lib/columns.ts`）をそのまま使い、このペインのための別の表や描き方は作らない。
- **行は登録表で決める**（`src/shared/markets.ts` の `MARKET_REFS`）。Yahoo で取れると確かめた記号だけを置く。
  利用者が任意の記号を足す操作は持たない（取れるかの確認と通貨の扱いが要るため）。
- **取得は今のジョブに乗せる**。データ源・通信先は増やさない。
- **表示するだけで、円の計算には入れない**。海外の行は市場 `I` として扱う（スクリーナー・ヒートマップ・ランキングは `I` を既に外している）。
  連動 ETF は普通の ETF なので、スクリーナーで市場に ETF を選べば出てくる（そのままでよい）。
- 値は日足の終値（取得したときの最後の足）。リアルタイムの値ではない。日付の列でいつの値かを出す。

## 3. データの持ち方と既存の利用者

- **銘柄の表**（`instruments`）: 海外の行（`IDX:`）は日経平均と同じく市場 `I`・種別 `index` で入れる。Yahoo の記号は `yahoo` 列に
  そのまま入れる（`JPY=X` などに `toSymbol` の `^` 付けは使えないため）。
- **入れる時期**: Core の起動のたびに `repo.ensureRefs()` で入れる（無ければ入れ、名前と記号は登録表に合わせて直す）。
  ユニバースの更新（7 日に 1 回）を待たない。
- **連動 ETF**: プライム・REIT ではないので、今は取得の対象外。取得の対象（`fetchSet`）に `MARKET_REFS` の `JP:` の ID を足す。
  利用者の追加（`userAdded`）は変えない。今の market-overview が表示のたびに `instruments.addUser` していた処理は消す。
- **既存の利用者**: 特別な処理は要らない。次の日々の更新で、
  1. 気配のバッチ（`Q:n`）に新しい行が入る（`fetchOrder` の先頭）。
  2. 日足が 1 本も無い行は、気配の処理で全期間の取得（`F:`。保存期間の分）が積まれる（今の作りのまま）。
  3. 月次の系列が無い行は `missingMonthly` で拾われる（今の作りのまま）。
  4. 指標は取得のあとに計算される。

  新しい行は 19（海外 15・連動 ETF 4）。全期間と月次で約 40 リクエスト、1 秒の間隔で 1 分弱増える。以後の日々の更新では、海外の行の
  取り直し（15 リクエスト）が毎回増える。初回の取り込み中の利用者も、計画（`planFor('initial')`）に入る。
- 日足・気配・指標の表は今のまま。新しい表は作らない。

## 4. 取得

今の日々の更新は、気配の時刻と東証の営業日から、仮の足・取りこぼし・分割の疑いを判断している（FR-D8・F9）。海外の行にこれを当てると、
東証の休日や時差で取りこぼしと誤って判断するので、海外の行（市場 `I` で日経平均以外）は分ける。

- **気配**: 海外の行も今のバッチで取る（気配の表に入れる）。仮の足・分割の疑い・取りこぼし・定期照合の判断はしない。
- **日足**: 日々の更新で、海外の行は毎回、最後の日足の 10 日前から取り直す（`H:`）。日足が無ければ全期間（`F:`）。
  取得に成功してから置き換える（FR-S11）。
- **取りこぼしの確認**（`check()`）・取得の順（`fetchOrder`）: 今は記号が `^` で始まるかで指数を見分けている。市場 `I` で見分けるように直す。
- **日付**: 日足の時刻を日本時間に直した日付が、その市場の取引日になる（米国 23:30、香港 10:30、為替 09:00。夏時間でも同じ日付）。
  `toJstDate` のまま使える。
- **F5 の「データは最新です」**（FR-F10）: 日足の無い銘柄があるとき（新しく足した行）と、最後の更新が直近の海外の終値の区切り
  （火〜土の朝 7:00）より前のときは最新としない（`src/shared/freshness.ts`）。東証の大引けだけを見ると、金曜の夜に更新したあと
  月曜の朝に F5 を押しても米国の金曜の終値を取らないため。
- **24 時間の市場**（先物・為替・暗号資産）: 取得したときの最後の足は取引の途中の値。チャート・一覧ともそのまま出す。
- **指標**: 海外の行も計算する。「古い」（`stale`）は東証の営業日で決めているので、海外の行は「最後の足が最後の東証の営業日の
  5 日前より前」で決める（海外の休日の表は持たない）。

## 5. ペイン（`board`）

```
[マーケット一覧 · 全て                                     ]   ← PaneHeader
 全て 20 │ 日本 6 │ 米国 5 │ アジア 2 │ 為替・金利 3 │ 商品 3 │ 暗号資産 1   ← ウォッチリストと同じタブ
                                               20 件  [列]   ← 件数・列の選択
 コード  名前                         終値     前日比   1か月   年初来   52週高値から  日付
 N225    日経平均                    xx,xxx.xx   +x.x%   …
 1306    TOPIX 連動ETF NEXT FUNDS…     x,xxx.x   +x.x%   …
 USDJPY  ドル/円                       xxx.xxx   +x.x%   …
```

- **タブ**: 区分（全て・日本・米国・アジア・為替・金利・商品・暗号資産）。件数を添える。ウォッチリストと同じ見た目（`.tabs`）。
  ＋ボタン（リストの作成）は無い。
- **段**: 件数と列の選択のボタン（ウォッチリストの `.filter` と同じ）。★のみの切り替えは置かない（★の対象ではないため）。
- **列**: 今の列の定義（`COLUMNS`）から選ぶ。既定は `code`・`name`・`price.close`・`price.chgPct`・`ret.1m`・`ret.ytd`・`tech.fromHi52`・`asOf`。
  Ctrl+Shift+C で選べる（ウォッチリストと同じダイアログ）。幅が狭いと右から隠す（`fitColumns`）。
- **名前**: 登録表の表示名。連動 ETF は「TOPIX 連動ETF」の後に ETF の名前を小さく出す（`name` の列のセルで、`MARKET_REFS` の行なら表示名を出す）。
- **価格の桁**: 登録表の `digits`。今の `px` は 1,000 未満を 1 桁にするので、ドル/円・米10年・銀が足りない。価格の列のセル
  （`perShare` の列）とチャートの価格の表示で、`MARKET_REFS` の行は `digits` を使う。
- **行の色**: 古い行は今の `stale` と同じ見た目（`tr.stale`）。
- 選択は銘柄の ID で持つ（`SelectionFollow`）。取得で値が変わっても、選んだ行から動かない。
- フリーの窓（2〜4 枚目）には置かない（一覧のペインは 1 枚目だけ。`FREE_WIDGETS`）。CSV の書き出しは持たない（`columns()` を返さない）。

### キー（`registerPane` の `key()`。ウォッチリスト・ランキングと同じ割り当て）

| キー                                   | 動き                                                              |
| -------------------------------------- | ----------------------------------------------------------------- |
| ↑ / ↓ / PageUp / PageDown / Home / End | 行を選ぶ。同じリンク色のチャートがその行になる                    |
| Enter                                  | リンクグループに送る                                              |
| Ctrl+PageDown / Ctrl+PageUp            | 区分のタブを次へ / 前へ（ウォッチリストのリストの切り替えと同じ） |
| G / Shift+G                            | 区分を次へ / 前へ（ランキングの市場と同じ）                       |
| ← / → と S                             | 列を選んで並べ替える（もう一度で逆順、`code` で元の並び）         |
| Ctrl+Shift+C                           | 列を選ぶ                                                          |

マウス: タブ・行・見出しのクリック、行のドラッグでチャート・グリッドへ落とす（FR-DR7）。

## 6. マーケットのタブの並び

左の列: 上にマーケット一覧（40%）、下にランキング（60%）。右は今のまま（ヒートマップとチャート、下に market-overview）。リンク 1。
お気に入りのウォッチリストはこのタブから外す（FR-L12 に例外を書く）。market-overview の既定は日経平均・1306・NYダウ・ドル/円にする。
変わるのはプリセットの初期値だけなので、保存済みのレイアウトは「プリセットに戻す」で新しい並びになる。

## 8. テスト

| 層   | 確かめること                                                                                                                                                                                      |
| ---- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| L1   | 区分の絞り込み・表示名・桁（`markets.ts`）。価格の桁の表示。海外の行の `stale`                                                                                                                    |
| L2   | `MARKET_REFS`: ID と記号が重ならない、区分がすべてタブにある、`IDX:` の行だけが海外                                                                                                               |
| L3   | 起動で海外の行が入る（2 回目で増えない）。`fetchSet` に連動 ETF。日々の更新で海外の行は `H:`・`F:` が積まれ、取りこぼしの判断を通らない。スクリーナー・ランキング・ヒートマップに海外の行が出ない |
| L5   | マーケットのタブにマーケット一覧が出る。↓ でチャートの凡例の名前が変わる。G・Ctrl+PageDown で区分が変わる                                                                                         |
| 契約 | `LIVE=1`: 登録表の記号がすべて日足を返す                                                                                                                                                          |

スタブの値はすべて架空（記号と名前だけ実在）。
